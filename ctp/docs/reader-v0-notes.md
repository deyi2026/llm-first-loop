# 读码器 v0 说明（B3）

对应计划 §4.2 B3：输入单帧图像，输出 B1 定义的 C-5 全字段；未知版本按 C-3 输出 unknown version 且不输出 ID。
规范依据：SPEC-20261123-CTP-0.9.2 §5（C-2 纠错能力、C-3 未知版本、C-4 最小可读条件、C-5 输出契约）。

## 1. 读取流程（fail-closed）

1. 校验输入（2 维 uint8 灰度图）与采集时刻（带时区的 ISO 8601）——否则 `invalid_input`；
2. Otsu 二值化，取暗像素包围盒作为靶标黑边框外沿（8 格见方），估计格阵；
3. 几何证据过闸门（`ctp_reader.gate`）：不允许即 `below_min_readable`，**不解码、不输出**（C-4b）；
4. 取 36 个数据位，四个取向各算一次与 587 个码字的汉明距离，仅在纠错能力内（≤5）且候选唯一时输出；
   否则 `unknown_version`（C-2b / C-3b），异常上不携带任何索引；
5. 靶标黑边框外四角 → PnP（`ctp_calib.pixel`）→ 协方差 → C-5 不确定度声明；
6. 组装观测，用 `ctp_contract.parse_observation` 自检，通过后才返回。

## 2. 单位与坐标约定

| 项 | 约定 |
|---|---|
| tag_size_m | 靶标黑边框外沿边长（8 格）。B6 布局的 size_mm 覆盖含静区的 10 格，两者相差 1.25 倍 |
| 图像角点顺序 | 左上、右上、右下、左下 |
| 坐标系 | 靶标系与相机系同为 x 向右、y 向下、z 垂直靶面向里；摆正的靶标姿态为单位旋转 |
| 四元数 | 把靶标系向量旋转到相机系（v_cam = q ⊗ v_tag ⊗ q*） |
| 姿态与取向 | 码字需转 r 次 90° 才摆正 ⇒ 姿态 = Rz(r·90°) |
| 协方差 | 顺序 [tx, ty, tz, rx, ry, rz]，单位 m / rad；旋转分量是相机系左扰动切空间里的量 |
| 不确定度声明 | 平移 1σ 单位 m；旋转 1σ 单位 deg，仅在生成声明时由 rad 换算一次；k 原样带出 |
| resolution | v0 不输出 `code`：36h11 板内索引不等于全局 ID（C-1d）。给了 resolver 且解析出非空串才 `resolved`，否则 `unresolved` |

## 3. 几何证据的口径

- 角点可见 = 该角相邻的三段黑边框单元格都完整落在图像内且为暗。矩形裁剪裁掉的是整条边：
  裁左边 → 左上、左下都不完整；裁上 + 左 → 只剩右下完整。
- 数据位可见比例 = 36 个数据格里完整落在图像内的比例。只按几何计，**不识别遮挡**；
  遮挡造成的位错误由纠错能力与 `unknown_version` 兜底。
- 数据位不完整落在图像内时当"未知位"：已知位 ≥ 26 才解码（保证候选唯一），否则拒读。

## 4. v0 明确做不到的事（如实）

1. **只支持轴对齐的单枚靶标**：任意角度倾斜、透视、多靶同图、尺度非整数格——都不支持；
   非正方形暗区域按 `no_tag_found` 拒读。
2. **平面 PnP 二义性未消解**（SPEC G7）：4 个外角点的平面位姿在斜视下可能翻转；v0 只在近正对位形下可信。
3. **靶标两个方向同时被图像边界截断时无法估计格宽** → `no_tag_found`（不会猜格宽）。
4. **静区或背景出现大面积暗斑会破坏定位**（包围盒被撑大）；随后由"边框环必须全黑"的校验拦下，仍不输出。
5. **没有做真实打印件与相机实测**（属 B8 / G3）；没有与第二实现互比（属 V6）。
6. 重噪声下包围盒可能偏 1–2 像素，格宽估计随之有小误差；v0 靠中心区域中位数采样与边框校验容忍，未量化。
7. 不提供实时性承诺；V1 时延分布未测。

## 5. 错误码

`unknown_version`、`below_min_readable`、`no_tag_found`、`invalid_input`、`config_invalid`
（定义于 `ctp_reader/errors.py`，风格对齐 `ctp_contract.errors`）。全部构造参数必填、无默认值。
