# 读出闸门与阈值配置说明（B4）

对应规范：SPEC-20261123-CTP-0.9.2 §5 C-4（a 可见角点数 ≥ [TBD-V4a] 且数据位可见比例 ≥ [TBD-V4b]；
b 低于阈值必须不输出——宁可漏检，不可错读；b-2 达标样本漏检率受限）、§11.2 V4（双向判据）；
计划 §4.1 K1（阈值可配置 + 声明式，禁止硬编码）、K6（失败显式）、K7（影子通道）。

## 1. 阈值从哪来

两项阈值在代码里**没有默认值**：必须由调用方给出（构造参数或声明式 JSON 文件）。
它们在实测与工作组裁决前是空缺——[TBD-V4a]、[TBD-V4b] 的取值只能来自 V4 实测回执与
WG-RES 决议编号（SPEC §0.2 填充流程）。任何测试里出现的数字都只是测试参数。

## 2. 双向抑制怎么落

| 侧 | 规范要求 | 本实现的供给侧保证 | 统计归属 |
|---|---|---|---|
| 错读侧 | 低于阈值的样本误读率 = 0 | 低于任一阈值即不允许（恰等于阈值允许，≥ 语义），调用方必须不输出 | 误读数由 V4 runner 按样本标签统计 |
| 漏检侧 | 达标样本漏检率 ≤ [TBD-V4c]，N ≥ [TBD-V4d] | 达标样本永不被闸门抑制；"永不输出"的退化实现无法靠闸门通过 | 漏检率 = 被抑制的达标样本数 / 达标样本总数，由 V4 runner 计算；闸门只提供 suppressed_count |

判定顺序：先角点数，再数据位比例；原因码取首个不满足项（below_min_corners / below_min_data_ratio）。

## 3. 影子通道（K7）

V4 要同时满足"正式输出为零"与"漏检可统计"，两者只能靠构建隔离：正式构建 shadow=False，
测试构建 shadow=True。影子通道在证据落入近阈值带时记一条日志并计数，**绝不改变 allowed**，
日志只含几何证据与原因，不含任何 ID 或观测内容。

**近阈值带的工程定义（待 G2 追认，不是规范数值）**：设带宽比例 b = shadow_band，对阈值 t，
证据值 v 满足 t·(1−b) ≤ v < t·(1+b) 即为近阈候选。角点数与数据位比例各自套用，任一命中即记。
b 是调用方给定的测试参数，shadow=True 时必填。

## 4. 与 B3 读码器、B7 runner 的调用约定

- 读码器在解码**之前**用几何证据调用 ReadGate.evaluate；不允许即抛 below_min_readable，
  解码结果不得以任何形式对外输出。
- 证据口径（几何定义，不引入新的数值参数）：visible_corners = 完整落在图像内的靶标角点数；
  visible_data_ratio = 完整落在图像内的数据格比例。
- V4 runner 用 suppressed_count 与样本标签计算漏检率；[TBD-V4c] / [TBD-V4d] 未配置时只能给出
  实测数与 indeterminate，不能判通过。

## 5. 已知边界

- 闸门只看调用方交来的证据，不自行从图像测量；证据的真实性由读码器负责。
- "可见"取"完整落在图像内"的保守口径；部分遮挡但格心可见的情形不计入可见，
  这会让闸门偏严（偏漏检侧），符合"宁可漏检"的方向，但真实漏检率须由 V4 实测给出。
- 影子日志是进程内列表，不落盘、不签名；需要留证的由 runner 在回执里记录计数。
