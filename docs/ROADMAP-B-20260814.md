## 三、红线（框架化不越界）

1. **程序最小化不倒退**：插件/API 化是开放能力，不引入"程序替 AI 决策"的新机制（RULE-AI-00 反例清单继续有效）。
2. **零回归纪律**：每个 B 任务走既有门禁（pytest 全绿 + ruff 0 + pyright 0 + CHANGES 登记）。
3. **SoT 先行**：规则类改动先 ai_rules.md 再 prompt.py（防漂移测试保护）。
4. **密钥不出域**：任何公开代码/文档不含真实密钥；CI secrets 独立。
5. **A 路线能力不回退**：个人助理体验（CLI/Web/飞书）随框架化保持可用（测试覆盖延续）。
