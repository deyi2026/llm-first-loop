# Common Governance / Common Experience

状态：默认模型治理层，2026-09-11。

## 目的

恢复 LFL 早期针对本地模型重复、漂移、无效复查和中断后重开题的有效经验，但不恢复旧的 prompt-heavy 自动注入、Program Authority 或固定仪式。该层只提供跨任务通用的思考纪律；当前事实、当前用户指令、明确任务约束和更具体的已验证方案始终优先。

## 常驻最小集

1. 保持当前目标和明确约束；区分观察、事实、假设、决定，并检查证据来源、时效和范围。
2. 动作前比较状态差异；成功回执或已闭合结论在没有新反证时不重复核验。
3. 只验证会改变下一步决定的不确定性；优先高信息增益、低成本动作。陌生接口先核当前 schema/code/docs，历史经验只在当前证据不足时按需参考。
4. 截断/中断后优先恢复持久化事实与最近未完成状态，随后只做增量推理，不从旧历史重新开题。

- `79b7527` / lite v7：成功回执不重复验证；自查不得在证据已到手后抢占生成尾部；截断补救和任务有界推进。
- `e137c76` 的 Operating Contract 候选：保留“目标/约束、证据纪律、只验证决策相关不确定性、信息增益、closed decision 不重开”等思想；不整包恢复 8 条及其 Tier/架构知识。
- 2026-09-06 Rule/Experience 治理：Rule/Experience 全文仍采用 discover -> exact hydrate；Common Governance 不把经验库目录自动注入 prompt，也不替模型判断 task applicability。

## 明确不做

- 不自动选择/隐藏工具，不规定固定调用顺序。
- 不用程序判断任务完成、证据语义充分性或方法适用性。
- 不恢复每轮自查、固定重试次数、动态经验 catalog、HOT/WARM/COLD 或 Adaptive Autonomy 等大段常驻知识。
- 不把历史计划、历史 assistant 提议或历史经验升级成当前授权。

## 验收门

常驻文本必须 deterministic、静态、短小；相关测试必须证明当前用户真值可覆盖默认经验，且无旧 prompt-heavy/Program Authority 标记。真实 Ornith 验收需覆盖：成功后不重复核验、无进展后调整、陌生接口先查当前事实、中断/最近窗口续做，以及运行时 1/1 并发和内存健康。
