## 1. 事故与事实（F 系）

- **F1** 用户问题"重启不成功"于 09-22 13:27 入队（`q_9e60caae0f09`，会话 b8938fdb），撞服务重启窗口（svc-86a873 操作屏障），回执承诺"消息已持久化排队，恢复后自动继续"，随后该项被置 **cancelled**（terminal，13:29）。
- **F2** "自动继续"的实际承载是**浏览器端派发循环**：UI 轮询 `POST /api/v1/chat/queue/dispatch` 认领队首，认领方（前端）自己发起 `/chat/stream`。服务端无人兜底。
- **F3** 服务重启后，原标签页的派发循环死亡：次日 07:1x 观测该页仅轮询 jobs/messages/interop，**30 秒 0 次 dispatch 请求**——持久化承诺失效，用户侧表现为"大模型很久没有反应"。
- **F4** 后端无任何在途 run（无 run.lock、无在途 provider 调用）——纯前端恢复语义缺口，非模型/运行时故障。
- **F5** `dispatch_claim` 本身是原子 FIFO（端点文档："多标签并发领取只有一个成功（幂等收敛）"）——多领取方安全，服务端兜底可直接复用同一原语。
- **F6** 09-23 07:1x 处置：经 `HumanTurnQueue.enqueue` 官方语义重投原问题（`q_113e83e0cc0c`，queued）；用户刷新页面后恢复正常使用（另开会话），重投项留待回到该会话时接续。
- **F7** schedule 体系已有服务端发起 run 的完整机制（wake: true 的会话续跑）——服务端执行一轮"排队消息"不存在能力空白。

## 2. 问题定性

**P1（P0）** 持久化排队的"恢复后自动继续"承诺依赖浏览器存活——服务重启/关标签/断网后承诺静默失效，用户无限等待。
**P2（P1）** cancelled-by-barrier 是终态，无任何恢复路径（连刷新也无法续）。

## 3. 修复方案（两档，推荐 A）

### 方案 A（推荐）：服务端 scheduler 兜底派发

web 进程内低频巡检（复用既有 scheduler 节拍）：会话空闲 + 存在 `queued` 项 + **项龄超过阈值（如 60s，避让浏览器正常领取窗口）** → 服务端调同一 `dispatch_claim(claimed_by="server-fallback")` 认领并按 schedule-wake 同构路径执行该轮。

- 复用 F5 原子性：浏览器与服务端竞争认领，天然单赢家；
- 复用 F7 机制：执行路径与 wake 续跑同构，无新运行时形态；
- `claimed_by` 区分来源，审计可辨。

### 方案 B（窄补）：barrier 取消项服务端重排

服务重启完成后，扫描近期 `cancelled` 且 detail 含屏障操作号的项，以**新队列项**重排（origin=recovery_requeue，原项保持终态不改写——诚实溯源）。

- 只覆盖 F1/F2 的具体形态，不救浏览器死亡/关标签场景；
- 实现最小，可作 A 落地前的止血。

### 拷问记录

| 疑点 | 裁决 |
|---|---|
| a. 服务端兜底会不会与浏览器双发？ | 不会：dispatch_claim 原子 FIFO（F5），单赢家；败者收到 claimed=None 即收敛（现端点语义） |
| b. 阈值 60s 会不会抢走正常插话节奏？ | 阈值只约束"项龄"，浏览器正常在 1-2 个轮询周期内认领；兜底仅在浏览器缺席时生效 |
| c. B 重排 cancelled 是否违反"terminal 不复活"？ | 不改写终态记录，新建项携带 origin 溯源——与 reconcile 的 crash_recovered 重排同构（learning journal 先例） |
| d. 是否新增控制机械（准入不对称审计）？ | 否：两案均为恢复语义管道（agency 放大——消息必然达达），无语义裁决门 |

## 4. 验收清单（实现时落测）

- [ ] A：浏览器缺席（无 dispatch 轮询）时，queued 项 ≤ 阈值+巡检周期内被服务端认领执行并产出 assistant 回复
- [ ] A：浏览器正常在场时，服务端兜底永不抢领（claim 竞争收敛回归）
- [ ] B：barrier-cancelled 项在服务恢复后重排为新项，原项终态与审计不变
- [ ] 回归：现有多标签并发领取幂等测试零变化；屏障期不派发语义（§8.2-2）零变化

## 5. 优先级建议

P1=P0（用户可感知的承诺失效）。A 为根治，B 可先行止血；两案可同批实现（B 先 A 后）。
