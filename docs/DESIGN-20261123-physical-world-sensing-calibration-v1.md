## 1. 问题定义

仿真测试中，即使简单动作也需要校准（坐标系、时延、增益、摩擦系数……），原因有二：
一是仿真器参数与真值有偏差，二是动作执行的"效果"必须被观测闭环确认。

真实世界把这件事变得更难，且更必要：

| 维度 | 仿真 | 真实世界 |
|---|---|---|
| 可重复性 | 可任意重置、重放 | 不可重置，每个时刻只发生一次 |
| 观测噪声 | 可控、可关 | 无处不在（光照、遮挡、电磁、声学混响） |
| 漂移 | 无 | 温度、磨损、松动导致参数随时间变化 |
| 校准成本 | 重跑脚本 | 占用设备、占用人、可能破坏工件 |
| 验证手段 | 断言真值 | 真值本身也要被测量 |

因此本方案的核心命题是：**如何让"校准"从昂贵的一次性仪式，变成低成本的持续闭环。**

"校准"在此定义为：把系统内部模型（几何、时序、动力学参数、感知映射）与物理世界真值对齐，并在漂移发生时维持对齐的过程。它包含三个环节，每一个都有成本：

1. **感知**：取得物理世界的观测证据；
2. **估计**：从证据推断参数修正量；
3. **验证**：确认修正后的模型确实更接近真值。

"便利"= 同时降低这三个环节的人力、物力与时间成本。

## 2. 总体思路

### 2.1 一条主原则：以证据为中心的闭环

一切校准决策必须锚定在**当前取得的观测证据**上，而不是先验假设或上一次的校准结果。
这带来两个直接推论：

- **先感知、再校准**：怀疑哪个环节漂了，就先取哪个模态的当前证据，而不是凭记忆判断（感知层的问题必须用同模态证据回答，结构/日志类证据回答不了"物理上看起来对不对"）。
- **校准必须可证伪**：每次校准结束前必须能回答"我怎么知道这次校准是对的"——用一个已知答案的探针动作/探针观测来实测，而不是默认成功。

### 2.2 大模型不替代数值内核，而是压缩校准的"周边成本"

传统标定的数学内核（张正友相机标定、手眼标定 AX=XB、IMU 重力对准、声学时延估计）依然有效且应当保留。大模型（多模态 Agent）的真正增量在四个方向：

1. **编排成本 → 对话化**：把"写标定脚本、找标定板、跑流程、看报告"压缩为自然语言指令驱动；
2. **标定物成本 → 日常物自标定**：开放词汇视觉让日常物体（桌面、硬币、门框、手机屏幕）成为可用的几何参照；
3. **发现成本 → 异常自动检出**：多模态模型持续观察视频/音频流，在人类察觉之前发现"哪里不对劲"（漂移的早期信号）；
4. **判定成本 → 语义解释与归因**：把数值残差翻译成"左相机外参绕 Y 轴偏了约 0.8°，疑似夹具松动"，并给出处置建议。

## 3. 传感层：多模态工具箱

### 3.1 视觉（主力模态）

| 用途 | 工具 | 便利性要点 |
|---|---|---|
| 几何/位姿校准 | RGB + 深度相机；棋盘格、ArUco/AprilTag（可打印） | 标定物成本≈一张 A4 纸 |
| 开放世界自标定 | 视觉基础模型提取日常物体关键点/平面/边缘 | 零专用标定物，随处可校 |
| 细节核验 | 高分辨率局部裁剪 + 视觉模型读数 | 坐标契约：原图/裁剪/送检尺寸与缩放系数必须显式换算，防止"看错位置" |
| 过程证据 | 定期截图/短录像落盘，带时间戳与哈希 | 可回放、可审计、可离线重校 |

视觉工程上有两条纪律值得从软件工程迁移过来：

- **坐标契约**：任何视觉输出的位置（如检测框）必须附带"原图像素坐标 + 换算式"，且标注"未经验证"，直到被另一个通道核对。物理世界里"看错位置"是校准事故的第一大来源。
- **缓存不等于现状**：同一场景返回同一份旧图像（缓存命中）不能当作当前状态证据；感知证据必须带采集时间戳，用前核对新鲜度。

### 3.2 听觉（被低估的便利模态）

听觉的物理优势：麦克风便宜、无遮挡问题、全向、采样率高（微秒级时基），适合做**时基与事件校准**：

1. **多传感器时间对齐**：一个拍手/敲击声 + 各传感器记录的时间戳，即可校准相机间、相机与力传感器的时钟偏差（声速约 340 m/s，近场误差可控；需要更高精度时改用电子同步信号）。
2. **接触与松动检测**：碰撞声、电机异响、齿轮啸叫是接触状态与机械松动的廉价代理信号——音频指纹/异常检测模型可在任务中持续监听，作为漂移报警器。
3. **声-视联合验证**："看到夹爪闭合"与"听到接触声"互为印证；两者不一致即提示视觉或机构存在偏差，触发针对性复查。
4. **语音作为人类标注通道**：现场人员的一句口头反馈（"刚才那下歪了"）经语音识别进入系统，是成本最低的人工标注来源；大模型把它结构化为带时间戳的异常事件。

### 3.3 力觉/触觉

- 六维力/力矩传感器：接触力学对齐（工具坐标系与力传感器坐标系标定，用重力向量自校准——倾角不同方向的静止读数即可解出安装偏置，无需外部设备）。
- 抓取电流/压力反馈：作为"任务即校准"的隐式信号（见 §5）。

### 3.4 本体感觉

- 关节编码器、IMU：上电自检的第一手证据（重力方向、零位漂移）。
- 温度传感：建立"温度—参数漂移"补偿曲线，把可预测的漂移从"故障"降级为"已知修正"。

## 4. 大模型的四个增量角色（展开）

### 4.1 校准流程的对话式编排

用户说"帮我校一下左边的相机"，Agent 负责：
1. 感知当前设备清单与权限（自检：能不能访问相机？分辨率多少？——失败时给出修复指引，而不是产出黑图还继续跑）；
2. 生成校准计划（采集多少帧、什么姿态覆盖、判停条件）；
3. 引导现场人员配合（"请把标定板移到画面右下角"或"请在听到提示音后拍一次手"）；
4. 运行数值内核，输出参数修正量与不确定度；
5. 执行探针验证（§6）并出具报告。

人只出"一句话 + 少量配合动作"，其余由 Agent 编排——这是"便利"的第一落点。

### 4.2 无标定物的自标定

利用视觉基础模型从日常场景提取几何约束：平面（桌面/墙面）、平行/正交边缘（门框）、已知尺寸物体（A4 纸、硬币、显示器）。
策略：优先用专用标定物获得高精度基准（L0，见 §5）；日常运行中用日常物做**低精度快速复查**，只在复查失败时才升级到专用标定流程。精度分级换取频度，是便利性的核心交换。

### 4.3 漂移的持续监听与归因

任务运行中持续对比"预测—观测"残差：
- 视觉残差：抓取点预测位置 vs 实际接触位置；
- 力残差：预测接触力 vs 实测；
- 声学异常：新出现的异响模式。

大模型负责归因排序：把"成功率下降"翻译成候选原因清单（相机外参漂移 > 末端工具松动 > 光照变化 > 物料批次变化），并给出每种的**最低成本鉴别实验**（"先拍一张标定板照片，2 分钟排除相机问题，再动夹具"）。

### 4.4 校准结果的语义化与知识沉淀

每次校准产出结构化记录：参数旧值/新值、证据引用（原始图像/音频/力曲线的落盘路径与哈希）、置信度、生效范围、验证探针结果。
积累后形成设备的"健康档案"：漂移速率、易松动部位、温度敏感参数——支持预测性维护，把重校准从事后抢救变为计划内动作。

## 5. 分层校准架构

```
L3 重校准触发层   残差超阈/异常报警 → 停止或降级 → 定向重校（只校漂了的参数）
L2 在线层        任务运行中：预测-观测残差监控 + 声学监听 + 隐式标定信号收集
L1 例行层        每次开机/每任务开始：自检清单（权限、视野、重力零位、时基、听一声自检音）
L0 基准层        安装/维修后：专用标定物全量标定 + 全通道时基同步，产出基准参数与档案
```

关键设计点：

1. **自检必须"fail-closed + 给修复指引"**：某通道不可用时报"不可用+怎么修"，绝不静默降级后继续执行（看不到就当没看到，按未通过处理）。
2. **定向重校优先于全量重标**：先用敏感性分析定位漂移参数（哪个自由度、哪个传感器），只重估该参数。全量重标是最后手段。
3. **时基是隐形地基**：所有跨模态校准的前提是各传感器时钟对齐。建议把"拍手对时/电子同步"做成开机例行动作，成本秒级。
4. **原始观测持久化**：所有校准用的原始流（图像、音频、力曲线）落盘、带时间戳与内容哈希，支持离线重放重校——一次采集，多次使用。

## 6. 验证、安全与审计

### 6.1 探针动作实测（校准的"应拦输入"）

校准宣称"生效"之前，必须实测一个**已知答案**的动作：
- 相机校准后：识别放置在已知位置的标准物，位置误差应在阈值内；
- 手眼标定后：触碰一个视觉定位的点，实际接触偏差应在阈值内；
- 力零位校准后：空载读数应回零。

没有探针实测的校准不得标记为完成。这与软件工程中"护栏变更必须用应拦输入实测"是同一条纪律。

### 6.2 风险分级执行

物理动作按可逆性分级：
- **只读感知**（拍照、录音、读传感器）：自动执行；
- **可逆动作**（移动到观察位、轻触）：先演练（dry-run）确认计划，再执行；
- **不可逆/危险动作**（大负载抓放、接触未知物体）：必须人工确认令牌后才执行，且每个动作一个令牌，不复用。

### 6.3 审计日志

追加式（append-only）记录：何时、谁/哪个 Agent、校了什么参数、依据哪些证据、探针结果如何。校准事故的复盘和责任界定完全依赖这份日志。

## 7. "便利性"工程清单（本方案的落点汇总）

1. **校准仪式最小化**：把校准嵌入自然动作——机器人每次抓取日常物品都是一次隐式手眼校准（抓取成功的伺服收敛数据免费积累）。
2. **任务即校准**：利用任务自身的成功/失败信号作为免费校准证据，不额外占用设备时间。
3. **精度分级**：日常物快速复查（高频、低精度）+ 专用标定物精标（低频、高精度），按需升级。
4. **对话式编排**：人只说目标，Agent 编排采集、计算、验证、报告。
5. **声学时基**：一次拍手完成多传感器对时，成本秒级。
6. **定向重校**：只校漂了的参数。
7. **一次采集多次使用**：原始流持久化 + 离线重放重校。
8. **人类语音标注通道**：现场一句话 = 一条带时间戳的结构化异常记录。
9. **温度补偿曲线**：把可预测漂移变成查表修正。
10. **健康档案与预测性维护**：漂移趋势提前预警，重校准进入计划而非事故响应。

## 8. 落地路线图

| 阶段 | 内容 | 验收标志 |
|---|---|---|
| P1（0–3 月） | 现有标定流程的 Agent 编排化：自检清单、对话引导、报告生成、审计日志 | 一次相机标定的人工参与时间下降 ≥ 70%，全部校准有探针验证记录 |
| P2（3–9 月） | 多模态辅助自标定：日常物几何参照、声学对时、漂移监听报警 | 无专用标定物场景下完成低精度复查并正确触发升级 |
| P3（9–18 月） | 持续在线校准闭环：隐式标定信号积累、定向重校、预测性维护 | 漂移导致的任务失败中，≥ 80% 在失败发生前被报警捕获 |

关键指标：校准耗时、重校准频率、残差收敛速度、探针一次通过率、任务成功率恢复时间、人工干预次数。

## 9. 标准标定图案体系（合作目标协议）：航天对接式分级校准

### 9.1 航天对接给的核心启示

航天器交会对接（ISS / Dragon / 联盟号等）的可靠性来自一个朴素设计：**对方配合，提供已知答案**——

- 远场：差分 GPS / 微波雷达（米级）；
- 中场：光学相机识别对接机构上的十字靶标 / 编码靶标（厘米级）；
- 近场：激光雷达 + 密集靶标阵列（毫米级）；
- 最终：对接环机械接触 + 力传感伺服（亚毫米级）。

四级通道各管一段精度区间，逐级交接、逐级校验。这就是"特定图案校准、逐步精确对接"的标准范式。它验证了一条原则：**与其从噪声世界里反推位姿，不如让世界的关键部位自带可读的已知结构**。AI 操纵工具、认知感知物理世界，可以直接继承这套范式：工具、夹具、工件、工作台上的标准图案，就是机器人的"对接靶标"。

### 9.2 图案即接口：把标定做成协议而非工艺

把编码图案（AprilTag / ArUco / ChArUco 一族）从"标定工具"升级为"标定协议"，分四层标准化：

| 层 | 内容 | 作用 |
|---|---|---|
| 物理层 | 印刷规范：黑白对比度、最小角点边长（像素占比）、哑光防反光材质、平面度与粘贴公差 | 保证任何相机在规定距离内可读 |
| 编码层 | ID 空间分配、汉明距离纠错（如 36h11 族）、版本位 | 一物一码，误检可控，支持向后兼容扩展 |
| 语义层 | 注册表：ID ↔ 所属物体 ↔ 参考系定义 ↔ 安装日期 ↔ 上次验证时间 | 图案不仅回答"在哪"，还知道自己"是谁、装在哪、何时校过" |
| 组合层 | 单靶（6DoF 单点）→ 三靶阵列（消解单视角歧义）→ 标定板/笼（多视角全覆盖）→ 标定室（全参数基准） | 从点到面，覆盖不同标定任务的观测需求 |

由此获得通用性与可拓展性：

- **通用**：任何工具、夹具、手腕、工作台贴上标准图案，任何兼容读码器（相机 + 开源检测器）即可读出其 6DoF——图案成为物理世界的"USB 接口"，设备间零协商互通；
- **可拓展**：新增自由度或新模态时通过版本位扩展图案族（彩色靶标、红外反射涂层、偏振标记、被动声学信标），旧读码器自动忽略新版本不误读，新读码器向下兼容——协议演化不破坏存量部署。

### 9.3 分级精度收敛：对接过程 → 工具操纵

| 阶段 | 感知通道 | 可达精度 | 交接条件 | fail 检查 |
|---|---|---|---|---|
| 远：场景级 | VIO / 语义地图 / 基础模型场景理解 | 0.1–1 m | 靶标进入视野且 ID 校验通过 | 相邻层级位姿差超阈 → 回退 + 报警 |
| 中：编码图案 | AprilTag / ArUco | 1–10 mm | 高密度大板 / 靶标阵列可见 | 角点亚像素残差、重投影误差 |
| 近：精细阵列 | ChArUco 大板 + 双目/深度 | 0.1–1 mm | 力/触觉传感器就位 | 标定板平面度自检 |
| 接触：伺服级 | 力觉 / 触觉 / 编码器闭环 | 0.01–0.1 mm | 接触力进入期望窗口 | 力曲线形状符合预期 |

两条纪律直接复用本方案既有原则：

1. **逐级交接做一致性校验**：相邻两级给出的位姿差超过阈值即 fail-closed，回退上一级并报警（同 §5 纪律 1），绝不在层级矛盾下"硬接"；
2. **靶标读取本身就是探针**：看一眼 30ms 即完成一次"已知答案"的核对（§6.1），天然构成 L1 开机自检的标准动作——开机扫一圈靶标、读 ID、比位姿，全部命中即自检通过。

### 9.4 合作通道与被动通道：双腿结构

| | 合作通道（标准图案） | 被动通道（日常物自标定，§4.2） |
|---|---|---|
| 精度 | 毫米级及以下 | 厘米级 |
| 布置成本 | 需一次性粘贴/安装 | 零 |
| 适用场景 | L0 基准标定、L1 自检、L3 定向重校的对齐参考、精密任务 | L2 在线残差监控、未知环境探索 |

决策规则：**任务精度需求超过被动通道可达精度时，必须启用合作通道**。两者不是替代关系，而是精度—频度交换的两条腿（与 §7.3 精度分级同构）：标准图案保证"随时有高精度答案可查"，日常物保证"没贴图案的地方也能粗查"。

### 9.5 动态图案：把非合作表面临时"合作化"

- **投影图案**：投影仪向任意平面投射 ChArUco / 结构光，把普通桌面临时变成标定板——零粘贴成本换取合作通道精度；限制：依赖投影面平面度与环境光可控；
- **现场生成**：Agent 判断任务需要合作通道而现场没有靶标时，产出图案 PDF + 布置图纸 + 验收探针清单，人工粘贴一次、长期受益。

### 9.6 大模型在标准体系下的角色：不发明图案，经营协议

编码图案的数学与工程已成熟，大模型的增量在协议的经营层：

1. **布置优化**：给定待标参数集，分析可观测性/信息量（调用 D-optimal 实验设计求解器），推荐"贴哪、贴几张、什么尺寸与密度最优"——把"凭经验贴"变成"按信息量贴"；
2. **图案健康监测**：基础模型识别靶标污损、起翘、反光异常，在读取精度劣化前预警；
3. **误差翻译**：残差模式 → "3 号靶标疑似贴歪约 2 mm"或"左相机绕 Z 漂 0.5°"（§4.3 归因能力直接复用）；
4. **方案生成**：读任务描述 → 选靶标组合 → 出布置图纸 → 给验收探针清单（§4.1 编排能力的自然延伸）。

### 9.7 验收与纪律

- 标准化收益指标：靶标粘贴后单次自检耗时（目标 < 100 ms）、同一读码器跨设备复用率、标定一次的人工参与时间（目标：贴纸 + 一键）；
- **探针实测**：图案体系上线必须跑已知动作（标定后触碰视觉定位点、靶标已知位姿复测），未过探针不得标记生效——与"护栏变更必须用应拦输入实测"同一条纪律（§6.1）。

## 10. 拷问清单与缺口闭合（v1.2）

对第 9 章协议做一轮强制盘问：**每问必须回答，跳过 = 假装完整**。每条回答给出裁决——已闭合（落到规范条目，编号 S*）或缺口（进入第 11 章验证计划，编号 V*）。本清单本身就是标准化的第一份评审记录。

### 10.1 数值与承诺的来历

**Q1：§9.7 的"自检耗时目标 < 100 ms"来自实测还是估算？超过多少时设计失效？**
估算，未实测（依据：编码图案检测在常规工控相机分辨率下的典型单帧延迟为数十 ms 量级，加查表比对）。裁决：耗时是**可用性指标而非安全指标**——超时（如 > 1 s 或超出工位节拍预算）只触发降级（并行扫靶 → 逐靶串行）并在报告标注，不触发 fail-closed；安全判据是漏检/误读率，不是速度。缺口 V1：实测时延分布，确认目标可达或修订目标数值。

**Q2：§9.3 的精度区间（1–10 mm 等）依据是什么？**
文献与工程经验的量级估计，非本方案实测。裁决：进入规范前必须用计量级真值实测重建"精度—距离—入射角—光照"曲线，规范中的精度声明一律以实测为准，禁止照抄经验数字。缺口 V2。

### 10.2 物理与环境的边缘情形

**Q3：图案自身就是误差源（印刷/切割公差、粘贴偏移、热胀冷缩）——宣称毫米级，图案自身的尺寸误差多大、谁认证？**
制造公差与读出精度必须解耦：物理层规范定义**公差带**（边长公差、平面度、热膨胀系数上限、哑光防反光要求），一切精度声明以"公差带内制造 + 规定读出条件"为前提，带外产品不得引用精度声明。认证样本（参考件）由计量实验室标定后作为一致性测试基准。缺口 V3：公差带具体数值需计量数据支撑。

**Q4：污损、起翘、部分遮挡下的降级规律是什么？**
规范必须规定**最小可读条件**（可见角点数 / 数据位比例阈值）；低于阈值时读码器的合规行为是**不输出**，而不是输出一个低质量解——"宁可漏检，不可错读"。到达阈值之前的劣化预警交给健康监测（§9.6）。缺口 V4：阈值与降级曲线实测。

**Q5：投影临时合作化（§9.5）的"毫米级"承诺，在投影面不平、环境光不可控时还成立吗？**
不成立时必须自动判别。原断言弱化为：投影标定的有效前提（投影面平面度、对比度、投影畸变校正）作为**运行时自检项**，前提不满足即降级为"粗对齐"并显式打降级标记，不得混入毫米级通道。缺口 V5：投影标定的"精度—前提条件"曲线。

**Q6：两台读码器并发读同一靶标给出不同 6DoF，谁对？**
协议输出的是"观测 + 不确定度"，不是真值，不存在"裁决谁对"。一致性要求：两个合规读码器对同一认证样本的位姿差 ≤ 各自声明不确定度的合成（RSS）；运行时多观测融合交给上层估计器（EKF 等）。缺口 V6：跨厂商一致性测试。

### 10.3 失败模式

**Q7：fail-closed 逐级回退，回退到最上级也失败怎么办？**
回退链终点必须显式定义：远→中→近→接触逐级交接，**每级都有失败出口**，最底层出口 = 停止 + 报警 + 人工介入，绝不允许"默认通过"（与 §5 纪律 1"看不到就当没看到"同构）。已闭合：回退状态机为规范必写章节（S1，Phase 0 起草）。

**Q8："旧读码器自动忽略新版本不误读"（§9.2 版本位承诺）如何证明？**
这是一条可证伪断言，验证方法唯一：混合版本靶标墙 + 旧版读码器，误读率必须为 0（或 ≤ 规定上界）；不达标的新旧版本组合**不得发布**——版本演化的发布门禁。缺口 V7。

### 10.4 规模化

**Q9：ID 空间治理——谁分配？跨厂碰撞怎么办？一间工厂 10 万个靶标怎么办？**
分层命名空间：高位 = 机构前缀（类 MAC OUI / ASN 模式：前缀自治分配 + 可选公共注册），低位 = 本地分配保证厂内唯一；跨机构互通只要求前缀唯一。规模不是瓶颈：视觉检测先于查表发生，注册表查询是哈希查找。缺口：治理章程 → 第 12 章 P4。

**Q10：温度形变与长周期——早上和下午读出的 6DoF 不同，是漂移还是真值变了？**
参考系定义必须绑定基准温度（或对认证参考件采用低膨胀材质）；常规靶标的热形变**纳入不确定度预算**而非试图消除；注册表的"上次验证时间" + 复验周期由健康档案（§4.4）驱动。部分闭合：参考温度条目落 SPEC P-3；T0 数值待工作组确认（`[TBD-G]`）。

### 10.5 安全

**Q11：伪造靶标 = 伪造定位真值——贴一张复制 ID 的靶标就能骗过机器人？**
必须显式声明协议安全边界：**编码层提供识别，不提供防伪**。防伪分三级：语义层签名（注册记录带签名，伪造 ID 查不到对应签名记录即拒）、组合层几何互证（单靶可复制，三靶阵列的几何关系一致性难以伪造）、物理访问控制（封闭产线场景天然具备）。威胁模型成为规范必写章节。缺口：威胁模型正式化（S3，Phase 0 起草）。

**Q12：注册表投毒 / ID 复用导致旧设备误读？**
注册表变更走 append-only 审计（与 §6.3 同构）；ID 报废进入**墓碑状态**而非复用；注册表数据带版本与签名，离线快照可校验。已闭合方向：规范条目（S4，Phase 0 起草）。

## 12. 开放标准路径（v1.2）

### 12.1 标准四件套

1. **规范文本**：四层协议（§9.2）+ 威胁模型（S3）+ 回退状态机（S1）+ 一致性要求；
2. **开源参考实现**：读码器封装 + 生成工具链 + 注册表；
3. **一致性测试套件**：软件测试（含 V7 混合版本测试）+ 物理认证样本（计量标定件）；
4. **认证与治理流程**：前缀注册规则、合规声明格式、认证标志使用规则。

### 12.2 治理与知识产权

- 开放工作组 + 贡献者协议 + 决策规则（草案→评审→投票记录全程公开）；
- 免版税 / RAND-Z 知识产权承诺；P0 上游许可在线初筛完成（2026-11-23，回执见 SPEC v0.9.1 §12.1）：AprilTag 参考实现为 BSD-2-Clause（v1.2 原记 MIT 系笔误，本版勘误）、OpenCV 4.5+ 为 Apache-2.0（≤4.4 为 BSD-3）；专利维度未能在线确认，v1.0 发布前须完成专利数据库人工检索与法律复核，规避标准必需专利陷阱；
- ID 前缀自治分配 + 可选公共注册（DNS 式起步，而非中心收费式）。

### 12.3 两步走路线

- **第一步（事实标准）**：规范 + 参考实现 + 测试套件以开源生态路线立住——AprilTag 本身就是先例（论文 + 开源实现成为事实标准，从未经过正式标准化组织）；
- **第二步（正式标准）**：生态与验证成熟后提交标准化组织（机器人领域：ISO/TC 299、IEEE，国内：全国机器人标准化技术委员会 SAC/TC 591）；
- 两步互不排斥，第二步的材料（规范文本、测试数据、互操作记录）在第一步中自然积累。

### 12.4 发布门禁（与第 11 章衔接）

规范 v1.0 发布前三关，**全过才发布**：

1. V7 版本兼容误读 = 0（协议演化不破坏存量部署的承诺经过实测）；
2. V6 跨厂商一致性（≥ 2 个独立实现互认）；
3. V3 认证样本公差带实测落带（物理层可信有计量依据）。

"验证通过"以 11.2 门槛表的全量实测回执为准，不以评审共识代替——这是"实测应拦输入才可称生效"（§6.1）在标准层面的直接延伸。

## 13. 风险与边界

1. **大模型幻觉风险**：参数修正量必须来自数值内核的输出，大模型只做编排与解释，不得"凭感觉"改参数；所有修正量附带不确定度。
2. **感知证据被缓存/过期污染**：证据必须带时间戳与内容哈希，跨时刻比对前核对新鲜度。
3. **开放世界参照的精度上限**：日常物自标定只用于低精度复查，不得替代 L0 基准标定。
4. **声学环境假设**：混响、多声源会劣化时延估计；强噪声场景降级为电子同步。
5. **安全边界**：涉及人身与贵重设备的动作永远走人工确认闸，便利性不得凌驾于安全。
6. **权限与隐私**：持续音视频监听需要明确授权边界与数据保留策略。
7. **协议安全边界**：编码层只提供识别、不提供防伪；开放环境中的防伪依赖语义层签名、组合层几何互证与物理访问控制（第 10 章 Q11），不得单独依赖靶标 ID 做安全决策。

## 14. 结语

真实世界的校准难，不在数学，而在成本。本方案的立场是：保留成熟的数值标定内核，用标准标定图案体系（第 9 章）把"已知答案"低成本地布满物理世界，用多模态大模型压缩感知、编排、发现、判定四个环节的人力与时间成本，用分层架构与探针实测保证每一次校准可信，最终把校准从"专家仪式"变成"系统的日常生理活动"——持续感知、持续对齐、漂移自愈。

其出口形态是一个经过验证的开放标准：以第 10 章的拷问清单闭合设计缺口，以第 11 章的八项量化门槛完成实测验证（门槛全过才可宣称"验证通过"），再按第 12 章的两步路线走向标准化——先以"规范 + 参考实现 + 一致性测试套件"立住事实标准，后提交正式标准组织。
