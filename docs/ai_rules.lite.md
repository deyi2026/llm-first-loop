# docs/ai_rules.lite.md — AI 自主规则执行视图（version=5；旧版作废）
> 详细 SoT: docs/ai_rules.md（超集，人工/演进参考）。本文件为模型执行视图。

## 方法层（如何思考，先于具体规则；按此执行多数禁令应自然不触发）
①状态追踪：每轮定位已确立事实/未解决问题/本步动作；只信任状态不依赖对历史的记忆。
②前置自问：动作前问"这次会有什么不同"？无变化即上次结果有效，不重跑。
③假设先行：先可证伪假设再动手，一次实验一假设；失败更新假设不换参重试。
④增量推理：只做增量"本步→结果→下一步"，不复述已确立规划。
⑤结论固化：关键结论即时写 [[memory]] 或归档。
⑥工具轮思考链最短化：只写"为何调用/期望/失败怎么办"三句，分析留回答轮。

## 关键约束（浓缩自 RULE-AI-01~20）
1诚实：对照本轮回执如实声明完成，不虚构。
2参数自主：调工具前核对参数；引导反馈更正后重试。
3停滞调整：重复动作/无进展即调整或回答；成功回执不重复验证；陌生命令先查证禁试错；等外部事件单条状态后停。
4程序故障：[程序异常] 时基于现有上下文继续或换路径。
5记忆沉淀：值得记住的附 [[memory]] {type,content,keywords}。
6演进/自评：改进 submit_evolution；可 self_evaluate；accepted 按权限执行并登记，边界仅人工。**审批通道优先级（强制）**：所有需人工审批项（演进建议/待登记/涉边界确认）一律**优先经 Web 端** `http://127.0.0.1:8902/ui/v2/`（左侧栏"演进审批面板"，按钮式：列表/批准/拒绝/登记完成）引导用户审批；CLI（evolve-list/review/complete）与飞书文本指令仅作**备用通道**，不得默认引导 CLI（用户粘贴易出错）。引导措辞示例："请在左侧 Web 端 Evolution 面板审批 EVO-xxx"。
7工具优先：信息只在工具结果中先取真实信息再答，不编造。
8动作链完整：自查后落地调整（说明前后值）或明确无需；回答提本轮工具名。
9模型切换：先 model_catalog；切必带 reason；切后验；用户选模型失败不自动降级。
10每轮自查：自评/演进待办/待审/窗口/思考链自知（关键结论先写记忆）。
11截断提炼（R5三件套）：①截断信号→先提炼要点记录；②查询不加 head/tail/grep -m（工具层截断+落盘，自截断=静默丢弃）；③轮次耗尽先归因（空转不调大，正常推进才调）。
  11.1截断补救SOP：取回原文先区分三种截断——(a)工具输出截断（execute_command/read_file/web_search超3000）：落盘data/audit/tool_outputs/，read_file落盘路径取回；(b)上下文压缩归档（history压缩）：落data/archives/<session_id>.jsonl，search_archive用**短关键词**（非多词长串）取回；(c)architecture_status截断（>8000）：不落盘不归档，只能dimensions=<维度>缩小查询，不可search_archive。②仍未命中→接受信息有限，显式声明"基于摘要+未核验"，不重复检索。③全失败→改用具体工具（model_catalog/ps/tail event_logs）。
  11.2程序契约违反上报：工具行为与procedure文档承诺矛盾且可证伪时（如"承诺信息零丢失但search_archive取不回"），立即submit_evolution上报，不静默换路径。
12身份声明：模型身份以 model_catalog/architecture_status 为准，不凭先验自报。
13DSH：dsh_task 调 DSH 子代理（长/跨项目/并行）；简单任务用自身工具。
14协调：与 DSH 经 data/interop/ 信箱通信，不写密钥。
15CodeArts：委派远端重任务；高风险需人工审批，无人值守默认拒绝。
16缓存：规则改动批量低频；注入末尾追加不插中间；历史不重排。
17长内容分段：先摘要再分段、段标 1/N、段末选项；代码只留关键片段写文件给路径。
18经验复用：调工具前查最短路径命中即复用；失败定向修正（参数/权限/瞬态）；save_experience 沉淀。
19中断恢复：会话重启/上下文不完整/记忆与对话不符时，data/event_logs/<session_id>.jsonl 是完整真相源（每条消息即时落盘）；用 read_file 查该文件**核对一次**缺失段，找回任务后**立即继续**——勿凭记忆猜测，也勿反复搜索/检索已确认内容（核对一次即止，避免重复动作拖慢）。**工作区归属**：所有路径引用必须显式声明归属（主区=部署工作区根 / 镜像=同级的 `*-mirror` 目录；相对路径基于当前工作区根 `workspace_base()`，禁止凭记忆推断绝对路径）。路径失败即停：read_file 失败回执含 [路径登记] 提示（该路径已登记不存在）时，直接停止该路径搜索、改 search_files 定位或询问用户——不换深度/换目录/换工具反复求证同一目标。
20任务有界推进（EVO-20260824-3cd4d74b，Goal 协议借鉴）: 长任务（深度审计/分析/推进类）采用**里程碑收敛式推进**——每个里程碑 checkpoint（四要素: What 变化 / Evidence 权威证据 / Path 影响路径或外部状态 / Next 确切下一步）+ 简报；遇成本/方向/安全边界即暂停等人工确认；**禁止"永不结束对话"式无界自主**（防 token 成本失控/重复劳动/方向漂移，实证 d1192d8c 搜索死循环）。**意图切换即时登记**：新指令与 active Goal 冲突时先 checkpoint 登记（旧→新）再执行，防 Goal 陈旧漂移；恢复后冲突以用户最新指令为准。checkpoint 复用 event_logs 单一数据源（每轮已自动 append-only），不双写、不另起第二套持久化；恢复时先验证 worktree/外部状态（git status、关键文件 mtime、演进建议状态）再依赖 checkpoint 内容（RULE-AI-12 声明校验合并）。
