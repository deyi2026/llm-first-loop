# WG 决议单 G3｜级间位姿差阈值

- 单据编号：WG-RES-〔YYYYMMDD〕-〔序号〕（占位，签发时填入）
- 对应规范条目：F-3（一致性校验与「带错硬接」禁令）
- 提案出处：PROP 0.2 §G3（第 44–51 行）
- 是否依赖实测：依赖实测——[TBD-FB]（回退率上限，P2 台架回退率实测，见 SPEC §14）；k 终值由 V8 注入故障集（1000 故障样本，PROP 第 48 行）验证，V8 只验证不校准
- 状态：待裁决

## 1. 事项

决定 F-3 阈值的形态与终值：阈值 = k × RSS(相邻两级 C-5 声明不确定度) 中 k 取多少，第二约束回退率上限 [TBD-FB] 定在哪里。

## 2. 选项与影响

| 选项 | 内容 | 代价/风险 |
|---|---|---|
| A) PROP 决策规则 | k × RSS，k 取满足「1000 故障样本带错硬接 = 0」的最大 k，并同时满足回退率 ≤ [TBD-FB] | 阈值随不确定度声明自适应；需两轮实测定值（V8 + 台架回退率），P2 尾段才能收口 |
| B) 取最小 k（PROP 第 49 行已否决） | 看似更保守 | 退化到 0.5 粒度下限，阈值 ≈ 0、回退率接近 100%，规则不可识别 |
| C) 固定常数阈值（PROP 第 51 行禁止） | 无需不确定度声明 | 同一阈值对高低精度读码器不等权，违反 F-3 与 C-5 的一致性前提 |

## 3. 建议（非决议）

只定规则，数值由实测回填。规则取自 PROP 第 46–50 行：

1. 阈值必须定义为 k × RSS(相邻两级不确定度声明)，不确定度取两级各自 C-5 声明值；
2. k 初值 = 2（v0.9.2 已冻结为规范默认值，见 SPEC F-3）；终值取满足「1000 故障样本中带错硬接 = 0」的最大 k，并同时满足回退率上限 ≤ [TBD-FB]；
3. 阈值修订一律走 SPEC VC-1 变更流程，V8 回执不得反向改写阈值；
4. 禁止脱离不确定度声明的固定常数阈值。

## 5. 若不采纳/延后

- 后果：阈值停在 k = 2 默认值，回退状态机可照默认值运行；但「带错硬接 = 0」在 k 终值与 [TBD-FB] 未定时不可计算，V8 回执无法判定达成与否。
- 阻塞：C4（V8 故障注入）、C9（数值回填），并使 P2 出口门（PLAN §9，表中编号 G4「数据齐 + 回填决议」）不能闭；不阻塞 B1–B4 开工。
