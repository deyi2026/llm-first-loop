# WG 决议单 G7｜最小可读条件阈值

- 单据编号：WG-RES-〔YYYYMMDD〕-〔序号〕（占位，签发时填入）
- 对应规范条目：C-4（C-4a 可见角点数 [TBD-V4a] 与数据位可见比例 [TBD-V4b]；C-4b 双向约束）
- 提案出处：PROP 0.2 §G7（第 74–78 行）
- 是否依赖实测：分两段——角点数（[TBD-V4a]）不依赖实测，可在首次工作组会议裁决（PROP 第 83 行）；数据位可见比例（[TBD-V4b]）依赖 V4 双向判据实测（PROP 第 78、83 行）
- 状态：待裁决

## 1. 事项

决定 C-4a 两个必要条件各自的取值口径：可见角点数下限，与数据位可见比例下限。

## 2. 选项与影响

| 选项 | 内容 | 代价/风险 |
|---|---|---|
| 角点数 ≥ 6（PROP 提案，第 77 行） | 共面靶标仅 4–5 个可见角点时，平面 PnP 存在两个位姿解，可能输出「看起来达标」的错误位姿 | 压缩检测距离（PLAN §10 R-05 已登记该风险），P2 前须用读码器实测歧义率回填 |
| 角点数 4 + 强制二义消解（PROP 列出的替代口径，第 77 行） | 保留 4 点下限的检测距离 | 读码器必须多解时按不可读处理，并新增「低角点数姿态歧义率」实测项 |
| 比例：V4 通过区间上确界向下取整、归整到 5% 粒度（PROP 第 78 行） | 归整方向永远向安全侧，符合 C-4b「宁可漏检，不可错读」 | 只能由 V4 数据定值；须同时守住 C-4b-2 漏检上限，防止「永不输出」平凡通过 |
| 比例：压低可见比例换取误读 = 0（PROP 第 78 行已排除） | 表面上误读可控 | 直接激励「永不输出」退化实现，违反 C-4b-2 |

## 3. 建议（非决议）

角点数：PROP 提案 = 6（第 77 行）；此项不依赖实测，可当场裁决。

比例：只定规则，数值由实测回填——取 V4 双向判据（误读率 = 0 且漏检率 ≤ [TBD-V4c]）通过区间的上确界向下取整，保守侧归整到 5% 粒度（第 78 行）。
