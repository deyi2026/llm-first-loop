# WG 决议单 G2｜强制码族选择

- 单据编号：WG-RES-〔YYYYMMDD〕-〔序号〕（占位，签发时填入）
- 对应规范条目：C-2（C-2a 码族与纠错）
- 提案出处：PROP 0.2 §G2（第 34–42 行）
- 是否依赖实测：不依赖实测（初值可裁）——强制族可在首次会议裁决；tagStandard41h12 的引入须先完成 V2/V4 双族对比实测（PROP 第 38、83 行）
- 状态：待裁决

## 1. 事项

决定 v1.0 的强制码族，以及高密度族 tagStandard41h12 以何通道、在何前提下引入。

## 2. 选项与影响

| 选项 | 内容 | 代价/风险 |
|---|---|---|
| 36h11（强制族） | 587 个可用码字；生态与文献基线最广（PROP 第 36 行） | 数据密度低于 41h12；单板 ID 容量受 G1 分层映射约束 |
| tagStandard41h12 | AprilTag 3 官方推荐，数据密度更高（SPEC 12.1-a） | 检测距离略降，侵蚀 V2 工作区间下限与 V4 漏检边界（PROP 第 40 行）；须先过 VC-2 解耦 + VC-3 混合版本门禁 |

## 3. 建议（非决议）

PROP 提案：v1.0 强制族 = 36h11；tagStandard41h12 列为候选扩展族，经 VC-2 版本解耦 + VC-3 混合版本门禁后引入，引入前须完成 V2/V4 双族对比实测（PROP 第 38 行）。

取舍依据：门槛优先级 V4（误读率 = 0）＞ 容量；587 码字在分层映射（G1）下对单板足够（第 40 行）。反对意见登记：新部署方若需多于 587 个单板 ID，应走扩展族通道而非放大强制族，该需求由 VC-2 吸收（第 42 行）。
