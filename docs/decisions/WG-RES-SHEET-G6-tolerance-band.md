## 1. 事项

决定各公差参数的定带规则：上下界取自哪种分布、制造裕度留多少、认证样本能否参与落带判定。

## 2. 选项与影响

| 选项 | 内容 | 代价/风险 |
|---|---|---|
| A) PROP 决策规则 | 上/下界取批次抽检（不含认证样本）分布的 P2.5 / P97.5；制造裕度 ≥ 25% 带宽；认证样本只作 V6 基准，落带另要求距带边 ≥ 10% 带宽（第 67–71 行） | 定带样本与被验样本分离，V3 判据不自证；代价是需独立批次与留出批次（PLAN §5.3-F3：批次须 W8 前下单） |
| B) 认证样本参与定带（PROP 第 68 行已排除） | 省独立批次与样本量 | 自身参与定带再验证自身 → V3 判据恒真 |
| C) 要求认证样本距带边 ≥ 1/3 带宽（PROP 第 71 行已排除） | 内侧余量更足 | 按 m/(2+2m) 反算需 m ≥ 200%，裕度失去工程意义 |

## 3. 建议（非决议）

只定规则，数值由实测回填。规则取自 PROP 第 67–72 行：

1. 每个公差参数的规范带 = 独立批次抽检分布的截断分位 ± 预留制造裕度；
2. 上/下界取批次抽检（不含认证样本）分布的 P2.5 / P97.5（对应 ≈ 1.96σ）；
3. 制造裕度预留 ≥ 25% 带宽，覆盖批次间漂移；
4. 认证样本不作落带判据样本（只用于 V6 基准），仅要求落在带内且距带边 ≥ 10% 带宽；
5. 自洽性反算：m = 25% → 内侧 10%；m = 20% → 内侧 8.3%；
6. 落带验证用独立留出批次，判据见 SPEC 11.2-V3；数值以实测回执回填，禁止以「行业惯例」名义填数。
