# WG 决议单 G1｜前缀段 / 本地段位长

- 单据编号：WG-RES-〔YYYYMMDD〕-〔序号〕（占位，签发时填入）
- 对应规范条目：C-1（C-1a 前缀段段长与分配细则；C-1b 本地段段长；C-1d 分层映射）

- 状态：待裁决

## 1. 事项

决定 ID = 前缀段 + 本地段的两段段长与分配细则，以及 587 个可用码字下码内承载什么。

## 2. 选项与影响

| 选项 | 内容 | 代价/风险 |
|---|---|---|
| i) 分层映射 | 码内只放板内短索引（≤ 587），全局 ID 由注册表以板级（M-2/M-3）聚合解析 | 单码离线不能直接反解全局 ID，必须经 R-4 离线快照；快速阅读语义退化为「板级识别」（PROP 第 32 行） |
| ii) 大容量码族 | 改选或自造高密度族（如 tagStandard41h12 或更大自定义族）承载更长 ID | 牺牲纠错裕度（PROP 第 31 行）；与 G2 强制族裁决耦合，且须先过硬接版本墙 VC-3 |
| iii) 前缀由部署域物理上下文绑定 | 同一封闭产线内前缀隐含，码内不承载前缀 | 破坏跨机构互通，违反 C-1c（PROP 第 31 行） |

## 3. 建议（非决议）

PROP 提案：i）分层映射 + 48 bit 逻辑 ID——逻辑 ID = 前缀 16 bit（机构；跨机构互通时必须唯一分配或具备冲突检测）+ 本地 32 bit（域内唯一），合计 48 bit，与 IEEE OUI-48 量级对齐；码内物理承载为板内索引（10 bit 足够覆盖 587 码字），前缀与本地高段由注册表 + 板级几何登记（M-2）联合解析（PROP 第 28–30 行）。

只定结构、不定细则：段长数值与分配 / 冲突检测规则由本单与治理章程同次会议一并裁出；取得决议号前不得移除 C-1a / C-1b 的 [TBD-G]。
