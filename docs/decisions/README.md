## 如何使用

1. 每份单据独立成页，会前由召集人分发；「1. 事项」定位待决点，「2. 选项与影响」用于取舍。
2. 「3. 建议（非决议）」是 PROP 提案原文，可整体采纳、改采其他选项或延后，不得当作已生效结论。
3. 「4. 若采纳」是回填清单：裁决当场逐项勾选并填取值与决议号；「5. 若不采纳/延后」写明后果与阻塞任务。
4. 「6. 签字」三行角色齐全方为有效决议；姓名与日期当场填写，不接受事后补签。
5. 首次会议可裁三项（PROP 第 83 行）：G2 初值、G4、G7 角点数；G1 与治理章程同次会议；G3 / G6 / G7-比例 终值须等实测回执。

## 裁决流程

以下照抄 PROP 0.2「附：裁决流程建议」（第 80–84 行），不改写：

> 1. 决议编号格式：WG-RES-[YYYYMMDD]-[序号]；回填规范时**保留 [TBD-G] 编号并追加取值与该决议编号**，v1.0 定稿时统一清除标记，并记入第 15 章变更历史；
> 2. G4 / G7-角点数 / G2-初值 可在首次工作组会议上裁决（无实测依赖）；G1 需与治理章程（前缀注册细则）同次会议裁决；G3 / G6 / G7-比例 终值必须等实测回执；
> 3. 本建议稿修订随规范版本走（PROP-0.x），不单独发版。
