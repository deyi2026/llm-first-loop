# 预注册：方法卡变异器 vs 人工改写（30 组配对）

- 状态：**已冻结，尚未跑**（写完正文后才允许产生 results）
- 冻结日：2026-10-19
- 关联：`docs/ANALYSIS-20261019-rsi-self-improvement-requirements.md`（R1 变异空间、R2 外部裁判、R3 预算、R5 Goodhart 防护、R8 速率对照）
- 产物目录：`evals/methodcard_rsi_v1/`

## 1. 要回答什么

RSI 的第一层（L1）只允许"变异器提议 + 人工应用"。本实验判定：**缺陷驱动的确定性变异器，是否值得作为方法卡的默认改写入口**。

- **H1（效率）**：变异器臂达到同等 held-out 表现所需的人工分钟数显著更低。
- **H2（不劣）**：变异器臂的 held-out 通过率不低于人工改写臂（非劣界 −5 个百分点）。
- 不假设"变异器更好"；若更差，应当被本实验拒绝，而不是靠叙事掩盖。

## 2. 单位、样本与抽样

- 抽样池：`data/methods/*/METHOD.md`，冻结时 **1214** 张卡。
- 抽样脚本：`evals/methodcard_rsi_v1/sample_prereg_cards.py`，`seed=20261019`，分层 5 类 × 6 张 = **30 对**。
- 分层：F1 生效判定 / F2 完成态/验收 / F3 检索去重 / F4 补丁后验证 / F5 其他。
- 同层排序键：`sha256(card_id|seed)`，与目录名、修改时间无关，可复现。
- 冻结清单：`evals/methodcard_rsi_v1/prereg_v1_cards.jsonl`，sha256 = `c1e8c63b53389541a3de3aa263ffc0fcaab996485e6641c6b5afccf288366bae`（见 `PREREG-FREEZE.json`）。
- **排除规则（先于数据）**：仅当 (a) 卡片无法被 `parse_card` 解析，或 (b) 卡片正文 < 200 字符 时排除；排除后**不顺延补样**，按实际对数分析并在结果里列出排除项。不得因"结果不好看"排除。

## 3. 两臂操作规范

| | A 臂（mutator） | B 臂（human） |
|---|---|---|
| 起点 | 卡片原文 | 同一份卡片原文 |
| 动作 | `python3 scripts/method_mutator.py --card <METHOD.md> --ops dup,vague,unlinked_ver --allow-todo` 产出候选；人**只能**填 TODO、修被标出的缺陷，不得顺手重写其他段落 | 人从原文自由改写，可用任何编辑器/助手，但不得参考 A 臂产物 |
| 终点 | 人确认"可以了"即停 | 同 |
| 计量 | 人从"读原文"到"确认停止"的墙钟分钟数（含填 TODO 时间） | 同 |
| 记录 | `pair_id, arm, passed, total, minutes, tokens` 写入 `results.jsonl` | 同 |

约束：同一张卡的 A、B 两臂由**不同会话**完成，且 B 臂执行者看不到 A 臂的产物与缺陷清单；A 臂执行者不得预先看到 held-out 题面。

## 4. 评估（裁判在外部）

- 题库：`evals/methodcard_rsi_v1/heldout_v1.jsonl`，20 题（5 类 × 4），sha256 = `e7852e750bbaae1041f31b6e7678dcfd8b126ba855b333a07b9d171713213e42`，判分器 `grade_holdout.py`（`--verify-freeze` 校验；对不上直接退出 4）。
- 每题与卡片按 family 对齐：每张卡固定考其所属 family 的 4 题（共 20 题全用，只是分卡片子集）。题面与 checks 分离：解题者只拿到题面，checks 只进判分器。
- **盲法**：评分流程看不到 arm 标签；`results.jsonl` 的 arm 字段在分析脚本里才合并。判分器本身无状态、无 LLM。
- 已知偏差（写在此处，事后不得当新发现）：机械判分偏好"结构完整"，而 A 臂正是结构修复 → 可能高估 A 臂；因此主要终点用**行为题**而非卡片文本评分。

## 5. 预注册判据（不因结果改规则）

令 `Δ = 通过率(A) − 通过率(B)`（配对，每对权重相同）、`r = 中位分钟(A) / 中位分钟(B)`：

- **D1 SHIP_AS_DEFAULT**：95% bootstrap CI 下界 ≥ −0.05 且 `r ≤ 0.5`
- **D2 ADOPT_IF_BETTER**：CI 下界 > 0.05 且 `r ≤ 1.0`
- **D3 REJECT**：CI 上界 < −0.05
- **D4 INCONCLUSIVE**：其余

解释约定：D1/D2 只允许把变异器设为**默认候选生成器**（产物仍 `review_required=true`，人工应用后才入卡）；任何自动上线都不在本实验授权内。D3 则把变异器降级为 linter（`--check` 只报缺陷）。

## 7. 停止规则与偏离登记

- 固定 n=30，**无期中分析**、无 optional stopping。
- 跑不完（如时间不够）→ 报告已完成的配对数与"未完成"状态，不得用部分数据做 D1/D2 裁决。
- 任何执行偏离（改题、改算子、改判分器）必须在本文件末尾追加 `## 偏离登记` 段，写日期 + 原因 + 影响，并重新冻结 hash；**改完再跑的结果只能作探索性**。

## 8. 成本预算（R3）

- 单卡单臂 ≤ 25 分钟人工 + ≤ 60k tokens；30 对上限约 25 人时 + 3.6M tokens。
- 超预算即停，按 §7 报告为未完成。

## 9. 主要威胁

1. **题目量小**（20 题），单题噪声大；缓解：配对设计 + 固定题集，报告 CI 而非点估计。
2. **同模型解题**：两臂卡由同一执行者应用，可能引入"卡片风格"混淆；缓解：A/B 不同会话、盲评。
3. **判分器覆盖有限**：只测 5 类失败模式，不外推到全部 1214 张卡。
4. **Goodhart**：A 臂针对缺陷优化，题库若与缺陷同源则高估；缓解：held-out 题面独立编写（内联输入、不引用仓库现状），并保留 §5 的负向判据。

## 10. 与 RSI 分级的接口

本实验只回答 L1→（是否默认生成器）。升 L2（低风险自动应用）需要**另一次**预注册，且必须包含自动回滚演练的证据；本次结果不能作为 L2 的授权依据。
