# 决策：长任务上下文管理职责分离——TA 写权、CMA 建议权、程序执行权

> 状态: **已采纳（架构方向；用户 2026-09-25 01:29 终审授权并同意三项裁决点；实施未开始，P0 未立项）** | 依据: docs/DESIGN-20260925-context-management-role-separation.md（v1.0 终审通过，终审记录见其 §12）
> 关联: docs/DECISION-context-injection-tier-boundary.md（L1/L2/L3 红线来源，本决策全程不越）；docs/DESIGN-20260830-digest-bucket-architecture.md + docs/SDD-20260830-digest-bucket.md（分工边界硬接口约束）；docs/ANALYSIS-20260831-injection-stop-compression-handoff.md（压缩衔接病根依据）

## 0. 决策一句话

**意图在 TA（写权），视野在 CMA（建议权），暴力在程序（执行权）**：状态快照由 TA 写增量、CMA 审计规范、程序版本化存储（写/审/存三权分立）；压缩由程序水位/里程碑触发、CMA 建议、TA 否决、程序机械执行；上下文由程序装配发送（载体义务），L3 内容级语义选择权归模型（既有 DECISION 授权，不转移）。**触发权与发送权永不下放给任何模型。**

## 1. 决策项（规范性内容；细则以 DESIGN v1.0 为准）

1. **三角色分立**：TA=语义权威（快照写权、删除否决、L3 终裁）；CMA=语义工人（触发式、无状态启动、可用低档模型；跨条目语义去重建议、判别删除打分、快照审计、相关性标注——只建议不裁决）；Orchestrator=程序（触发、Evidence/快照版本化存储、L1/L2 必达注入、机械装配发送、结构化类别硬保护、审计落盘）。职责矩阵见 DESIGN §4.2。
2. **状态快照**：五字段 schema（invariants / facts_and_decisions / negative_knowledge / cursor+pointers / provenance）+ 类别保护优先级（DESIGN §5）。decision 必带 reason；negative_knowledge 未 resolved 不可删，唯一出口是 TA 显式 resolve，CMA 打分跳过该类别（结构硬保护，非语义判断）。
3. **管线顺序约束（不可调换）**：快照增量更新（TA，程序强制检查点）必须先于语义去重与判别删除——先给信息找结构化去处，再判历史可扔性；语义去重（区分有意/无意冗余，有意冗余判定权在 TA）先于判别删除；语义去重与判别打分为**同一次 CMA 调用的两个输出段**（每次压缩 1 次模型调用）。
4. **与 digest-bucket 分工（两条硬接口约束，违反即架构破损）**：快照不写入档案槽（保 append-only 前缀不变式），走注入层 L2 整块保留档；被删内容指针索引须兼容 DIGEST_ENABLED 两态。字段归属判别式：删掉后会让下一轮工具选择或终局判断出错的信息归快照，只影响复述完整性的靠档案槽。
5. **fail-safe 与保底**：打分缺失/失败默认 keep（删除错误代价不对称）；CMA 不可用或管线异常时程序回退内建摘要，不中断任务。
6. **可审计**：每次压缩"删了什么/为什么/谁裁决/依据哪条证据"落盘可回放；快照版本化可回滚；注入带语义标签防误读为新指令。
7. **指针优于内容**：被删内容以 Evidence ref 指针化（可重水合、有 provenance），不用文本截断替代。

## 3. 弃守线（决策自带可证伪边界，非永久承诺）

- **P1 门（CMA 成本）**：按 DESIGN §10 指标5 口径，CMA 边际净收益（vs P0 基线）≥0 才升默认；不过则 CMA 降为可选、P0 程序规则保持默认，方案本体（快照+指针化+顺序绑定）不动。量化前对 fast-jev 只主张成本非劣。
- **P2 出口门（快照质量）**：语义半漂移率 >5% 且不一致条目落在 invariants/negative_knowledge 保护类，或事实重建率 <95% 且归因于快照内容错误（非装配层漏注入），经一轮针对性修复复测仍不达标 → 放弃 TA 语义写层。**弃守后形态**：快照退化为程序生成的纯指针索引（放弃 D1 语义层，保留可程序执行的保护规则）；不是退回 fast-jev 式无状态——其兜底赌"可重跑"，外部状态已变时失效。
- **账单降级口径**：provider 账单拿不到 cache read/miss 拆分时，指标5 降级为原始 token 口径（净收益偏乐观）；降级数据只能支撑"不通过"结论，不足以支撑"通过"。

## 4. 裁决点记录（用户 2026-09-25 01:29 确认）

1. 语义去重与判别打分（③④）合并为同一次 CMA 调用的两个输出段——v0.4 评审引入的设计变更，确认采纳（每次压缩收敛为 1 次模型调用）。
2. 弃守线阈值维持：语义半漂移率 >5%、事实重建率 <95%（沿用既有目标值；实测可调，调整属参数变更非架构变更）。
3. cache 分账口径依赖账单数据可得性；降级路径已成文（DESIGN §10 指标5 末段 + 本决策 §3）。
