## 0. 本文件的读法（规范性前言）

0.1 规范性用语按 RFC 2119 语义以汉语表述：

- **必须 / 禁止**（MUST / MUST NOT）：一致性要求，违反即不合规；
- **应 / 不应**（SHOULD / SHOULD NOT）：强烈建议，偏离必须记录理由；
- **可以**（MAY）：可选。

0.2 占位标记：

- `[TBD-V*]`：数值空缺，依赖第 11.2 节门槛 V* 的实测结果填充；同一门槛的多个独立量拆分为子项（如 `[TBD-V4a]` 角点数 / `[TBD-V4c]` 漏检率上限）；
- `[TBD-<条目号>]`（如 `[TBD-P2a]`、`[TBD-M2]`、`[TBD-F2]`）：数值空缺，依赖该条目的计量实测数据填充；
- `[TBD-G]`：数值或方案空缺，依赖工作组裁决（需要决定，不需要实测）；其子项写作 `[TBD-V3α]`、`[TBD-FB]` 等形式，仍属裁决类。

**一个编号只承载一个物理量 / 一个判据**——禁止同一编号同时代表两种量纲（例如"角点数"与"可见比例"）。

填充流程：**填充时保留 TBD 编号，在其后追加取值与回执编号**（例：`[TBD-P2a] = 0.10 mm（WG-RES-2026xxxx-01）`）；仅在 v1.0 定稿时统一清除标记。每次填充必须附对应实测回执或工作组决议编号，并记入第 15 章变更历史。

0.3 本文件与设计文档的分工：设计文档回答"为什么"；本文件只保留"是什么、必须怎样"。设计文档中的背景论述、路线图、资源分工不在本文件范围内。

0.4 条目编号采用分层字母前缀：物理层 P-\*、编码层 C-\*、语义层 R-\*、组合层 M-\*、威胁模型 T-\*、回退状态机 F-\*、版本兼容 VC-\*。与设计文档 §10 旧编号 S1–S4 的映射见第 13 章（旧编号存在复用歧义，本规范不复用）。

## 1. 范围

1.1 本规范规定合作目标校准协议（CTP）的：

a) 物理层：靶标的制造与安装要求（第 4 章）；
b) 编码层：ID 空间、码族、版本位、最小可读条件与读取输出契约（第 5 章）；
c) 语义层：注册表记录、审计、墓碑与签名（第 6 章）；
d) 组合层：单靶 / 阵列 / 标定板笼室的几何一致性与投影模态（第 7 章）；
e) 跨层行为：威胁模型（第 8 章）、回退状态机（第 9 章）、版本兼容（第 10 章）、一致性与合规（第 11 章）。

1.2 本规范不规定：

a) 读码器检测算法的内部实现——任何满足 C-5 输出契约并完成第 11 章合规声明的实现均为合规实现；
b) 多观测融合与上层估计器（如 EKF）的行为；
c) 靶标粘贴 / 安装的施工工艺；
d) 传感器时基同步（见设计文档 §5 纪律 3，属设备侧例行动作）；
e) 安全决策逻辑本身——本协议只提供观测证据，安全边界见 T-3。

## 2. 术语与定义

| 术语 | 定义 |
|---|---|
| 靶标（target） | 按第 4–5 章制造的物理编码图案实体 |
| 读码器（reader） | 从图像中检出靶标并按 C-5 输出观测的软硬件实现 |
| 认证样本（certified sample） | 按 P-4 由计量实验室标定、用作一致性测试基准的靶标实体 |
| 注册表（registry） | 实现第 6 章记录结构的语义层数据服务（在线服务或离线快照） |
| 前缀（prefix） | ID 高位段，机构自治分配或公共注册，跨机构唯一 |
| 参考系定义（reference frame definition） | 靶标坐标系相对其所属对象坐标系的安装几何描述 |
| 公差带（tolerance band） | 物理层参数允许区间；带外制造不得引用精度声明（P-5） |
| 最小可读条件（minimum readable condition） | 编码层允许输出观测所需的最小图像证据阈值（C-4） |
| 降级（degradation） | 明确标注精度等级下降的受控运行模式，区别于失效 |
| 墓碑（tombstone） | 注册表中已报废 ID 的终态记录，不可复用（R-3） |
| 带错硬接 | 相邻层级证据矛盾时仍向更精细层级推进的行为，本规范禁止（F-3） |

## 4. 物理层（规范性）

P-1 光学与材质
a) 靶标表面必须为哑光；可见光（400–700 nm）下黑白区域漫反射对比度必须 ≥ [TBD-P1]；
b) 镜面反射分量不应产生可检测的镜面高光。

P-2 几何公差带
a) 角点边长制造公差：[TBD-P2a]；
b) 靶标平面度：[TBD-P2b]；
c) 安装（粘贴）平面度与贴合要求：[TBD-P2c]。

P-3 热学与参考温度
a) 靶标参考系定义必须绑定基准温度 T0 = 20 °C（依 ISO 1；[TBD-G] 待工作组确认）；
b) 常规靶标热膨胀系数必须 ≤ [TBD-P3a]，热形变必须纳入读出不确定度预算而非试图消除；
c) 认证样本应采用低膨胀材质。

P-4 认证样本
认证样本必须由具备计量能力的实验室标定，附证书（标定方法、设备、日期、不确定度），作为 V3 / V6 一致性测试的物理基准。

P-5 制造符合性
a) 公差带外制造的靶标禁止引用任何精度声明；
b) 声明公差等级的供应方必须附可核查依据（批次抽检报告或认证样本谱系）。

## 5. 编码层（规范性）

C-1 ID 结构：ID = 前缀段 + 本地段
a) 前缀段：**跨机构互通场景必须唯一**——或强制公共注册（参考 MAC OUI / ASN 模式），或提供等价互斥机制（保留号段 + 冲突检测 + 冲突时拒绝语义绑定）；仅限单一机构封闭域内可自治分配。段长与分配细则 [TBD-G]；
b) 本地段：域内唯一性由持有前缀的机构负责；段长 [TBD-G]；
c) 跨机构互通必须且只需前缀唯一（Q9 裁决）；前缀唯一性是分配权威的属性，不以码内是否承载前缀决定；
d) 码内物理容量（如 36h11 仅 587 个可用码字）可能不足以承载全长 ID：此时按分层映射，码内只承载板内 / 域内索引，逻辑 ID 由 R-1 注册记录解析（见 C-5 的 target_index / logical_id）。

C-2 码族与纠错
a) **在 [TBD-G] 裁决前，强制码族暂定 AprilTag 36h11**（36 位、最小汉明距离 11、可纠正 ≤ 5 位错误；官方图库可用码字 587 个，见 12.1-a）；最终选择 [TBD-G]（候选另含 tagStandard41h12，数据密度更高、检测距离略降，见 12.1-a），裁决后按决议更新本项；不允许出现"必须指定而尚未指定"的空档；
b) 解码必须在纠错能力内进行；超出纠错能力的码字按 C-4 处理（不输出）。

C-3 版本位
a) 图案必须携带版本字段；
b) 读码器遇到未知版本必须输出"不可读（unknown version）"，禁止猜测或降级解释为任何已知 ID；
c) 新图案族版本的发布必须通过 V7 混合版本测试（VC-3），不达标组合不得发布。

C-4 最小可读条件
a) 输出观测的必要条件：可见角点数 ≥ [TBD-V4a]（个）且数据位可见比例 ≥ [TBD-V4b]（%）；
b) 低于阈值时读码器必须不输出——宁可漏检，不可错读（对应门槛 V4）；
**b-2) 达标侧同样受限**：条件达标样本的漏检率必须 ≤ [TBD-V4c]，样本量 N ≥ [TBD-V4d]——只禁错读而不限漏检，等价于激励"永不输出"这一退化实现；
c) 到达阈值前的劣化预警属健康监测（设计文档 §9.6），不属本层强制行为。

C-5 读取输出契约
一次合规读取必须输出以下字段，缺一即不合规：

| 字段 | 内容 |
|---|---|
| target_index | 码内实际承载的索引值（板内 / 域内；单码可离线读出） |
| logical_id | 全局逻辑 ID（前缀 + 本地）；需经 R-1 / R-4 解析时可为空，但必须在 resolution 中标注 |
| resolution | 解析状态：`code`（码内即全局 ID）｜`resolved`（经注册表解析）｜`unresolved`（离线且无快照） |
| pose | 6DoF，附参考帧定义引用 |
| uncertainty | 平移 / 旋转不确定度；模型由实现方按 11.1 声明，**必须同时给出覆盖因子 k 与 1σ 值** |
| degradation_flag | 降级标记：`none`｜`coarse`（如投影前提不满足，M-5b）｜`quarantine`（R-6 超期隔离） |
| timestamp | 图像采集时刻 |
| reader_id / reader_version | 读码器身份与版本 |

附加要求：
a) 观测是"测量 + 不确定度"，不是真值；协议不裁决"谁对"，多观测融合交给上层估计器（Q6 裁决）；
b) 一致性要求：两个合规读码器对同一认证样本的位姿差 ≤ k·√(u₁²+u₂²)，k 取双方声明覆盖因子的较小者（与 C-5 uncertainty 声明一致；门槛 V6）。

## 6. 语义层（规范性）

R-1 注册表记录必须至少包含：ID、所属对象、参考系定义、安装日期、上次验证时间、复验周期、记录版本、签名。

R-2 变更审计：注册表变更必须 append-only；禁止物理删除或原地改写历史记录（与设计文档 §6.3 同构）。

R-3 墓碑：报废 ID 必须进入墓碑状态；墓碑 ID 禁止复用（防旧设备误读，Q12 裁决）。

R-4 离线快照：注册表必须支持带版本与签名的离线快照，快照可在无网络环境下独立校验。

R-5 签名验证：使用 ID 的语义绑定时必须校验注册记录签名；查无对应签名记录的 ID，必须拒绝其语义绑定（防伪第一级，见 T-4a）。

R-6 复验周期：记录的"上次验证时间 + 复验周期"由健康档案驱动；超期记录应标记"待复验"，其观测不应用于高精度决策。超期处置的强制等级 [TBD-G]。

## 7. 组合层（规范性）

M-1 单靶：提供 6DoF 单点观测。单靶观测不应作为唯一证据用于安全决策（见 T-3）。

M-2 三靶阵列
a) 阵列必须在注册表登记成对几何关系（距离、夹角）及其公差 [TBD-M2]；
b) 读码器或上层必须执行几何互证：实测几何关系与登记值偏差超公差 → 按 F-3 回退并报警（防伪第二级，见 T-4b）。

M-3 标定板 / 标定笼：板级、笼级组合的几何一致性要求按 M-2 递归适用（每个被登记的成对关系都互证）。

M-4 标定室：全参数基准设施；可以不作为协议合规要求（超出互换性范围）。

M-5 投影模态（可选）
a) 投影生成的临时图案必须满足编码层全部要求（C-2 / C-3 / C-4）；
b) 投影前提（投影面平面度、对比度、投影畸变校正）必须作为运行时自检项；前提不满足必须判"粗对齐"并显式打降级标记，禁止混入毫米级通道（Q5 裁决，门槛 V5）。

## 8. 威胁模型（规范性）

T-1 保护资产：定位真值的可信性；注册表完整性与谱系；基于靶标观测的决策链。

T-2 对手模型：

| 级 | 对手能力 | 典型动作 |
|---|---|---|
| D1 物理替换 | 能在物理空间粘贴 / 替换靶标 | 复制 ID 的伪造靶标 |
| D2 数据投毒 | 能写注册表或其快照分发链 | 注入伪造记录、投毒快照 |
| D3 信道篡改 | 能篡改在线查询应答 | 中间人替换应答 |

T-3 安全边界（显式声明）：编码层提供识别，不提供防伪。任何实现禁止单独依赖靶标 ID 做安全决策；涉及安全的决策必须叠加 T-4 至少一级防伪或独立安全通道（Q11 裁决）；开放环境按 T-4d 执行——T-4d 为本条加严子条款，不适用"独立安全通道单独满足"。

T-4 防伪三级：
a) 语义层签名（对 D1 / D2）：见 R-5；
b) 组合层几何互证（对 D1）：见 M-2；
c) 物理访问控制（对 D1）：封闭产线场景天然具备；
d) 开放环境部署必须至少实现 a + b，并留存风险评估记录。

T-5 信道防护（对 D3）：在线注册表查询必须走可校验通道（传输加密 + 记录签名核对），或必须使用 R-4 离线快照。

T-6 残余风险登记（资料性）：签名私钥泄露、阵列整体复制、认证样本被盗用——记录之，不承诺消除；缓解与响应预案属治理文档范围。

## 9. 回退状态机（规范性）

F-1 状态集：FAR（场景级）→ MID（编码图案）→ NEAR（精细阵列）→ CONTACT（伺服级）；全局终态 STOP。

F-2 交接条件（进入下一级的必要条件，全部满足方可推进）：

| 交接 | 必要条件 |
|---|---|
| FAR → MID | 靶标进入视野且 ID 校验通过（C-3 / C-4） |
| MID → NEAR | 阵列 / 高密度大板可见；角点亚像素残差 ≤ [TBD-F2]（像素；与 V2 的 mm/deg 精度口径分离） |
| NEAR → CONTACT | 力 / 触觉传感器就位；标定板平面度自检通过 |
| CONTACT 内部推进 | 接触力进入期望窗口；力曲线形状符合预期 |

F-3 一致性校验与"带错硬接"禁令：阈值为 k × RSS(相邻两级 C-5 声明不确定度)，k 初值 2（v0.9.2 冻结为默认值，见 PROP G3）；相邻两级位姿差 > 阈值时必须回退上一级并报警；禁止在层级证据矛盾下向更精细层级推进。**V8 只验证该阈值能否达成"带错硬接 = 0"，不反向校准阈值**；阈值修订走 VC-1 变更流程并记入第 15 章。

F-4 各级失败出口：
a) FAR 失败：重试 N 次（1 ≤ N ≤ 3；N 与单次超时预算必须在 11.1 合规声明中公开）后 → STOP；
b) MID / NEAR 失败：回退上一级；上一级亦失败则逐级回退至 FAR，再失败 → STOP；
c) STOP = 停止 + 报警 + 人工介入；禁止"默认通过"出口（Q7 裁决：每级都有失败出口，最底层出口显式定义为 STOP）。

F-5 状态图（资料性）：

```
[FAR] --ID 校验通过--> [MID] --阵列可见·残差达标--> [NEAR] --力觉就位--> [CONTACT]
  ^                      |                             |
  |   位姿差超阈 / 读取失败（逐级回退）                 |
  +----------------------+-----------------------------+
  任一级重试耗尽 --> [STOP：停止 + 报警 + 人工介入]   （无"默认通过"出口）
```

## 10. 版本与兼容（规范性）

VC-1 规范版本号采用 MAJOR.MINOR；MAJOR 变更必须保留旧图案族可读性或附显式废弃流程（含存量迁移期）。

VC-2 规范版本与图案族版本解耦：一个规范版本可以承载多个图案族版本（C-3 版本位承载族版本）。

VC-3 发布门禁：任一新旧版本组合必须通过 V7（混合版本靶标墙对旧版读码器误读 = 0）方可发布；不达标组合不得发布，无豁免通道（Q8 裁决）。

## 11. 一致性与合规（规范性）

11.1 合规声明：读码器实现方必须公开声明：
a) 支持的码族与版本；
b) 精度—条件曲线（距离 / 入射角 / 光照；附方法与数据来源；实测前禁止给出数字）；
c) 不确定度模型（对应 C-5）；
d) 时延分布（对应 V1）；
e) 最小可读条件实现值（对照 C-4 阈值）。

11.2 门槛表（原样纳入设计文档 §11.2，作为一致性测试判据；以下数字在实测前均为待验证目标，不得对外宣称已达成）：

| 编号 | 门槛 | 判据 |
|---|---|---|
| V1 | 自检时延（可用性指标，**非合规判据**） | 全流程 P95 < 100 ms；超时降级为逐靶串行并报告，不判失效。本项不参与合规判定，只作 11.1-d 声明与 V8 期望行为输入 |
| V2 | 定位精度 | 合作通道在 0.2–2 m、入射角 ±60°、规定光照内：平移 ≤ 2 mm (3σ)、旋转 ≤ 0.5° (3σ)。不确定度声明必须同时给出 k 与 1σ 值（C-5） |
| V3 | 公差带 | 规范带按 G6 由**独立批次抽检**分布的 P2.5 / P97.5 加 ≥25% 带宽裕度确定；随后用**独立留出批次的抽检样本**验证落带：带外率 ≤ [TBD-V3α]，样本量 N ≥ [TBD-V3β]。认证样本只用于定带与作 V6 基准，**不得自证落带**（自身参与定带再验证自身，判据恒真） |
| V4 | 降级行为 | 双向判据：① 低于 [TBD-V4a] / [TBD-V4b] 的样本误读率 = 0；② 条件达标样本漏检率 ≤ [TBD-V4c]（N ≥ [TBD-V4d]）。"永不输出"必须判为不通过 |
| V5 | 投影标定 | 前提自检不满足时必须判"粗对齐"并打 degradation_flag = `coarse`（C-5）；"混入毫米级通道"定义为：该观测被 F-2 用于 NEAR 交接、或计入 V2 精度统计——实现必须以 degradation_flag 支撑该判据，无标记即判不通过 |
| V6 | 跨厂商一致性 | 两个合规读码器对同一认证样本位姿差 ≤ k·√(u₁²+u₂²)（k 与 C-5 声明一致）；重复 N ≥ [TBD-V6a] 次，通过率 ≥ 95% |
| V7 | 版本兼容 | 混合版本靶标墙对旧版读码器误读 = 0 |
| V8 | fail-closed | 注入 1000 个故障样本，按类型分派期望行为：**漏检类**（遮挡 / 超纠错码字 / 贴歪不可读）→ 不输出 + 计数上报（禁止静默）；**伪造 / 层级矛盾类**（错 ID、复制靶标、级间位姿矛盾）→ STOP + 报警。两类均要求"带错硬接" = 0 |

验证纪律：门槛未达标时修订设计或规范，不得放宽门槛；确需放宽必须记录证据与理由。

11.3 一致性测试大纲：
a) 软件测试：混合版本墙（V7）、降级行为（V4）、注入故障集（V8）；
b) 物理测试：批次抽检落带（V3）、跨厂商一致性（V6）；认证样本仅作 V6 基准与定带输入；
c) 计量测试：精度—条件曲线（V2）、时延分布（V1）、投影前提曲线（V5）；
d) 测试结果必须以全量实测回执归档；评审共识不构成"验证通过"。
