## G1 前缀 / 本地段位长（C-1）

**约束（硬）**：36h11 单码仅 587 个可用码字（≈ 9.2 bit 信息量）。任何"前缀段 + 本地段"全长超过码族容量的方案都无法在单码内物理承载，这是 C-1 与 C-2 的结构性耦合。

选项：
- i) **分层映射**：码内只放"板内短索引"（≤ 587），全局 ID 由注册表以板级（M-2/M-3）聚合解析；
- ii) 大容量码族：改选或自造高密度族（如 tagStandard41h12 或更大自定义族）承载更长 ID；
- iii) 前缀由部署域物理上下文绑定（同一封闭产线内前缀隐含）。

**提案：i）分层映射 + 48 bit 逻辑 ID**。
- 逻辑 ID = 前缀 16 bit（机构；跨机构互通时必须唯一分配或具备冲突检测）+ 本地 32 bit（域内唯一），合计 48 bit，与 IEEE OUI-48 量级对齐；
- 码内物理承载：板内索引（10 bit 足够覆盖 587 码字），前缀与本地高段由注册表 + 板级几何登记（M-2）联合解析；
- 依据：587 码字实测事实使 ii) 牺牲纠错裕度、iii) 破坏跨机构互通（违反 C-1c）。
- 已接受代价（须记录）：单码离线不可直接反解全局 ID，必须经 R-4 离线快照；快速阅读语义退化为"板级识别"。

## G2 强制码族选择（C-2）

选项：36h11（587 ID，生态与文献基线最广）vs tagStandard41h12（官方推荐、密度更高、检测距离略降）。

**提案：v1.0 强制族 = 36h11；tagStandard41h12 列为候选扩展族**（经 VC-2 版本解耦 + VC-3 混合版本门禁后引入，引入前须完成 V2/V4 双族对比实测）。

依据：门槛体系优先级是 V4（误读率 = 0）＞ 容量——检测距离下降直接侵蚀 V2 工作区间（0.2–2 m）下限与 V4 漏检边界；587 码字在分层映射（G1）下对单板足够。

反对意见登记：新部署方若需要 >587 单板 ID，应走扩展族通道而非放大强制族；该需求由 VC-2 吸收。

## G3 级间位姿差阈值（F-3）

**决策规则（非数值）**：阈值必须定义为 k × RSS(相邻两级不确定度声明)，其中：
- 不确定度取两级各自 C-5 声明值；
- k 初值 = 2（v0.9.2 冻结为规范默认值，见 SPEC F-3）；终值由 V8 注入故障集**验证**：取满足"1000 故障样本中带错硬接 = 0"的**最大** k，并同时满足回退率上限 ≤ [TBD-FB]（第二约束）。
  理由：k 越大阈值越宽、越易漏拦，零带错约束集在 k 上向下封闭——取"最小 k"会退化到 0.5 粒度下限，使阈值 ≈ 0、回退率接近 100%，规则不可识别；
- 阈值修订一律走 SPEC VC-1 变更流程，V8 回执不得反向改写阈值；
- 禁止脱离不确定度声明的固定常数阈值（否则同一阈值对高低精度读码器不等权）。

## G4 T0 = 20 °C 确认（P-3）

**提案：确认 20 °C**。依据：ISO 1:2016 现行有效，20 °C 自 1931 年 CIPM 起为全球几何量计量统一参考温度；与本规范"绑定计量体系"立场一致。注：这是参考系定义，不是工作温度声明——工作温度范围属各实现方精度—条件曲线（11.1-b）。

## G5 R-6 超期处置强制等级（R-6）

**提案：两级处置**：
- 一级（现状文本保持）：超期 → "待复验"，观测可用但禁止进入高精度决策；
- 二级（新增）：超期持续 ≥ 2 × 复验周期 → 强制隔离态——观测仍可输出，但必须带 quarantine 标记，禁止语义绑定（R-5）与几何互证参与（M-2），且注册表应将该记录标记为"墓碑候选"。

依据：与 R-3 墓碑机制衔接，防止"永远待复验"的僵尸记录持续污染决策链；T-4b 防伪链条依赖注册表健康度。

## G6 公差带各项数值（P-1 / P-2 / P-3-b / M-2）

**决策规则（非数值）**：每个公差参数的规范带 = **独立批次抽检**分布的截断分位 ± 预留制造裕度：
- 上/下界取**批次抽检（不含认证样本）**分布的 P2.5 / P97.5（对应 ≈ 1.96σ；认证样本参与定带会使 V3 判据恒真）；
- 制造裕度预留 ≥ 25% 带宽（覆盖批次间漂移）；
- 认证样本不再作为落带判据的样本（只用于 V6 基准），仅要求**落在带内且距带边 ≥ 10% 带宽**；
- 自洽性反算：裕度 m 时，P97.5 处的抽检样本距带边占带宽比例 = m / (2 + 2m)。m = 25% → 10%；m = 20% → 8.3%。若要求内侧 ≥ 1/3 带宽，需 m ≥ 200%（使裕度失去工程意义），故本条采用 m ≥ 25% + 内侧 ≥ 10% 的组合；
- 落带验证用**独立留出批次**，判据见 SPEC 11.2-V3；所有数值以实测回执为准回填，禁止以"行业惯例"名义填数。

## G7 最小可读条件阈值（C-4）

**决策规则**：
- 角点数阈值：提案 = 6。共面靶标仅 4–5 个可见角点时，平面 PnP 存在两个位姿解（planar pose ambiguity），可能输出"看起来达标"的错误位姿，违反 C-4b"宁可漏检、不可错读"；若坚持 4 点下限，读码器必须强制二义消解（多解时按不可读处理），并新增"低角点数姿态歧义率"实测项；
- 数据位可见比例：取 V4 双向判据（误读率 = 0 且漏检率 ≤ [TBD-V4c]）通过区间的**上确界向下取整**（保守侧归整到 5% 粒度）；宁可漏检、不可错读（C-4b）决定归整方向永远向安全侧——注意 V4 已禁止"永不输出"平凡通过，阈值不能靠压低比例来满足误读约束。
