## 3. 设计决策

### E-D1 E07 auto memory 退出 → RETRIEVABLE_ONLY（总审计 P0-7）

- memory producer 的自动投影删除（fact/procedure 的 current-turn 自动检索取消）；
- 恢复路径三条：
  1. 用户显式指代（"按我之前的 X""你记得 Y 吗"）→ input-side retrieval 授权**一次**；
  2. 模型主动需要历史 → `search_records(kind=memory)`（E7 实证已有使用先例）；
  3. 维护场景 → playbook（A 包重定位后的 ai_rules.lite）指引的显式查询；
- 不再用 current turn / semantic similarity 作为自动 prompt grant；
- 不把 memory 嵌入 Cognitive packet 作为旁路（与 E-D4 联合关闭）。

### E-D2 E08 TIP replay 退出

TIP（turn-internal program）回放通道关闭；TIP 内容如有保留价值落 retrieval plane。验收含"resurrection=0"断言（防止以新 producer 名义复活）。

### E-D3 E35 compact anchor 退出

压缩锚点不再作为模型可见语义注入；压缩属物理管理（B 包 E17 机制面），anchor 不承载任务身份。

### E-D4 Cognitive enforce 冻结重设计（总审计 P1-11）

当前阶段：

- 只保留 `off/shadow` 做测量；
- **禁止 session allowlist 自动 promote 到 model-visible enforce**（现有 allowlist 机制冻结）；
- 现网 enforce 会话降级 shadow。

未来恢复的必要条件（缺一不可，全部满足才可重新设计启用）：

1. 显式 user-authorized continuation（用户明确授权延续）；
2. 无 current memory 自动进入 packet；
3. 无 quiet / header-only 注入（一切注入可观测、可归因）；
4. 只允许一条 canonical current-task channel，不与 `task_active` / compact anchor 并存（通道唯一性）；
5. 重新走独立设计审批（不属于本包范围）。

### E-D5 task_active：ACTIVE_STATE → USER_AUTHORIZED_STATE（总审计 P1-7）

- 用户明确"继续/接着/恢复上次任务"时，由 **input-side resolver 授权一次**；
- 本 run 内冻结该 task identity（`goal_id + task_id + title`），不动态变化；
- 普通新问题不自动读取 Goal；
- Goal 只作为 retrievable state（§2.3）；
- ambiguous state 继续零注入；
- 与 B 包接口：B-D6（E18 硬边界结束/暂停，等用户继续）的用户"继续"指令即本 resolver 的触发源。

### E-D6 CORE9 A/B 再决定（总审计 P2-1，收编 tasks.md E1）

实验设计：

- 三方案：①9 工具现状；②缩减实验组（universal core 是否只需 `get_tool_schema` + 最少 I/O；edit/web/skill/search 按用户任务意图加载）；③恢复三件套扩入方向（吸收 P0-A 冻结诉求：`list_evidence` 半集合 / 三件套全扩——**与 C-D8 路线 1 对应**）；
- 指标（不只看 token 下降）：任务完成率、错误工具率、发现工具耗时、重复 schema lookup 次数；
- 判据：缩减后 capability discovery 成功率不下降才可推广（§13.2 硬门）；
- 三态终判（扩入 CORE / 半集合 / 维持现状）**归用户**，数据不足标注证据等级降级并给补测方法。

### E-D7 词法路由 A/B（并入 tasks.md 组 4：4.1/E2）

三层联合评估（单一面调整不作数）：

1. **输入面**：路由输入是否扩展（原 P0-A 的"用户文本＋回执窗口"设想随胶囊退出失效；新评估面为"用户文本＋截断事实行/ref 在场"作为 schema 可见性状态输入——非文本扫描，见 C-D8 路线 3）；
2. **词表面**：关键词表放宽实验（含 tasks.md 4.1 的「健康」补齐——单词增量，误报只加小尾部，可先行）；"故意保守"注释前提（E4 锚点 :29-31）失效场景清单化（弱模型档位不自救实证 vs 强模型习惯无损）；
3. **解锁触发面**：可见性解锁只允许状态驱动（截断在场/control-plane 信号），**禁止扫模型可见回执文本锚点**（C 包约束继承）；
- 与 C 包关系显式声明：**互补不替代**——C 包治回执事实（去掉诱饵），本包治发现能力（恢复工具可找到）；
- E3/E4 残留项的重审归属见 §1.2 表（E3 由 C 包消解、E4 数据回填 B 包），本包 A/B 报告中仅引用结论不重复评估。

### E-D8 TOOL_ROUND_ZERO_HISTORY 维持实验（总审计 P2-3）

- 默认 off；
- 不因 cache/latency 指标自动开启；
- 只有 task-quality A/B 证明不降低 objective fidelity / tool-repeat / completion 才能推广；
- 不用 program task-anchor prose 补偿被删语义（与 E-D3 联合：anchor 已退出的前提下，该模式更无补偿手段，实验门槛相应提高）。

| 被弃方案 | 来源 | 弃因 |

### 4.2 能力不退化硬门（总审计 §13.2）

- **explicit user restore/continue 可恢复正确 task**（E-D5 授权路径的正确性是本包最关键能力门）；
- tool discovery 成功率不下降（E-D6/D7 A/B 核心判据）；
- 当前 unresolved tool follow-up 可正常继续；
- 任务完成率不得下降。

### 4.3 应改善指标（§13.3，本包主责项）

- 平均模型可见 program chars（E07 一项即消 ~417K chars 会话面）；
- memory/evidence 元数据占比；
- 弱模型答非所问率（元状态注入消失）；
- 用户任务→最终回答路径长度。

## 6. 迁移步骤（分批、可回滚、shadow→enforce）

```text
批 E1（通道静默 shadow）
  ① E07/E08/E35 producer 加开关，默认 on；shadow：记录 would_inject 量与内容分布
    （不进上下文），观察用户显式指代 memory 的频率（E-D1 路线 1 需求量）
  ② 达标（显式指代率低、无任务依赖注入证据）→ enforce off

  ③ allowlist 清空（禁止 promote）+ 现网 enforce 会话降 shadow（模式断言 E-G4）
  ④ shadow 测量持续（为未来重设计积累数据，不做任何注入）
批 E3（task_active 授权化）
  ⑤ input-side resolver 上线 shadow：识别"继续/恢复"类指令 → 记录 would_authorize
    与实际用户意图一致率
  ⑥ 达标 → enforce：task_active 注入仅经授权路径（E-G5 断言）
批 E4（CORE/词法路由 A/B，前置=C 包 capsule 退出验收）
  ⑦ 「健康」关键词补齐先行（单词增量，独立开关）
  ⑧ A/B 实验矩阵：CORE 三方案 × 指标四项（fixture 回放为主；环境可用时镜像区实跑，
     不可用如实标注"fixture 回放替代"——沿 tasks.md 5.4 口径不虚报验证等级）
  ⑨ 三态结论 + 数据表提交用户终判（门 E 纪律：维持须论证、越界标注、零静默吸收）
批 E5（收尾）
  ⑩ producer 代码移除（E-G6 静态断言）；TOOL_ROUND_ZERO_HISTORY 实验报告归档
  ⑪ behavior canary 重跑 + R9 启动条件核验
```

- **数据纪律**：A/B 数据不足时标注证据等级降级并给补测方法（沿 tasks.md spec 5.4.3-2 口径）。

## 7. 风险与不可删清单核对

### 7.1 风险

| 风险 | 缓解 |
|---|---|
| memory 退出后用户依赖的"它记得我"体验断裂 | E-D1 路线 1（显式指代授权检索）承接；shadow 期统计显式指代率评估真实需求量 |
| CORE 缩编后 discovery 成功率下降 | E-D6 判据即"不下降才推广"；三态结论归用户，数据不足不推进 |
| task_active 授权识别漏召回（用户说"继续"但未触发） | resolver shadow 期一致率观察；识别词表可配置；漏召回的兜底是模型可问用户（语义决策权在模型侧，恰好符合原则） |
| Cognitive 冻结后既有 enforce 依赖会话行为回退 | 降级 shadow 本身无注入（行为面即回退到无 packet），观察期比对任务完成率（13.2 硬门） |
| E4 锚点工作树漂移 | "必须复核"标注：以符号名（SemanticTaskState/allowlist promote 构造点）grep 再定位 |
| A/B 评估环境不可用 | fixture 回放替代 + 如实标注验证等级；实跑补验留待主区部署后 |

### 7.2 不可删清单核对（全部保留）

| 硬边界（总审计 §8.1） | 本包处理 |
|---|---|
| 灾难性安全 | 不涉及 |
| 隐私/凭据防泄漏 | 不涉及（memory 退出反而减少隐私面；属 D 包） |
| provider 协议 | 不涉及（CORE 是 prompt 可见性，不动 wire） |
| 真实物理限制 | 不涉及（TOOL_ROUND_ZERO_HISTORY 实验严守不以性能名义开启） |
