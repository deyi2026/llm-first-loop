## Q1. 保留批准的冻结历史债账本

权威设计 `docs/DESIGN-20261008-r9-static-diagnostic-ratchet.md` 明确冻结历史债。账本不是滚动的远端快照，来源 SHA 无须等于当前 HEAD 或上游；刷新远端 ref 不会改变其内容或数字。

原备忘录「锚错 legacy 仓库」「只影响显示，不影响判定」「刷新 ref 数字会跳」均撤回。基线允许集合参与 `new` 判断，改它会改变放行标准；不能以同步远端为由重建或放宽。本次保持账本字节、工具版本和判定规则不变，使用已有来源 SHA、账本哈希及版本输出解释结果。
