- **预算-完整性冲突**：过程轮瘦身（防漂移/缓存）与终局资料完整（质量）在单层上下文中不可兼得

## 2. 架构（v2 定稿）

### 2.1 核心思想
**过程-终局分层 + 缓存友好注入**：
- 过程轮（工具循环）：上下文薄（思维链零回传+工具摘要化+档案尾部槽）→ 前缀稳定、防漂移
- 终局轮（最终回答）：档案已全量在场（增量建立），全证据一次推理 → 质量上限提高
- 档案注入从任务开始、append-only、经尾部槽——**每轮 miss 恒等于增量块**（百字符级），终局轮零特殊注入

### 2.2 payload 布局（字节序=缓存序）
```
[system]                          恒定，全命中
[活跃桶历史]                       append-only，桶内增量追加
  └ 桶内：用户指令→工具摘要→…（薄，L1 级）
[档案槽]                           尾部槽（_tip_tail_messages 同机制），活跃桶专属，
  └ L1 摘要块增量追加               已有块零改动→全命中，新块=唯一 miss 源
[桶目录]                           尾部增量追加，其他桶锚点
  └（标题+终局结论+档案指针）
[当前注入/指令]                    每轮变化区（最小化）
```

### 2.3 桶结构（多任务）
- **桶=一个任务段**：新用户真实指令链 / create_goal = 新桶
- **切桶**：活跃桶历史整段更换（一次性 miss，低频可接受）
- **切回旧桶**：该桶历史原样回归，与 system 间零插入 → **全前缀命中**（同构于模型切换缓存机制）
- 非活跃桶背景经桶目录在场（标题+终局结论+档案指针），防止跨桶任务遗忘

### 2.4 弹性预算（用户决策 1）
```
注入预算 = max(基础 30k, 活跃档案需求 + 历史最小集)
上限     = 模型窗口 × 0.7（131k → ~92k）
约束     = 只扩尾部槽长度，不动已有字节（保前缀）
```
触发：完整文章等大内容入档案槽时自动上调；终局轮 L3 升级时按需再调。

### 2.5 档案分级（用户决策 3）
| 级 | 内容 | 在场性 |
|---|---|---|
| L1 | 规则摘要块（extract_key_info：路径/URL/关键行/结论） | 恒在场，append-only |
| L2 | archive 原文指针（tool_call_id → 压缩档案） | 恒在场 |
| L3 | 原文升级（终局轮预算允许时自动注入，尾部追加） | 按需 |

### 2.6 触顶策略（预算安全阀）
档案槽豁免滚动压缩；触顶时**整任务段折叠**（接受一次性 miss），禁止滑窗删块（每轮断前缀）。

## 3. 四层验证指标（用户决策 4：为定位问题设计）

| 层 | 指标 | 定位 |
|---|---|---|
| 缓存 | ①理论前缀命中字节（程序精确计算）②实测 cached_tokens ③每轮增量 miss ④桶切换 miss | ①≈② 正常；①>② 前缀断裂（二分找断点）；③突增→非追加写入 |
| 档案 | ⑤槽字节/块数 ⑥L3 升级次数 ⑦终局档案完整率 | ⑦<100%→弹性未跟上或触顶触发 |
| 质量 | ⑧终局评分钩子（web 👍/👎）⑨漂移标记率 | ⑨升→桶结构新干扰；⑧平⑨降→有效 |
| 预算 | ⑩使用率分布 ⑪弹性触发幅度 ⑫触顶折叠次数 | ⑫频发→弹性阈值不当 |

**核心自检不变式**：`理论前缀命中 ≈ 实测 cached_tokens`（每轮落 cognitive_telemetry，偏离即结构破损告警）。
