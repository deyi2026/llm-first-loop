## 1. 目的与判据引用

本规程规定 V5 投影标定的行为验证方法（coarse 标记 + "混入"判据）与留证要求。

SPEC §11.2 门槛表 V5 行（逐字）：

> | V5 | 投影标定 | 前提自检不满足时必须判"粗对齐"并打 degradation_flag = `coarse`（C-5）；"混入毫米级通道"定义为：该观测被 F-2 用于 NEAR 交接、或计入 V2 精度统计——实现必须以 degradation_flag 支撑该判据，无标记即判不通过 |

SPEC §7 M-5（逐字，全文）：

> M-5 投影模态（可选）
> a) 投影生成的临时图案必须满足编码层全部要求（C-2 / C-3 / C-4）；
> b) 投影前提（投影面平面度、对比度、投影畸变校正）必须作为运行时自检项；前提不满足必须判"粗对齐"并显式打降级标记，禁止混入毫米级通道（Q5 裁决，门槛 V5）。

SPEC §5 C-5 degradation_flag 字段行（逐字）：

> | degradation_flag | 降级标记：`none`｜`coarse`（如投影前提不满足，M-5b）｜`quarantine`（R-6 超期隔离） |

SPEC §9 F-2 NEAR → CONTACT 行与 MID → NEAR 行（逐字，"混入"判定的下游锚点）：

> | MID → NEAR | 阵列 / 高密度大板可见；角点亚像素残差 ≤ [TBD-F2]（像素；与 V2 的 mm/deg 精度口径分离） |
> | NEAR → CONTACT | 力 / 触觉传感器就位；标定板平面度自检通过 |

判读口径（依上述原文归纳，不新增判据）：

- **"混入毫米级通道"的判定依赖 degradation_flag**：判据句原文已把"混入"定义为两条下游事件——该观测被 F-2 用于 NEAR 交接、或计入 V2 精度统计；且"实现必须以 degradation_flag 支撑该判据，无标记即判不通过"。因此本规程的验证面是：(a) 前提不满足场景的输出必须带 degradation_flag = `coarse`；(b) 下游（F-2 NEAR 交接判定、V2 统计计入）必须以该标记为门——`coarse` 观测不得出现在 NEAR 交接输入与 V2 统计集合中；
- 无标记即判不通过：前提不满足场景输出 degradation_flag ≠ `coarse`（如为 `none`）→ 直接判 V5 不通过（判据句原文）；
- 对照侧（前提满足场景）预期不打 coarse；若对照侧误打 coarse，属过度降级假阳性，SPEC 未为其设门槛——如实记录为观察项，不发明判据。

- 依赖（PLAN §5.2 C8）：投影仪 `[需外部]`（PLAN §4.4 硬件清单行："投影仪（可选）| 普通办公投影 | V5 前提判别"）、B3（读码器，须实现 M-5b 运行时自检项）、图案生成链（B6 或投影生成路径，满足 M-5a）；

## 4. 步骤

1. 前置核对：被测实现含投影前提运行时自检项（M-5b"必须作为运行时自检项"）；**中断点：无自检项 → V5 行为要求无从触发，停并登记实现缺口**；
2. 前置核对：D-10 裁决口径；**中断点：未裁决 → 正式判定 blocked 登记；可先做合成模拟（simulated）通道验证**；
3. 生成投影图案并核验满足 C-2 / C-3 / C-4（M-5a）；记录图案版本与清单；
4. 对照场景（前提满足）：执行读取，记录输出（预期 degradation_flag = `none`；若为 `coarse` 记为观察项，见 §1）；
5. 逐项破坏前提（平面度 / 对比度 / 畸变校正）执行读取：检查输出是否判"粗对齐"且 degradation_flag = `coarse`；
6. 下游消费检查：核验 `coarse` 观测未被 F-2 用于 NEAR 交接、未计入 V2 精度统计（以消费端测试桩 / 日志为证）；**中断点：消费端不可观测（无日志 / 无桩）→ "混入"无法证伪，停并登记**；
7. 无标记检查：前提不满足场景输出无 `coarse` 标记 → 判不通过（判据句原文）；
8. 回执落盘（README §3 约定）。

## 5. 回执格式

JSON 字段清单（runner 产出，落盘约定见 README §3）：

| 字段 | 类型 | 说明 |
|---|---|---|
| gate | string | 固定 "V5" |
| simulated | boolean | true=合成模拟投影场景；false=投影仪实测（建议统一携带） |
| d10_status | string | "纳入行为验证"（本规程口径）或裁决结果引用；未裁决时标 blocked |
| scenarios | array | 每元素 {premise: flatness\|contrast\|distortion_correction, satisfied: bool, judged_coarse: bool, observed_flag, notes} |
| control_scenario | object | 前提满足对照场景结果（含过度降级观察项） |
| pattern_conformance | object | 投影图案对 C-2 / C-3 / C-4 的核验记录（M-5a） |
| downstream_checks | object | {near_handover_blocked: bool, v2_stats_excluded: bool, evidence_ref}——"混入"判定的下游证据 |
| unmarked_violation_count | integer | 前提不满足且无 `coarse` 标记的样本数（**必须 = 0**，判据句"无标记即判不通过"） |
| verdict | string | 逐项结论 |
| command / env / head_sha / exit_code | — | README §3 通用要素 |

## 6. 失败处置

- 无标记混入（unmarked_violation_count > 0）：V5 判不通过（判据句原文）。修订实现（自检项 / 标记传播 / 下游门控）后重测；
- `coarse` 观测进入 NEAR 交接或 V2 统计（"混入毫米级通道"）：判不通过；修订下游门控逻辑；
- 自检项缺失：实现缺口，补 M-5b 运行时自检后重测；
- 未达标处置总纪律（SPEC §11.2 验证纪律，逐字）："门槛未达标时修订设计或规范，不得放宽门槛；确需放宽必须记录证据与理由。"；
- D-10 裁决为"声明可选模态不适用"：本门槛转声明性登记，不虚构测试通过；裁决记录与风险评估留档（对应 T-4d 开放环境口径另行适用与否由工作组判断）。
