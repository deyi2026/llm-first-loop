## 1. 目的与判据引用

本规程规定 V3 公差带的定带方法、留出批次落带验证方法与留证要求。核心结构：**独立批次定带 → 独立留出批次验证落带**，两批分离，认证样本不得自证落带。

SPEC §11.2 门槛表 V3 行（逐字）：

> | V3 | 公差带 | 规范带按 G6 由**独立批次抽检**分布的 P2.5 / P97.5 加 ≥25% 带宽裕度确定；随后用**独立留出批次的抽检样本**验证落带：带外率 ≤ [TBD-V3α]，样本量 N ≥ [TBD-V3β]。认证样本只用于定带与作 V6 基准，**不得自证落带**（自身参与定带再验证自身，判据恒真） |

SPEC §4 P-2（逐字）：

> P-2 几何公差带
> a) 角点边长制造公差：[TBD-P2a]；
> b) 靶标平面度：[TBD-P2b]；
> c) 安装（粘贴）平面度与贴合要求：[TBD-P2c]。

SPEC §4 P-4（逐字）：

> P-4 认证样本
> 认证样本必须由具备计量能力的实验室标定，附证书（标定方法、设备、日期、不确定度），作为 V3 / V6 一致性测试的物理基准。

SPEC §4 P-5（逐字）：

> P-5 制造符合性
> a) 公差带外制造的靶标禁止引用任何精度声明；
> b) 声明公差等级的供应方必须附可核查依据（批次抽检报告或认证样本谱系）。

SPEC §4 P-3 a)（逐字，测量参考温度口径）：

> a) 靶标参考系定义必须绑定基准温度 T0 = 20 °C（依 ISO 1；[TBD-G] 待工作组确认）；

SPEC §11.3-b（逐字）：

> b) 物理测试：批次抽检落带（V3）、跨厂商一致性（V6）；认证样本仅作 V6 基准与定带输入；

SPEC §14 相关行（逐字）：

> | 公差带各项数值 [TBD-P1 / P2a–c / P3a / M2] | P-1 / P-2 / P-3 / M-2 | P2 计量数据（G6 定带规则） | 工作组 |

> | V3 落带判据的带外率上限 / 样本量 [TBD-V3α / β] | 11.2-V3 | P2 计量 | 工作组 |

判读口径（依上述原文归纳，不新增判据）：

- 定带规则：独立批次抽检分布的 P2.5 / P97.5 加 ≥25% 带宽裕度（G6 定带规则，属 `[TBD-G]` 裁决类，见 SPEC §0.2）；
- 落带验证：独立留出批次抽检，带外率 ≤ [TBD-V3α]，样本量 N ≥ [TBD-V3β]（两项数值待工作组回填，"待裁决回填"）；
- 本规程默认定带对象至少覆盖 P-2 a / b / c 三项；P-1 / P-3 / M-2 各项数值同属 §14 行的 P2 计量回填范围，是否纳入本规程落带验证范围由工作组按 G6 定带规则一并裁决——本规程不扩大也不缩小。

## 2. 前提与样本

- **批次 A（独立批次，定带用）**：一次真实制造批次（生产 run）的抽检样本；用于计算 P2.5 / P97.5 并加 ≥25% 带宽裕度得出规范带；
- **批次 B（独立留出批次，验证落带用）**：与批次 A 不同源（不同生产 run，非同批抽样再分半）的制造批次抽检样本；样本量 N ≥ [TBD-V3β]（SPEC 已写明，数值待裁决回填）；
- 认证样本：按 P-4 由计量实验室标定（附证书）；只用于定带输入与 V6 基准，**不得进入批次 B 落带验证集**（判据句"不得自证落带"）；
- 批次前置（PLAN §5.3 F3，逐字）："F3｜V3 的批次前置。独立批次抽检要求真实制造批次；打印/材料批次必须在 W8 前下单，否则 P2 尾部一定阻塞。"；
- 定带批次 A 的抽检量：SPEC 未给编号——**由工作组定**（随 G6 定带规则裁决）；留出批次样本量 N ≥ [TBD-V3β]（SPEC 已写明）；
- 测量条件：参考温度口径按 P-3 a)（T0 = 20 °C，[TBD-G] 待工作组确认）；测量在参考温度下进行或做温度修正，具体由计量方案定。

## 4. 步骤

1. 前置核对：批次 A 与批次 B 均为真实制造批次且相互独立（不同生产 run）；**中断点：批次 B 与批次 A 同源（同批分半 / 同一生产 run）→ 判据要求的"独立留出批次"不成立，停**；
2. 前置核对：计量档期（C0）与温控条件锁定；**中断点：无档期 → 登记 blocked**；
3. 批次 A 抽检：在参考温度口径下测量 P-2 各项（角点边长、平面度、安装平面度与贴合），得分布样本；
4. 认证样本参与定带输入（P-4）；记录其证书编号；
5. 定带计算：P2.5 / P97.5 分位数 + ≥25% 带宽裕度 → 规范带；**中断点：G6 定带规则未裁决（属 [TBD-G]）→ 定带细则无法执行，登记 blocked 待工作组决议**；
6. 规范带发布（按 SPEC §0.2 填充流程回填 [TBD-P2a]–[TBD-P2c]，保留 TBD 编号、附回执编号）；
7. 批次 B 抽检：独立留出批次测量同样项目，样本量 N ≥ [TBD-V3β]；**自证检查：认证样本 ID 出现在批次 B 验证集 → 无效，剔除并重抽（判据句"不得自证落带"）**；
8. 落带判定：计算带外率，对照 ≤ [TBD-V3α]；**中断点：[TBD-V3α] / [TBD-V3β] 未回填 → "跑完测试≠门槛判定"（PLAN §5.3 F4），回执记"数据齐、判定待回填"，登记待工作组回填会议**；
9. 回执落盘（README §3 约定）；批次抽检报告同时作为 P-5 b) 供应方可核查依据的素材。

### 最小冒烟步骤（无全量资源时先跑通流程）

> 性质：只验证"样本链路、流程与回执能跑通"，**不产生任何门槛证据**；冒烟回执的 `simulated` 必须为 `true`（PLAN §0.4：simulated 不得写成"实测"）。

**S1 冒烟一次**

- (a) 生成冒烟板：执行 `README.md` §2 的冒烟板命令，确认末行 `manifest_ok True`、四件产物齐全；
- (b) 如有普通打印机与钢尺：打印冒烟板，量 3 个角点边长，按 §5 落 3 行读数（`simulated: true`——普通打印与钢尺读数**不构成计量**）；无打印机则跳过，止于 (a)；
- (c) 按 §5 回执格式落一份冒烟回执（`simulated: true`），核对必填字段齐全后停止——**不得据此填写 §1 的任何判据结论**。

- **跑通判据**：冒烟板四件齐全且清单复核通过；有打印机时 3 行 simulated 读数能按 §5 落回执；
- **止步点**：无独立批次与计量实验室，定带与落带判定不可得；冒烟读数不得进入落带统计。

## 5. 回执格式

JSON 字段清单（runner 产出，落盘约定见 README §3）：

| 字段 | 类型 | 说明 |
|---|---|---|
| gate | string | 固定 "V3" |
| lot_a | object | {production_run_id, n_inspected, measured_items[]}，measured_items 含 P-2a/b/c 各项分布数据引用 |
| band_derivation | object | {p2_5, p97_5, margin_pct（≥25，判据句已写明下限）, final_band, g6_resolution_ref}；G6 未裁决时 g6_resolution_ref 为空并标注待裁决 |
| lot_b | object | {production_run_id, n_samples（≥ [TBD-V3β] 回填值）, out_of_band_count, out_of_band_rate} |

| certified_sample_check | object | 认证样本未参与落带验证的核验记录（判据句"不得自证落带"） |

## 6. 失败处置

- 落带验证未达标（带外率 > [TBD-V3α]，在 N ≥ [TBD-V3β] 条件下）：V3 未达标。按 SPEC §11.2 验证纪律（逐字）："门槛未达标时修订设计或规范，不得放宽门槛；确需放宽必须记录证据与理由。"处置方向：修订制造工艺 / 公差带设计（走 G6 与工作组，规范数值变更按 SPEC §0.2 填充流程与第 15 章变更历史）或补测（排除测量缺陷后重抽批次）；
- 严禁为使落带通过而反向放宽 [TBD-V3α] 或压缩 [TBD-V3β]：回填值由工作组依 P2 计量数据与统计功效裁决（PLAN A1b 已将 [TBD-V3α/β] 登记为裁决项），不得以本次测试结果为唯一依据取值；
- 独立性或自证违规（批次同源、认证样本混入验证集）：数据无效，重建样本集后重测；
- 带外样本本身：按 P-5 a)（逐字）"公差带外制造的靶标禁止引用任何精度声明"——带外个体不得流通使用，处置记录入回执。
