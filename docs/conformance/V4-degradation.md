## 1. 目的与判据引用

本规程规定 V4 降级行为的双向测试方法（错读侧 + 漏检侧）与留证要求。

SPEC §11.2 门槛表 V4 行（逐字）：

> | V4 | 降级行为 | 双向判据：① 低于 [TBD-V4a] / [TBD-V4b] 的样本误读率 = 0；② 条件达标样本漏检率 ≤ [TBD-V4c]（N ≥ [TBD-V4d]）。"永不输出"必须判为不通过 |

SPEC §5 C-4（逐字，全文）：

> C-4 最小可读条件
> a) 输出观测的必要条件：可见角点数 ≥ [TBD-V4a]（个）且数据位可见比例 ≥ [TBD-V4b]（%）；
> b) 低于阈值时读码器必须不输出——宁可漏检，不可错读（对应门槛 V4）；
> **b-2) 达标侧同样受限**：条件达标样本的漏检率必须 ≤ [TBD-V4c]，样本量 N ≥ [TBD-V4d]——只禁错读而不限漏检，等价于激励"永不输出"这一退化实现；
> c) 到达阈值前的劣化预警属健康监测（设计文档 §9.6），不属本层强制行为。

SPEC §11.1-e（逐字）：

> e) 最小可读条件实现值（对照 C-4 阈值）。

SPEC §14 相关行（逐字）：

> | 最小可读条件阈值 [TBD-V4a–d] | C-4 | P2 实测（双向判据：误读 = 0 且漏检受限） | 工作组 |

判读口径（依上述原文归纳，不新增判据）：

- 判据①（错读侧）：条件低于 [TBD-V4a] / [TBD-V4b] 的样本，误读率必须 = 0；
- 判据②（漏检侧）：条件达标样本漏检率 ≤ [TBD-V4c]，且样本量 N ≥ [TBD-V4d]；
- 反退化检查：组②侧"永不输出"（输出总数为零或漏检率 100% 且非样本构造原因）必须判为不通过（C-4 b-2 原句）；
- "误读"操作定义：输出观测的 target_index / logical_id 与样本真值不符，或对构造上不可唯一解码的样本输出了任何 ID——真值来自样本构造记录（合成样本自带 ground truth；物理样本附 B6 布局 JSON 与清单哈希）。

## 2. 前提与样本（双向判据两组样本）

- **组①（低于阈值组 / 错读侧）**：构造可见角点数 < [TBD-V4a] 或数据位可见比例 < [TBD-V4b] 的样本——合成劣化（遮挡、污渍、离焦 / 透视劣化、数据位遮蔽、位翻转超出纠错能力）。判据①误读率 = 0。组①样本量：SPEC 未给编号——**由工作组定**（占位 N_V4_below）；
- **组②（达标组 / 漏检侧）**：构造可见角点数 ≥ [TBD-V4a] 且数据位可见比例 ≥ [TBD-V4b] 的样本。判据②漏检率 ≤ [TBD-V4c]，N ≥ [TBD-V4d]（SPEC 已写明，数值待回填）；
- 每样本必须带条件真值标注（可见角点数、数据位可见比例），否则无法分组判读（见 §4 中断点）；
- 依赖（PLAN §5.2 C3）：B4（可配置阈值 + 双向抑制 + 漏检计数）、B7（V4 runner）、B3（读码器）；B6（合成样本生成与布局清单）；
- 影子通道（PLAN §4.1 K7，逐字）："测试构建可开'影子通道'：记录近阈值候选但不对外输出"；理由（逐字）："V4 要统计漏检，正式输出又必须为零；两者只能靠构建隔离"——组②漏检统计依赖影子通道，无它则判据②不可测；
- 阈值可配置（PLAN §4.1 K1，逐字）："所有 `[TBD]` 阈值可配置 + 声明式，禁止硬编码"；
- 物理面 `[需外部]`：条件分级物理样本（打印件 + 人工劣化：遮挡 / 贴歪 / 污损）；
- 样本量：除 N ≥ [TBD-V4d] 外无 SPEC 数值——组①与组②内部条件分层（按角点数 / 可见比例分几档）由工作组定。

## 3. 设备与工具

- 软件：B3 读码器、B4 阈值配置（写入 `ctp/src/ctp_reader/config/`，T3 写区）、B7 V4 runner、B6 生成器；各版本记入回执；
- 影子通道构建开关（K7）：测试构建启用，正式构建关闭；两种构建的配置差异记入回执；
- 统计口径：误读数 / 漏检数 / 抑制数三计数器（B4 产出）；
- 物理段 `[需外部]`：打印件、人工劣化工装、拍摄台。

## 4. 步骤

1. 前置核对：B4 影子通道可用（K7）；**中断点：无影子通道 → 判据②漏检不可统计，停并登记（实现缺口，PLAN §4.2 B4 验收含"漏检计数"）**；
2. 前置核对：[TBD-V4a]–[TBD-V4d] 回填状态。已回填 → 使用回填值 + 决议编号进入正式判定；未回填 → 允许以显式登记的探针配置跑**通道验证运行**（simulated，回执标注"非判据运行，阈值为探针值"），门槛判定留待回填后；**中断点：探针值未显式登记即冒充判据值 → 停**；
3. 构造组①样本（每样本记录条件真值：可见角点数、数据位可见比例）；
4. 构造组②样本（同上，达标侧）；
5. 运行 runner 于影子通道构建：逐样本执行读取，收集——正式输出集（对外可见）、影子候选集（内部记录）、抑制计数、误读判定（输出 ID vs 真值）；
6. 判据①判定：组①误读率 = 0（任何误读即未达标，零容忍）；
7. 判据②判定：组②漏检率 ≤ [TBD-V4c]，且 N ≥ [TBD-V4d]；
8. 反退化检查：组②输出总数为零 / 漏检率 = 100% 且排除样本构造原因 → 判不通过（"永不输出"退化实现）；
9. 产出 11.1-e 声明材料（最小可读条件实现值，对照 C-4 阈值）；
10. 回执落盘（README §3 约定；**simulated 必填**）。

### 最小冒烟步骤（无全量资源时先跑通流程）

> 性质：只验证"样本链路、流程与回执能跑通"，**不产生任何门槛证据**；冒烟回执的 `simulated` 必须为 `true`（PLAN §0.4：simulated 不得写成"实测"）。

**S1 冒烟一次**

- (a) 生成冒烟板：执行 `README.md` §2 的冒烟板命令，确认末行 `manifest_ok True`、四件产物齐全；
- (b) 从 `board-matrices.json` 取 1 个码的位图真值，手工遮蔽数据位构造 1 个「低于阈值」候选与 1 个完好候选，核对 §2 要求的逐样本真值标注（可见角点数、数据位可见比例）可填写；
- (c) 按 §5 回执格式落一份冒烟回执（`simulated: true`），核对必填字段齐全后停止——**不得据此填写 §1 的任何判据结论**。

- **跑通判据**：冒烟板四件齐全且清单复核通过；两条候选样本的真值标注字段可逐样本填写；
- **止步点**：B3 / B4 / B7 未落地，读码、阈值抑制与漏检计数均不可执行，冒烟止于样本构造。

## 5. 回执格式

JSON 字段清单（runner 产出，落盘约定见 README §3；**本门槛 simulated 为必填字段**）：

| 字段 | 类型 | 说明 |
|---|---|---|
| gate | string | 固定 "V4" |
| **simulated** | boolean | **必填**：true=合成样本 / 探针阈值；false=物理样本 + 已回填阈值的正式判定 |
| thresholds_used | object | {v4a, v4b, v4c, v4d, source}：正式判定填回填值 + WG-RES 决议编号；通道验证填探针值并标 probe |
| group_below | object | 组①：{n（N_V4_below 实际值）, misread_count, misread_rate, condition_bins[]} |
| group_adequate | object | 组②：{n（须 ≥ [TBD-V4d] 回填值）, missed_count, miss_rate, outputs_total} |
| never_output_check | object | {outputs_total, cause_eliminated, verdict}——反退化检查（C-4 b-2） |
| shadow_channel | object | {enabled, build_config_ref}——K7 构建隔离证据 |
| sample_manifest | object | 两组样本清单引用（含条件真值标注、B6 布局哈希） |
| verdict | string | 判据①②与反退化检查逐项结论 |
| command / env / head_sha / exit_code | — | README §3 通用要素 |

## 6. 失败处置

- 判据①违例（组①任何误读）：严重失效——"宁可漏检，不可错读"（C-4 b）被破坏。修订实现（抑制逻辑 / 解码置信门槛）或修订阈值取值依据后重测；按 SPEC §11.2 验证纪律（逐字）："门槛未达标时修订设计或规范，不得放宽门槛；确需放宽必须记录证据与理由。"；
- 判据②违例（组②漏检率 > [TBD-V4c]）：未达标，修订检测能力或按证据走工作组流程调整 [TBD-V4c]（须记录证据与理由，不得为通过测试反向取值）；
- 反退化检查判不通过（"永不输出"）：按 C-4 b-2 原句必须判为不通过；修订实现后重测；
- [TBD-V4a–d] 未回填即声称通过：无效——"跑完测试≠门槛判定"（PLAN §5.3 F4），回执只能记"数据齐、判定待回填"。
