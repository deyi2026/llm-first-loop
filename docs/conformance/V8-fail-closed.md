## 1. 目的与判据引用

本规程规定 V8 故障注入测试的样本构造、**按故障类型分派的期望行为判定**与留证要求。

SPEC §11.2 门槛表 V8 行（逐字）：

> | V8 | fail-closed | 注入 1000 个故障样本，按类型分派期望行为：**漏检类**（遮挡 / 超纠错码字 / 贴歪不可读）→ 不输出 + 计数上报（禁止静默）；**伪造 / 层级矛盾类**（错 ID、复制靶标、级间位姿矛盾）→ STOP + 报警。两类均要求"带错硬接" = 0 |

SPEC §2 术语表"带错硬接"行（逐字）：

> | 带错硬接 | 相邻层级证据矛盾时仍向更精细层级推进的行为，本规范禁止（F-3） |

SPEC §9 F-3（逐字，全文）：

> F-3 一致性校验与"带错硬接"禁令：阈值为 k × RSS(相邻两级 C-5 声明不确定度)，k 初值 2（v0.9.2 冻结为默认值，见 PROP G3）；相邻两级位姿差 > 阈值时必须回退上一级并报警；禁止在层级证据矛盾下向更精细层级推进。**V8 只验证该阈值能否达成"带错硬接 = 0"，不反向校准阈值**；阈值修订走 VC-1 变更流程并记入第 15 章。

SPEC §9 F-1 / F-4（逐字）：

> F-1 状态集：FAR（场景级）→ MID（编码图案）→ NEAR（精细阵列）→ CONTACT（伺服级）；全局终态 STOP。

> F-4 各级失败出口：
> a) FAR 失败：重试 N 次（1 ≤ N ≤ 3；N 与单次超时预算必须在 11.1 合规声明中公开）后 → STOP；
> b) MID / NEAR 失败：回退上一级；上一级亦失败则逐级回退至 FAR，再失败 → STOP；
> c) STOP = 停止 + 报警 + 人工介入；禁止"默认通过"出口（Q7 裁决：每级都有失败出口，最底层出口显式定义为 STOP）。

SPEC §8 威胁模型相关（逐字）：

> | D1 物理替换 | 能在物理空间粘贴 / 替换靶标 | 复制 ID 的伪造靶标 |

> T-4 防伪三级：
> a) 语义层签名（对 D1 / D2）：见 R-5；
> b) 组合层几何互证（对 D1）：见 M-2；
> c) 物理访问控制（对 D1）：封闭产线场景天然具备；
> d) 开放环境部署必须至少实现 a + b，并留存风险评估记录。

SPEC §7 M-2 b)（逐字，复制靶标检测机理）：

> b) 读码器或上层必须执行几何互证：实测几何关系与登记值偏差超公差 → 按 F-3 回退并报警（防伪第二级，见 T-4b）。

SPEC §5 C-2 b)（逐字，超纠错码字行为）：

> b) 解码必须在纠错能力内进行；超出纠错能力的码字按 C-4 处理（不输出）。

SPEC §14 相关行（逐字）：

> | 级间位姿差阈值 [TBD-F3：k×RSS，k 默认 2] | F-3 | V8 只验证不校准；修订走 VC-1 | 工作组 |

> | 回退率上限 [TBD-FB]（F-3 阈值第二约束） | F-3 / PROP G3 | P2 台架回退率实测 | 工作组 |

判读口径（依上述原文归纳，不新增判据）——**期望行为按故障类型分派**：

| 故障类型 | 判据句原文归类 | 期望行为 |
|---|---|---|
| 遮挡 | 漏检类 | 不输出 + 计数上报（禁止静默） |
| 超纠错码字 | 漏检类（C-2 b：按 C-4 处理（不输出）） | 不输出 + 计数上报（禁止静默） |
| 贴歪不可读 | 漏检类 | 不输出 + 计数上报（禁止静默） |
| 错 ID | 伪造 / 层级矛盾类 | STOP + 报警 |
| 复制靶标 | 伪造 / 层级矛盾类（D1 对手动作，M-2 b 几何互证拦截） | STOP + 报警 |
| 级间位姿矛盾 | 伪造 / 层级矛盾类（F-3 阈值 k × RSS 触发回退 + 报警） | STOP + 报警 |
| ——两类共同 | "两类均要求" | "带错硬接" = 0 |

- "静默"操作定义：漏检类样本既无输出也无计数上报记录；
- "带错硬接"操作定义：术语表原文——层级证据矛盾时仍向更精细层级推进；以状态机日志（层级推进事件 + 矛盾证据事件的时间序）判定；
- V1 关联：V1 判据句原文"（V8 期望行为输入）"——V1 回执（超时降级行为）作为本测试期望行为参考输入。

## 2. 前提与样本

- 总量：注入 1000 个故障样本（SPEC 判据句已写明）；1000 例内部的类型配比 SPEC 未写——**由工作组定**，配比一经裁决写入回执 thresholds 字段；
- 每样本必须带类型标注（七类之一 + 构造参数），无标注即无法分派期望行为（见 §4 中断点）；
- 合成构造（simulated，先行）：遮挡（图像区域遮蔽）、超纠错码字（位翻转数超过码族纠错能力——36h11"可纠正 ≤ 5 位错误"，C-2 a 原文）、贴歪不可读（大角度透视 / 非平面贴合仿真）、错 ID（改码字为另一合法 ID）、复制靶标（同 ID 双贴构造 + 注册表登记几何）、级间位姿矛盾（两级观测位姿差构造为超 F-3 阈值）；
- 物理构造 `[需外部]`：真实遮挡物、物理贴歪、复制靶标打印件、双层级观测台架；
- 依赖（PLAN §5.2 C4 与 §5.1 依赖图）：B7（V8 runner）、C2（依赖图原文："V2 精度 ─→ V8 故障注入 ……（V8 的 k×RSS 需已验证的不确定度）"）、回退状态机实现（F-1–F-5）、B4 计数通道、B5 注册表（复制靶标 / 错 ID 的语义面证据）；
- F-3 阈值状态：k 初值 2（v0.9.2 冻结为默认值）；[TBD-F3] 表述按 §14 行原样保留；[TBD-FB] 回退率上限待 P2 台架实测（本规程不消费该值，仅登记依赖）。

## 4. 步骤

1. 前置核对：故障样本集构造完成且每样本带类型标注；**中断点：类型标注缺失 → 期望行为无法分派（判据按类型分派），停**；
2. 前置核对：C2 已通过（不确定度已验证）——级间位姿矛盾类的 F-3 阈值（k × RSS）依赖已验证不确定度；**中断点：C2 未过 → 级间矛盾子类判定 blocked，其余子类可先行（回执分项标注）**；
3. 前置核对：五类日志通道可用；**中断点：日志缺失 → "带错硬接"与"静默"不可判定，停**；
4. 注入执行：逐样本注入（合成面：直接送入读码器 / 状态机；物理面：台架摆放），记录系统响应（输出 / 不输出、计数上报、层级事件、STOP、报警）；
5. 漏检类判定：不输出成立？计数上报成立？两者任一缺失——输出观测（误读）或无上报（静默）——均计违规；
6. 伪造 / 层级矛盾类判定：STOP 触发？报警触发？任一缺失计违规；
7. 带错硬接计数：扫描全部样本的时间序日志，任何"层级证据矛盾仍向更精细层级推进"计 1；
8. 汇总判定：静默违规 = 0、漏检类误读 = 0、STOP / 报警缺失 = 0、**"带错硬接" = 0**（两类共同要求）；
9. 回执落盘（README §3 约定；**simulated 必填**）；引用 V1 回执作为期望行为输入（v1_receipt_ref）；
10. **禁止动作**：不得用本次注入数据反向调整 F-3 阈值 k（F-3 原文"V8 只验证该阈值能否达成'带错硬接 = 0'，不反向校准阈值"；阈值修订走 VC-1 变更流程）。

## 6. 失败处置

- 带错硬接 > 0：F-3 禁令被破坏，V8 未达标。修订回退状态机实现（矛盾证据下的推进门控）后全量重测；按 SPEC §11.2 验证纪律（逐字）："门槛未达标时修订设计或规范，不得放宽门槛；确需放宽必须记录证据与理由。"；
- 漏检类静默 > 0（不输出但无计数上报）：判据句"禁止静默"被违反，补计数上报通道后重测；
- 漏检类出现输出（误读）：与 C-4 b"宁可漏检，不可错读"冲突，严重失效，修订后重测；
- 伪造 / 层级矛盾类 STOP 或报警缺失：fail-closed 出口缺失（F-4 c"禁止'默认通过'出口"），修订失败出口实现后重测；
- 不得以测试结果反向校准或放宽 F-3 阈值（F-3 原文"不反向校准阈值"）；阈值修订只能走 VC-1 变更流程并记入 SPEC 第 15 章；
- [TBD-FB] 回退率上限未回填：不影响本门槛"带错硬接 = 0"判定，但 F-3 阈值第二约束的台架回填另行等待（SPEC §14 行），在回执边界注明。
