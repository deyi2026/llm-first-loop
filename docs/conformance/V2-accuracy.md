## 1. 目的与判据引用

判读口径（依上述原文归纳，不新增判据）：

- 条件范围：0.2–2 m、入射角 ±60°、规定光照内（均为 SPEC 已写明）；
- 判据：平移 ≤ 2 mm (3σ)、旋转 ≤ 0.5° (3σ)；σ 口径由 C-5 不确定度声明承载（k + 1σ 双要素，缺一即不合规）；

- 禁止引用 §3.2 量级表替代 11.2-V2 的 3σ 口径（两表不得并列表述）。

## 2. 前提与样本

- 依赖（PLAN §5.2 C2）：C0 计量档期 `[需外部]`、B3（读码器）、B2（不确定度声明与传播——C-5 uncertainty 字段的模型来源）；
- 真值基准：计量实验室真值（PLAN §8 R4 职责："V2/V3/V6 真值与认证样本"）；
- 被测靶标：公差带内靶标，且须可溯源（认证样本，或量具核对板尺寸——PLAN §10 R-10 对策："打印前校准；用认证样本或量具核板尺寸"），避免制造误差混入端到端误差；
- 条件矩阵：距离（0.2–2 m 区间内）× 入射角（±60° 区间内）× 光照（按 §1 规定光照口径）三个维度的条件点集合；**条件点数量、间距与每点重复次数 SPEC 未规定——由工作组/计量方案定**（本规程以 C_V2 个条件点、每点 N_V2 次重复占位，不填数字）；
- 附带产出（PLAN §5.3 F2 发现，逐字）："F2｜V2 与 F-2 共用一次采集。……建议 C2 的数据集附带像素残差统计，避免二次上架。"——同一数据集同时产出角点亚像素残差统计，供 F-2 [TBD-F2] 回填；两口径（mm/deg 与像素）分离统计、分离判读；
- 样本量：除上述占位外无 SPEC 数值——由工作组定。

## 4. 步骤

1. 前置核对：B2 不确定度声明就绪且含 k 与 1σ（C-5 硬要求）；**中断点：声明缺 k 或 1σ → 判据不可计算，停**；
2. 前置核对：真值链锁定（计量设备档期 + 溯源证书）；**中断点：真值不可溯源 → 停**；
3. 靶标就位：认证样本或量具核对过的被测靶标安装；安装几何记入测试记录；
4. 条件矩阵遍历：对每个条件点（距离 / 入射角 / 光照组合）执行 N_V2 次读取；每次输出必须为完整 C-5 观测（九字段）；**中断点：任一输出缺字段或缺 k/1σ → 该样本无效；系统性缺失 → 停**；
5. 附带采集：同一数据集产出角点亚像素残差统计（PLAN F2），单独成表，供 F-2 回填，不并入 V2 判据计算；
6. 误差统计：逐条件点计算与计量真值的平移误差（mm）与旋转误差（deg），按 3σ 口径汇总；
7. 判定：对照 §1 判据句（平移 ≤ 2 mm (3σ)、旋转 ≤ 0.5° (3σ)，条件范围内）；
8. 产出精度—条件曲线（距离 / 入射角 / 光照三维，附方法与数据来源——11.1-b 声明材料；实测前禁止给出数字）；
9. 回执落盘（README §3 约定）。

### 最小冒烟步骤（无全量资源时先跑通流程）

> 性质：只验证"样本链路、流程与回执能跑通"，**不产生任何门槛证据**；冒烟回执的 `simulated` 必须为 `true`（PLAN §0.4：simulated 不得写成"实测"）。

**S1 冒烟一次**

- (a) 生成冒烟板：执行 `README.md` §2 的冒烟板命令，确认末行 `manifest_ok True`、四件产物齐全；
- (b) 从 `layout.json` 读出任一靶的 `center_x_mm` / `center_y_mm` 与 `frame_ref`，核对它们能作为位姿真值的几何基准被引用（坐标口径见同文件的 `coordinate_frame`）；
- (c) 按 §5 回执格式落一份冒烟回执（`simulated: true`），核对必填字段齐全后停止——**不得据此填写 §1 的任何判据结论**。

- **跑通判据**：冒烟板四件齐全且清单复核通过；逐码中心坐标与参考系引用可从布局 JSON 直接读出；
- **止步点**：无计量设备与认证样本，精度—条件曲线不可得，冒烟止于几何基准可引用。

## 6. 失败处置

- 任一条件点未达判据（平移 > 2 mm (3σ) 或旋转 > 0.5° (3σ)，在 0.2–2 m / ±60° / 规定光照内）：V2 未达标。按 SPEC §11.2 验证纪律（逐字）："门槛未达标时修订设计或规范，不得放宽门槛；确需放宽必须记录证据与理由。"处置方向：修订设计（光学、算法、曝光、靶标制造工艺）或补测（排除采集缺陷后重测）；禁止改用 §3.2 量级表口径、禁止扩大不确定度声明吸收偏差而不修订实现；
- 不确定度声明与实测不符（声明 k/1σ 明显低估）：先修声明（B2 面）再重测——"观测是'测量 + 不确定度'，不是真值"（C-5 附加 a），但门槛判据以 3σ 实测为准，不得以声明替代实测；
- 未达标项进入工作组"修订设计/补测"决定流程（PLAN §5.5 G4："未达标项有'修订设计/补测'的决定，不以放宽门槛收口"）。
