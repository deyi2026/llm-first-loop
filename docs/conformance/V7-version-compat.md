- 对应计划任务：PLAN §5.2 C5（V7 混合版本墙，`[可自执行]`，依赖 B3、第二版本族）；测试面分类：SPEC §11.3-a 软件测试（混合版本墙（V7））

## 1. 目的与判据引用

本规程规定 V7 混合版本靶标墙对旧版读码器的误读测试方法与留证要求。

SPEC §11.2 门槛表 V7 行（逐字）：

> | V7 | 版本兼容 | 混合版本靶标墙对旧版读码器误读 = 0 |

SPEC §5 C-3（逐字，全文）：

> C-3 版本位
> a) 图案必须携带版本字段；
> b) 读码器遇到未知版本必须输出"不可读（unknown version）"，禁止猜测或降级解释为任何已知 ID；
> c) 新图案族版本的发布必须通过 V7 混合版本测试（VC-3），不达标组合不得发布。

SPEC §10 VC-3（逐字）：

> VC-3 发布门禁：任一新旧版本组合必须通过 V7（混合版本靶标墙对旧版读码器误读 = 0）方可发布；不达标组合不得发布，无豁免通道（Q8 裁决）。

SPEC §5 C-2 a) 相关句（逐字，第二版本族来源）：

> a) **在 [TBD-G] 裁决前，强制码族暂定 AprilTag 36h11**（36 位、最小汉明距离 11、可纠正 ≤ 5 位错误；官方图库可用码字 587 个，见 12.1-a）；最终选择 [TBD-G]（候选另含 tagStandard41h12，数据密度更高、检测距离略降，见 12.1-a），裁决后按决议更新本项；不允许出现"必须指定而尚未指定"的空档；

SPEC §11.3-a（逐字）：

> a) 软件测试：混合版本墙（V7）、降级行为（V4）、注入故障集（V8）；

判读口径（依上述原文归纳，不新增判据）：

- 被测对象：旧版读码器（声明支持范围 = 旧版本族）扫描混合墙（旧版本族 + 新版本族靶标同墙混布）；
- "误读"操作定义（由 C-3 b 组合得出）：旧版读码器对新版本族靶标输出任何已知 ID（即"猜测或降级解释为任何已知 ID"）计为误读；合规替代行为为——不输出，或显式输出"不可读（unknown version）"状态；
- 判据零容忍：误读 = 0；任一误读即该新旧组合未达标；
- 本门槛同时是 VC-3 发布门禁的测试依据：不达标组合不得发布，无豁免通道。

## 2. 前提与样本

- 混合版本靶标墙：同一墙面混布旧版本族靶标与新版本族靶标；两族各自数量与布局 SPEC 未规定——**由工作组定 / 随待发布组合的发布声明一并公开**（占位：旧族 O_V7 个 + 新族 W_V7 个）；
- 旧版读码器：B3 构建配置为只支持旧版本族（其 11.1-a 声明"支持的码族与版本"= 旧族）；
- 第二版本族：待 C-2 [TBD-G] 裁决（候选含 tagStandard41h12，C-2 a 原文）；裁决前允许以占位族 / 模拟版本位做**通道验证运行**（simulated，标注"非判据运行"）；正式 VC-3 门禁组合必须用已裁决族；
- 版本位承载：PLAN §13.1 D-09 ① 暂定"码族标识即版本 + 保留位段"（暂定非裁决，PLAN 原文口径）；
- 依赖（PLAN §5.2 C5）：B3、第二版本族图案（B6 生成工具链产出，附布局 JSON 与清单哈希作真值）；
- 合成先行（11.3-a 软件测试）→ 物理打印墙 `[需外部]`（打印、张贴）；
- 样本量：墙的靶标总数与两族配比无 SPEC 数值——由工作组定。

## 3. 设备与工具

- 软件：B6 生成器（两族图案 + 布局 JSON + 清单哈希）、B3 旧版读码器构建、B7 V7 runner；版本记入回执；
- 真值链：墙布局清单（含每靶族属、版本、ID）+ 清单哈希——无清单即无误读判定基准（见 §4 中断点）；
- 物理段 `[需外部]`：打印（激光或喷墨 + 亚光纸，PLAN §4.4 口径）、墙面张贴。

## 4. 步骤

1. 前置核对：第二版本族来源合法（C-2 裁决状态；未裁决则仅通道验证，标 simulated + 非判据）；**中断点：以未裁决族冒充正式组合 → 停**；
2. 生成混合墙：旧族 + 新族混布；产出布局 JSON 与清单哈希；**中断点：无清单 / 哈希不匹配 → 真值缺失，停**；
3. 配置旧版读码器：声明支持范围 = 旧族；记录 reader_id / reader_version；
4. 扫描全墙（合成面：逐样本送入；物理面：整墙采集）：收集全部输出与"不可读（unknown version）"状态；
5. 对照统计（旧族靶标）：应正常读出（读出率异常另行记录，不属 V7 判据）；
6. 误读判定（新族靶标）：输出任何已知 ID 计误读 1 次；不输出或 unknown version 为合规行为；
7. 判定：误读 = 0（零容忍）；
8. VC-3 门禁结论：该新旧组合"可发布 / 不得发布"；
9. 回执落盘（README §3 约定；**simulated 必填**）。

### 最小冒烟步骤（无全量资源时先跑通流程）

> 性质：只验证"样本链路、流程与回执能跑通"，**不产生任何门槛证据**；冒烟回执的 `simulated` 必须为 `true`（PLAN §0.4：simulated 不得写成"实测"）。

**S1 冒烟一次**

- (a) 生成冒烟板：执行 `README.md` §2 的冒烟板命令，确认末行 `manifest_ok True`、四件产物齐全；
- (b) 按 §2 登记混合版本样本清单的占位表（现行族 1 条 + 预留的新族占位行 1 条），核对 §5 回执中「旧读码器误读数」字段可逐样本填写；不执行读码；
- (c) 按 §5 回执格式落一份冒烟回执（`simulated: true`），核对必填字段齐全后停止——**不得据此填写 §1 的任何判据结论**。

- **跑通判据**：冒烟板四件齐全且清单复核通过；占位样本表与回执的误读计数字段一一对应；
- **止步点**：无第二版本族与旧版读码器，版本墙行为不可执行，冒烟止于样本清单。

## 5. 回执格式

JSON 字段清单（runner 产出，落盘约定见 README §3；**本门槛 simulated 为必填字段**）：

| 字段 | 类型 | 说明 |
|---|---|---|
| gate | string | 固定 "V7" |
| **simulated** | boolean | **必填**：true=合成墙 / 占位族通道验证；false=物理打印墙 + 已裁决族正式判定 |
| wall | object | {old_family, new_family, n_old（O_V7）, n_new（W_V7）, layout_manifest_sha, layout_ref} |
| reader | object | {reader_id, reader_version, supported_families}（旧版读码器声明） |
| old_family_read_count | integer | 对照侧：旧族靶标读出数 |
| unknown_version_count | integer | 新族靶标上"不可读（unknown version）"输出数（C-3 b 合规行为） |
| silent_count | integer | 新族靶标上不输出数（合规行为） |
| misread_count | integer | 新族靶标上输出任何已知 ID 的次数（**必须 = 0**） |
| misread_details | array | 若有误读：逐条 {target, output_id, evidence}（零容忍，任何一条即未达标） |
| vc3_gate_conclusion | string | 该组合可否发布（VC-3） |
| verdict | string | V7 判定 |
| command / env / head_sha / exit_code | — | README §3 通用要素 |

## 6. 失败处置

- 误读 > 0：V7 未达标，该新旧版本组合**不得发布，无豁免通道**（VC-3 / Q8 裁决原文）。按 SPEC §11.2 验证纪律（逐字）："门槛未达标时修订设计或规范，不得放宽门槛；确需放宽必须记录证据与理由。"处置方向：修订图案族设计（版本位承载方式 C-3、码族互相关抑制）或修订读码器版本处理（严格执行 C-3 b"禁止猜测或降级解释"）后重测；
- 读码器对新族靶标"猜测为旧族已知 ID"：正是 C-3 b 禁止的行为，属实现缺陷，修订后重测；
- 通道验证（simulated）结果不得写成"实测通过"（PLAN §0.4）；正式判定必须 physical 墙 + 已裁决族 + simulated=false 回执。
