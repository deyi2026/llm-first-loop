## 1. 目的与判据引用

本规程规定 V1 自检时延的测量方法、判读口径与留证要求。**V1 是非合规判据**：不参与合规判定，只作 11.1-d 声明与 V8 期望行为输入。

SPEC §11.2 门槛表 V1 行（逐字）：

> | V1 | 自检时延（可用性指标，**非合规判据**） | 全流程 P95 < 100 ms；超时降级为逐靶串行并报告，不判失效。本项不参与合规判定，只作 11.1-d 声明与 V8 期望行为输入 |

SPEC §11.1-d（逐字）：

> d) 时延分布（对应 V1）；

SPEC §13.1 Q1 行（逐字）：

> | Q1 | 自检时延 | 非合规判据；11.1-d 声明项 + V8 期望行为输入 | 待 V1 实测（可用性指标） |

判读口径（依上述原文归纳，不新增判据）：

- 测量对象为"全流程"时延的分布，统计量为 P95（对照值 100 ms 为 SPEC 已写明数值；本项**非合规判据**，超标不判失效）；
- "超时降级为逐靶串行并报告，不判失效"是**期望行为**：超时发生后，系统必须实际发生降级且产生报告，这本身是可验证的行为要求；
- 产出物为 11.1-d 声明材料（时延分布），并作为 V8 期望行为的输入。

## 2. 前提与样本

- 依赖：B3 读码器封装（PLAN §5.2 C1 依赖 B3）——被测对象是 B3 构建的全流程链路；
- 外部资源：正式门槛数据按 SPEC §11.3-c 属计量测试；若在计量台架环境采集，依赖 C0 档期 `[需外部]`。参考实现上的软件面分布可先行（标注 simulated/非正式）；
- "全流程"的操作边界：判据句未定义起止点。建议口径——起点为 C-5 `timestamp` 字段所记图像采集时刻（该字段定义为"图像采集时刻"），终点为 C-5 观测可被消费方读取。此为**操作定义建议，非 SPEC 判据原文**，必须在 11.1-d 声明中公开并经评审确认后方可作为测量口径；
- 负载构成（单靶 / 多靶 / 阵列）与场景集合：SPEC 未规定，由实现方随 11.1-d 声明公开，不由本规程指定；
- 样本量：SPEC 未给出 V1 样本量对应 [TBD-*] 编号——**由工作组定**（建议随 11.1-d 声明方法一并裁决）；本规程中以 N_V1 占位，不填数字；
- 时基：传感器时基同步属设备侧例行动作（SPEC §1.2-d），测量前必须完成；计时域不统一时数据无效（见 §4 中断点）。

## 3. 设备与工具

- 被测读码器构建：B3（记录 reader_id / reader_version 与构建 HEAD SHA）；
- 计时基准：单一时钟域（同一主机时钟或已同步时基）；分辨率与回执中记录的计时工具版本足以分辨判据对照值（100 ms）量级——具体精度要求由工作组随样本量一并定，本规程不发明数值；
- 软件：runner 脚本版本、Python/解释器版本、关键库版本（回执记录，口径见 README §3）；
- 计量项 `[需外部]`：C0 台架档期（正式采集段）。

## 4. 步骤

1. 冻结被测构建：记录 B3 reader_id / reader_version、工作树 HEAD SHA；
2. 公布"全流程"边界口径（§2 建议口径或工作组认可口径），写入 11.1-d 声明草稿；**中断点：口径未经公布/评审即开始采集 → 数据无判读基础，停**；
3. 完成时基同步核对；**中断点：多时钟源未同步 → 停，数据无效**；
4. 按 §2 公开的负载构成与场景集合执行 N_V1 次全流程读取，逐次记录时延样本（起点/终点按步骤 2 口径）；
5. 计算分布统计量：P50 / P95 / P99（PLAN §5.2 C1 产出为"P50/P95/P99 分布"）；
6. 超时降级路径验证：构造使全流程超时的场景，观察并记录——降级是否实际发生（逐靶串行）、是否产生报告；**中断点：超时后既无降级也无报告 → 期望行为缺失，属实现缺陷，停并登记**；
7. 回执落盘（README §3 约定），并将分布数据编入 11.1-d 声明材料；
8. 在 V8 规程执行时，本回执作为"V8 期望行为输入"被引用（V8 回执含 v1_receipt_ref 字段）。

## 5. 回执格式

JSON 字段清单（runner 产出，落盘约定见 README §3）：

| 字段 | 类型 | 说明 |
|---|---|---|
| gate | string | 固定 "V1" |
| nonconformity_note | string | 固定声明："非合规判据"（对应 SPEC §11.2 V1 行原文标注） |
| n_samples | integer | N_V1 实际值 |
| p50_ms / p95_ms / p99_ms | number | 分布统计量（单位 ms） |
| reference_threshold_ms | number | 100（SPEC 判据句已写明数值；仅作对照，不构成合规判定） |
| full_flow_boundary | string | 步骤 2 公布的起止点口径（verbatim） |
| degrade_path_observed | boolean | 超时降级是否实际发生 |
| degrade_report_verbatim | string | 超时降级报告原文摘录（无则空并说明） |
| workload_declaration_ref | string | 11.1-d 负载构成声明引用 |
| simulated | boolean | true=合成/非正式采集；正式计量段为 false（建议统一携带，V1 非强制） |
| command / env / head_sha / exit_code | — | README §3 通用要素 |

## 6. 失败处置

- **本门槛不判合规**：P95 超过对照值 100 ms 不判失效（SPEC V1 判据句原文），但必须如实记入 11.1-d 声明并作为 V8 期望行为输入——禁止为改善数字而修改测量口径、剔除样本或重定义"全流程"边界；
- 期望行为缺失（超时后无降级、无报告）：属实现缺陷，修订实现后重测；该缺陷同时影响 V8 期望行为输入的可用性，须在 V8 回执中声明；
- 测量基础设施缺陷（时基不同步、边界口径未公布）：数据无效，补齐后重测；
- 总纪律（SPEC §11.2 验证纪律，逐字）："门槛未达标时修订设计或规范，不得放宽门槛；确需放宽必须记录证据与理由。"——V1 虽非合规判据，任何对照口径的放宽同样必须记录证据与理由。
