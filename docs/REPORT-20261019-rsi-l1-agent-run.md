## 2. 变异器实况（确定性，无需 LLM）

- 23 张有效卡中：22 张只报出 **1 类**缺陷（`unlinked_verification`），1 张报 0 缺陷，1 张（P21）解析拒绝。
- 22 张的补丁内容是**同一句样板**：`- Verification 未逐条通过前不结案（覆盖全部 N 条验证条目）`。
- 因此 A 臂相对原卡的**全部内容差**就是这一行（P01 实测 diff：`30a31,32` 新增 1 行 + 行尾换行差异）。
- 含义：这一轮测的不是"变异器修复能力"，而是"往所有卡尾巴上加同一句样板有没有用"。

## 4. 主跑（4 对，描述性；不出 D1–D4）

| card | family | 原卡 | A 臂（变异器+受限应用） | B 臂（自由改写） | A−B |
|---|---|---|---|---|---|
| P01 | A_effectiveness | 11/13 = .846（题 2/4） | 10/13 = .769（1/4） | 10/13 = .769（1/4） | **0.000** |
| P07 | B_completion_gate | 11/11 = 1.000（4/4） | 11/11 = 1.000（4/4） | 11/11 = 1.000（4/4） | 0.000 |
| P13 | E_dedupe | 9/9 = 1.000（4/4） | 9/9 = 1.000（4/4） | 9/9 = 1.000（4/4） | 0.000 |
| P19 | D_patch_verify | 9/10 = .900（3/4） | 9/10 = .900（3/4） | 9/10 = .900（3/4） | 0.000 |

- `Δ(A−B)` 均值 0.000，CI95 [0.000, 0.000]：**四对全部同分**。
- `Δ(·−原卡)` 均值 −0.019，CI95 [−0.057, +0.018]：唯一的差异在 P01，两臂都从 11/13 掉到 10/13（1 个 check）。
- 改写成本：A 中位 4,970 token vs B 中位 6,819 token，**比值 0.729**（受限应用比自由改写**便宜**，与预判相反——补丁应用输出更短）。
- 解题成本：A 中位 2,901 vs B 中位 3,519。

**怎么读这张表**：A 与 B 分数完全相同，说明"卡里这一行/这次改写"没有进入模型的实际判断路径；4 对里 3 对本来就是满分，唯一有 headroom 的 P01 两边同时掉 1 个 check——在 n=1 下不能归因于改写，只能记为"未观察到收益、也未见显著损害"。

## 5. 结论（按证据强度排序）

1. **本 held-out 集不能做 RSI 上线闸门**（强证据）：4 张卡里 3 张"不给卡"即满分；23 张卡里 22 张的原卡效应为 0 或 +1 check。在天花板下 D1（非劣 −0.05）恒成立，闸门会盖章放行任何东西。
2. **现版变异器不构成"内容级修复"**（强证据，确定性可复现）：22/23 张卡的补丁是同一句样板；A 臂相对原卡的全部差异就是这一行。它测不出"修复能力"，只能测"加一句样板"。
3. **agent 代跑下 A ≡ B**（中证据，n=4）：同一模型两臂同分，说明该干预未进入判断路径。
4. **受限应用更便宜**（中证据，n=4）：改写 token 比 0.73。原以为 A 更贵（多读补丁），实测 A 输出更短、净成本更低。
5. **人时收益主张作废**：agent 条件下"省人时"不存在，v1 的主端点不可恢复。

## 6. 对 RSI 实现的需求（可直接落到规格）

R1 **题目必须标定**：每道 held-out 题需实测"无卡基线"，只保留 0.3–0.8 通过率的题；≥0.95 的题进 `calibration_blocked`，不参与闸门。
R2 **闸门要能被证伪**：判据必须在"无差异"时返回 INCONCLUSIVE，而不是 SHIP。当前 D1（非劣）在天花板下等价于"永远通过"，须改为**双重门槛**：非劣 + 至少 1 个"可提升族"上的点估计 > 0。
R3 **变异算子要内容级**：结构类算子（去重、措辞、链接）只能做 lint；至少要有 1 个能改变 Discriminator 判据的算子，并用"变异前后解题分差"作为算子准入标准。
R4 **效率端点必须写明量纲、且方向要靠实测**：本次实测受限应用改写 token 比 0.73（A 更便宜），原因是 A 的输出更短，而不是"省人时"。若做 agent 代跑，效率端点应写成 token / 审阅行数，并在预注册里给出预期方向；"省人时"只能在有人参与的臂里测。
R5 **截断即无效**：推理模型下 `finish=length` 必须判无效重跑，否则假性压低分数。
R6 **可复现**：seed、冻结哈希、每调用 usage 与原文必须落盘（已实现）。
