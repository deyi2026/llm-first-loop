## 二、一手来源（arXiv，2026-10-11 检索；均为作者自报实验，本文未独立重跑）

### 1. arXiv:2610.12436 — Ecology of AI Agents: Collaboration Creates a Population Threshold for Takeoff
- 提交 2026-10-08；类别 cs.MA/cs.AI
- 核心：生态安全问题。以网络安全能力为适合度建立种群增长方程：个体能力不达标时群体不扩张；一旦允许协作，集体能力随种群规模上升，于是出现临界群体规模——低于它种群走向衰退，高于它即使个体能力未变也会起飞（strong Allee effect）。论文进而主张生态红队与种群节奏控制（小规模红队不能保证大规模部署的生态安全），并提醒能力提升会压低阈值、每代模型需重新估计。
- 边界：种群动力学的理论建模（未见真实部署验证）；「83% 的 interrupted runs 导向失败」不属于本篇，见备选区 2610.12375。

### 2. arXiv:2610.11600 — Error-Propagation Modeling for Failure Attribution in LLM-Based Multi-Agent Systems
- 提交 2026-10-08
- 核心：把多 Agent 失败归因做成可计算的误差传播模型，量化「上游节点的错误如何在拓扑中扩散、最终被记到下游」。
- 边界：模拟 + 基准任务；模型版本相关。

### 3. arXiv:2610.10126 — Know the Shape, Find the Fault: Topology-Conditioned Diagnosis of Multi-Agent LLM Failures
- 提交 2026-10-07（14:07:48Z）
- 核心：通信拓扑提供区分协调失效模式的结构线索。MAScope 两阶段：TSE 从缺少拓扑标签的执行轨迹重建通信拓扑，TC-Judge 用轨迹 + 预测拓扑 + 从另一批带标签轨迹估出的经验先验 + 人工写的拓扑失效模式描述做分类。
- 数字：χ²=409.9，p=1.2×10⁻⁷⁰；851 条 MAST-clean 轨迹上 gpt-mini Macro-F1 0.173→0.350（真实拓扑），预测拓扑 0.346，接近但未超过纯轨迹 gpt-5.4 基线 0.372；预计成本约为反复调用 gpt-5.4 诊断的 6%。
- 边界：依赖额外标注数据（带标签轨迹估先验、人工写失效模式描述）；预测拓扑口径未超过最强纯轨迹基线。

## 四、本期写作口径

1. 论文结论一律标注「来自作者自报实验，本文未独立重跑」。
2. 不把任一篇的数字当成行业定论；83% 一类数字只在明确归属的单篇内引用。
3. LFL 侧只讲本轮实测到的机制（outcome 不变量、租约 TTL、只读拓扑、结算状态），不吹「已解决多 Agent 可靠性」。
4. 结尾给读者可操作的三条分工建议，且明确 LFL 不是通用解决方案。
