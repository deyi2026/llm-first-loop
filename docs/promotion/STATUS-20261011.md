## 本轮最重要的一条坑（用户直接指出的）

**粘贴图片前正文是全选态，图片一粘就把正文整体覆盖。**
用 ClipboardEvent 注入图片时，若选区不是折叠光标而是选中了全文，图片节点会替换整篇正文，
表现为「正文消失，只剩一张图，页脚显示共 0 字」。

- 错误写法：`r.setStartBefore(para); r.setEndBefore(para)` —— 段落**边界**。
- 正确写法：`node=para.firstChild; r.setStart(node,0); r.setEnd(node,0)` —— 段落**文本节点内**的折叠光标。
- 粘贴前必须加硬断言：`if(selection.toString().length!==0) return 'ABORT'`，选区非空就拒绝粘贴。
- 每插一张图后必须复验 `pm.innerText` 字数未塌陷，再插下一张。

## 本轮新增的坑（已沉淀）

1. **`<templ>` 假阳性**：统计编辑器图片数时，`pm.querySelectorAll('img')` 会把编辑器渲染用的 `<templ>` 内克隆节点一并计入，贴 1 张图会显示 n=2。计数必须用 `[...imgs].filter(i=>!i.closest('templ'))`。
2. **md2html 的 `<h1>` 塌缩**：本工具把 Markdown `##` 转成 `<h1>`，头条会塌缩成一级标题且与文章标题混淆。已新增 `fixup_html.py` 做后处理（`<h1>`→`<p><strong>`，并去掉图注残留的裸 `!`），08/09 均须经它转换。
3. **PIL 边界检查抓到视觉模型漏报**：fig29 右侧方框实际画到 x=1036 超出 1000 画布，右边距=0；肉眼与视觉模型均未报。**排版问题必须以 PIL 像素边界为准，视觉模型只作补充。**
4. **「确认发布」按钮被覆盖**：`elementFromPoint` 在按钮中心返回 `TEXTAREA.byte-textarea.inner-input`，真实鼠标点击落空，必须用元素级 `.click()`（与既有记录一致，本轮再次实证）。
5. **CDP 回执解析**：自建 `_cdp.py` 时把 `m["result"]["result"]["value"]` 多写了一层 `.get("result", {})`，导致连 `1+1` 都返回 None。写完要用最简单表达式自测。
