4. **图床上传失败项会留在弹窗里**：点「确定」前先删掉 `.pic-select-image-item .error` 节点，否则失败项会被一起插进正文。

### 本轮新经验（可直接复用）
1. **md 图片必须靠发布链路单独插，转换链只留图注**：`md2html.py` 的 `inline()` 会把 `![]()` 拆成纯文本，所以 HTML 里 `<img>` 恒为 0，`grep -c '<p>fig'` 只查裸 fig 残段；正文里保留一句**人话图注**当落点锚，比留 `figNN` 占位好。
2. **头条插图不要用「点击标题行 + End」**：脚本按标题行坐标点击后，选择器实测落在文末（`anchorOffset` 指到最后一段），两图全被追加到正文末尾。改为 **Range.setStartBefore(段落) → 找 `.btn-upload-handle input[type=file]` → setFileInputFiles → 等到页面出现「已上传 1 张 / 上传失败 0 / 确定 可点」再点确定**，落点 100% 正确。
3. **上传成功判据不能靠固定 sleep**：第一次两图全「上传失败」，第二次同流程一次成功 → 必须轮询「已上传 N 张 + 失败 0 + 确定 enabled」三条件再点确定。
4. **知乎编辑器是 Slate，不是 ProseMirror**：block 全是 `div[data-block=true]`（头条是 `.ProseMirror` + `p/li`），按 `<p>` 找锚点必然 NO_ANCHOR。
5. **知乎合成 paste 不认 Range 光标**：`setStartBefore(block)` + `ClipboardEvent('paste')` 会把图追加到文末；`Cmd+Z`（modifiers=4）也删不掉。可靠链路 = **H2 前一块正好是空 FIGURE 块 → 直接点它 → 合成 paste 落到该块**；若该块非空则 `NOT_EMPTY`，改用「上一段末尾点击 → Enter 造空块 → 点空块 → paste」。
6. **知乎插图前置清理**：文末多余图用「点击图块 + Backspace」删（Backspace 有效、Cmd+Z 无效），删净再插。
7. **图片描述（caption）会在进入预览后被清空**：填 caption → 点预览 → 返回编辑，caption 归零；重填后直接走发布，标题/图/AI 声明不受影响。
8. **AI 声明要点 label 里的 input**：`label` 上 click 不生效，必须 `label.byte-checkbox` 内的 `input[type=checkbox].click()`，之后状态读 `checked`（引用AI value=4）。
9. **公网验收必须走浏览器 fetch + DOMParser**：`curl` 头条拿到的是 JS 壳（200 但正文空）；在已登录的 Chrome 里 `fetch(canonical).then(r=>r.text())` + `DOMParser` 解析，才能真正验到正文/图/标题。
10. **审稿必须独立且拿到 shell**：子代理无 shell 时 A4-A7 数值只能判 UNVERIFIED；给它 fs 不给 shell 也行，但数值复算要由发布者会话跑一遍并把命令+输出写回 ledger。
11. **来源数字自己内部不自洽时，要在正文里说**：SWE-bench 报告批次明细合计 112/106 与合计行 114/105/92.1% 冲突 → 正文改成自报口径 + 括注 + 「不对这个数字背书」，比硬报一个漂亮数字诚实。
