## 本轮新经验（可直接复用）
1. **头条整篇 HTML 合成 paste 一次成型**：`.ProseMirror[contenteditable]` dispatch `ClipboardEvent('paste', {text/html})` → 47 段正文 + 表格 + 引用 + 强调一次还原（比逐段 insertText 快且不丢格式）。平台会把 `h2` 归一为 `H1`，属平台行为，不需要对抗。
2. **粘贴前必须先清掉 md 图片 alt 残段**：md→html 转换若不处理 `![]()`，会留下 `<p>!图注文案</p>` 这种裸段。发布前用 `grep -o '<p>![^<]*</p>'` 自检。
3. **图 40 上传失败的真实原因是路径拼接**：`os.path.dirname(os.path.abspath("."))` 得到的是**父目录**，拼出来是 `.../docs/img/...`（不存在）。插图统一用 `os.path.abspath("img/xxx.png")`（相对 cwd），或先 `os.path.exists()` 断言。
4. **图床上传失败项会留在弹窗里**：点「确定」前先删掉 `.pic-select-image-item .error` 节点，否则失败项会被一起插进正文。
5. **头条插图的可靠链路**：真实鼠标点击目标标题行（`Input.dispatchMouseEvent`，先 `scrollIntoView({block:'center'})`）定位光标 → 点 `.syl-toolbar-tool.image .syl-toolbar-button`（工具栏按钮无 tooltip，认 class）→ `DOM.setFileInputFiles` → 删失败项 → 点「确定」。
6. **平台自带的首图卡片不可删**：`syl-selected-card` 节点（`contenteditable=false`）删不掉，只能接受其位置；本次它落在正文最前，正好当引子后的首图。
7. **作品声明在编辑器底部**：勾 `label.checkbox-with-tip` 里 innerText 为「引用AI」的 input（value=3）。「头条首发」默认**未**勾，选了等于向平台承诺 72 小时内仅在头条发布 —— 未获用户确认不勾。
8. **知乎域名当前本机不可达**：`zhuanlan.zhihu.com` 解析到 198.18.x.x fake-ip 段，TLS 握手被重置（curl 000 / Chrome chrome-error），对照 `www.zhihu.com` 302、`www.toutiao.com` 200 正常。属网络层问题，不重试到底，卡点上报。
