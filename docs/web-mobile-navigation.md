# Web V2 手机端左右侧栏（v0.6.36）

在手机浏览器访问 `/ui/v2/`：

- 左上角 `☰` 打开会话/学习/服务等导航抽屉；点遮罩或选定导航项关闭。
- **屏幕右边缘中部的 `◂` 箭头**打开右侧面板；展开后箭头移至面板左边缘并显示 `▸`，点击即可收起，不遮住面板内容。桌面端沿用两栏之间的同款箭头。
- 手机右面板包含设置、运行任务、会话绑定、预览等页签；关闭入口、遮罩和 Escape 均能收起面板。右侧箭头始终独立于顶栏操作菜单，并在左侧抽屉打开期间暂不接受点击。
- 触摸区域至少 44px 宽，随 iOS 安全区缩进；屏幕 320px 宽度仍不应出现横向页面溢出。

## 验收边界

在**目标源码**启动的 WebUI 上执行 `scripts/qa_web_v2_session_mobile.py`（需安装本机 Chrome 和 Python Playwright）。检查 320、375、390、430、768、1366px 六种视口、固定右边缘位置、`◂/▸` 状态、开合、左侧抽屉、会话切换、消息滚动与浏览器异常。脚本用隔离 API fixtures，**不验证真实生产账号的数据操作或真实 iPhone Safari**。

部署应执行来源绑定构建、受控发布和所需服务重启，再读取实际 Web/Feishu/Learning 进程身份和在线版本。若手机仍显示旧图标，请先核对页面路径是否为 `/ui/v2/`、Web 返回版本与页面缓存；仅 HTTP 200 不能证明新组件已经加载。GitHub 版本号升级不等于 tag/Release 已经公开发行。
