# 飞书渲染支持矩阵（Render Matrix）

> F5(2026-08-14) 建立：飞书 Card 2.0 `markdown` 元素对 markdown 特性的支持范围。
> **状态标注**：✅ 已验证支持 / ❌ 实测不支持 / ⚠️ 未验证（需人工确认一次后固化）
> 验证方式：`python scripts/feishu_smoke.py --chat-id <真实chat_id> --render-matrix`
> （发送下述各特性样本，人工在飞书端确认后更新本矩阵）。

## 矩阵

| markdown 特性 | 状态 | 项目处理 | 备注 |
|:---|:---|:---|:---|
| 粗体 `**x**` | ✅ | 透传 | 错误醒目已用（⚠️+加粗） |
| 斜体 `*x*` | ⚠️ | 透传 | 未单独验证 |
| 行内代码 `` `x` `` | ⚠️ | 透传 | 未单独验证 |
| 代码块 ```` ``` ```` | ✅ | fence 感知分段（闭合/重开+语言标签） | 分段已实测 |
| 链接 `[t](url)` | ⚠️ | 透传 | **未验证**（若不可点击需降级为裸 URL） |
| 无序列表 `- x` | ✅ | 透传 | 表格 bullets 化依赖 |
| 有序列表 `1. x` | ⚠️ | 透传 | 未单独验证 |
| 任务列表 `- [ ] x` | ⚠️ | 透传 | 未验证（可能显示为普通列表） |
| 引用块 `> x` | ⚠️ | 透传 | 未验证 |
| 表格 `\| a \| b \|` | ❌ | **转 bullet 列表**（G2 列语义 + 超限重试） | 实测不可靠（M43 结论：API 不报错但渲染无保证；230099/11310 超限错误） |
| 行内公式 `$...$` | ❌ | 检测 + "公式请于 Web 端查看"降级提示 | 卡片无 KaTeX |
| 块级公式 `$$...$$` | ❌ | 同上 | |
| 图片 `![alt](url)` | ⚠️ | 透传 | 未验证（飞书卡片图片元素与 markdown 图片语法不同） |
| 水平线 `---` | ⚠️ | 透传 | 未验证 |
| 删除线 `~~x~~` | ⚠️ | 透传 | 未验证 |
| Emoji | ✅ | 透传 | 状态卡/状态条已用 |
| 超长单行（无断点） | ⚠️ | **F1 零宽空格折行**（>100 字符无空白行） | 2026-08-14 已处理 |

## 未验证项的降级预案（人工确认后按需启用）

| 特性 | 若不支持的处理 |
|:---|:---|
| 链接 | 发送前正则提取 URL，markdown 链接降级为 `文本（https://...）` 裸 URL |
| 有序列表/任务列表 | 保持透传（即使渲染为无序列表信息不丢失）；任务列表可转 `- [x]` → `- ✅/⬜` |
| 图片 | 检测 `![alt](url)` → 追加"（图片请于 Web 端查看）"或尝试卡片图片元素 |
| 引用块 | 保持透传（普通段落渲染信息不丢） |

## 更新约定

- 每次真实冒烟（`--render-matrix`）后在飞书端人工确认，将 ⚠️ 更新为 ✅/❌。
- 新增降级处理时同步更新本项目处理列与本矩阵。
