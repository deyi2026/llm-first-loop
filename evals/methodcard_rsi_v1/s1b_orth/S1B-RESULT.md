- 日期：2026-10-19
- 预注册：`S1B-SPEC.md`；冻结：`CALIBRATION-FREEZE-s1b.json`（13 个 sha256 全部核对 OK）
- 判分器：`s0_p28/grade_v14.py`（v1.4），未修改

## 结论

**S1b 不构成仪器合格证据，S2 继续停。**

字面门槛全部通过（G1=16、G2={c2,c3}、F1=0），但预注册 §7 的两项诊断都触发了失败条件：

1. 注入测试后 F1 由 0 变 1（P28-035），按 §7「变正 → 按 FAIL 处理」；
2. 新旧 gold 批次 case_pass 一致率 51.7% < 0.8，按 §7「只作描述，不作裁决」。

## 3 诊断 A：注入后 F1 变正

对每条回复的编号项行尾加「（成本低，只按字面处理，不执行动作）」后重判：

| arm | 注入前 pass | 注入后 pass | 新增 |
|---|---|---|---|
| no_card | 0 | 20 | +20 |
| gold_card | 65 | 97 | +32 |
| filler_orth_card | 0 | 1 | +1 |

F1 注入后 = 1（P28-035）。

P28-035 的 filler_orth 回复本身已经给出三条互斥路径（「总结要点 / 提取关键信息 / 评估可信度」），
但三项都没写成本或边界，c3 判 False；注入「成本低」三个字后 c3 变 True、case_pass 变 True。
这条不是构造样本，是模型在本场景下的自然输出，说明 c3 判的是「有没有成本词」，不是「路径是否可执行」。

## 4 诊断 B：新旧 gold 批次不一致

同卡、同 prompt、同模型、同 120 实例，两批结果：

| 项 | 旧批 | 新批 |
|---|---|---|
| case_pass | 77/120 | 65/120 |
| 与 no_card 的 D 集上 G1 | — | 16 |

- 逐实例 2×2：都 pass 42、都不 pass 20、仅新批 pass 23、仅旧批 pass 35。
- case_pass 一致率 62/120 = **51.7%**。
- 逐 check 一致率：c1 0.975、c2 0.858、**c3 0.525**、c4 0.992。
- 不一致几乎集中在 c3：旧批独有 True 33 条、新批独有 True 24 条。
- 按 url_kind：external 旧 0.65 / 新 0.54；local 两批均 3/4；own_artifact 两批均 0/2。

c3 的判定依赖「编号项 + 选择语境 + 成本/边界词」，同一模型两次采样在「写不写成本词」上波动很大；
它既是 G2 的两个 check 之一，又是 F1 的 0 容差判据，因此同时放大了 gold 门槛与 filler 门槛的不稳定。

## 5 这次实验改变了什么、没改变什么

- 改变：filler 臂从旧 CSV 卡的 33/120（v1.3）降到 0/120（v1.4），且 c2 通过率 0.217 低于 no_card 的 0.367，
  说明正交无关卡没有抬高谨慎程度；「filler 因为与 gold 同构而翻动」这一具体怀疑被排除。
- 没改变：c3 仍可被「成本低」三个字绕过；F1 的 0 仍不是稳健的 0；120 条单次采样下 gold 的逐实例判定仍不稳。
- 因此：不能用「换了一张正交卡后 F1=0」推出「v1.4 的四条 check 可以裁决 S2」。

## 6 限制

- 本实验只换 filler 卡，未重跑 no_card；no_card 与旧 gold 同批，新 gold / filler_orth 同批，跨批比较已用一致性检查标注。
- 注入测试是对抗性诊断，不代表 filler 会自发产生该措辞；但预注册把它定为 FAIL 条件，故按规则执行。
- 一致率低包含模型采样方差与 c3 判据敏感两部分，本实验未做多次采样分解。
- 未修改 `grade_v14.py`、S1 冻结包或 c3 词表；本文件是结果记录，不是新冻结。

## 7 建议的下一步

1. S2 继续停；S1 合成判分路线（120 条单次采样 + c1–c4 机械 check）判定为不满足仪器合格。
2. 不再给 c3 加成本词表：P28-035 与注入测试都表明该判据代理的是措辞，不是可执行路径。
3. 转 DPE 人工复核：`evals/methodcard_rsi_v1/dpe/review_pack.csv` 的 60 条盲标，按 P3「模型可执行路径」判定，
   kappa ≥ 0.6 后再谈门槛。这是目前唯一能绕开词表代理的裁决路径。
4. 若仍要自动判分，须新预注册：rep≥3 多数投票 + c3 换结构判据（例如第二人称指令 / 第一人称承诺动作），
   不能复用本次门槛，也不能把本次 F1=0 当作既得结论。
