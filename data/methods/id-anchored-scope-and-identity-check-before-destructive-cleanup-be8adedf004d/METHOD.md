## Trigger
需要在有活动写入者的生产/共享数据存储中，按历史审计清单定位并冻结、迁移或删除一批会话/运行产物；且手头存在记忆计数、旧路径印象或 mtime 之类代理过滤条件。

## Discriminator
两条当时即可用的权威事实可把候选空间缩到个位：①每个目标带跨子树复用的稳定唯一 id，其身份可由文件自身首条记录（session.created 的 id/ts）权威判定；②存在指针文件（如 shared_current_session.json）一锤定音标明当前活动会话。因此 mtime 等代理过滤命中的任何清单外成员都不需要扩大枚举，只需一次身份读取即可判定去留。

## Short path
- 解析权威根：读取 WORKSPACE_ROOT 类环境变量/配置并 pwd 校验后再断言数据路径；未知量：生产数据真实位置。
- 以全部已知 id 前缀对整个数据树做一次新鲜 find，得到每个 id 的完整文件足迹（覆盖 event_logs/sessions/audit/episodes 等所有子树）；未知量：每个 id 的全部产物。
- 对命中但不在清单内的成员做身份甄别：读当前会话指针文件定活动会话，读每个文件首条记录定创建时间与归属；未知量：哪些是污染、哪些是活动或合法延续。
- 结构性残留（空会话目录等）按目录名编码模式在存储根下扫描求全集，不按记忆中的位置与数量；未知量：残留全集。
- 冻结（manifest+sha256）→ 迁移后重哈希 → 按 id 断言各数据根零残留（保留项注明原因）；权威校验全部通过即停止发现。

## Stop conditions
- 所有目标 id 在全部数据子树的足迹已枚举完毕，且每个清单外成员的身份已由权威记录判定
- 迁移后重哈希与按 id 的零残留断言全部通过，即停止扫描与发现
- 若权威指针显示当前活动会话落入候选集，先排除它并复核甄别逻辑，暂停一切批量删除

## Verification
- 对 manifest 中全部非空文件在迁移后重算 sha256 并比对
- 对每个 sid 在全部数据根执行 find 断言为空；唯一保留项在 manifest 注明理由
- 最终清单与计数来自本次 find 证据而非记忆；与历史审计记忆不一致处（数量、路径、额外子树）已逐项解释或复核

## Counterexamples
- 只读分析任务（不冻结/不删除）：身份甄别与零残留断言是多余开销，直接读取所需文件即可
- 存储无权威活动指针（没有 shared_current_session 类文件）：本方法无法可靠排除活动写入者，应退回锁文件存活/最近写入时间等启发式并保守处理
- 同一实体在各子系统使用不同命名键（id 不跨子树通用）：按单一 id 全树扫描会漏检，需先建立子系统键映射
- 工具输出无法用窄查询收窄且无替代命令时：分页读取截断 blob 是唯一途径，不应机械套用'换窄查询'
