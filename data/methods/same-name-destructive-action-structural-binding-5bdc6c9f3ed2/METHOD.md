## Trigger
目标行的操作控件可访问名不唯一（同名按钮数=行数）、动作不可逆，且页面语义快照对象携带 parent/child relations 与每行唯一 href，执行工具按 kind+name 匹配。

## Discriminator
当时已知：(1) 快照对象已含行级 relations（标题链接→行容器→操作区→按钮）和每行唯一 href，可从唯一锚点反查按钮归属；(2) 用户点名属性（保留阅读数 5 的那条）已在截图/快照中区分同标题两行；(3) 后续多次快照反复出现相同元素 id（如 el_0dd7…跨 bsnap 复现），证明文档未变、再枚举是冗余；(4) 首次范围读回执 complete:false 且 next_start=4000，说明已捕获数据还有未读内容可续读。

## Short path
- 用用户点名的区分属性（阅读数/时间）在现有快照中标定目标行——解决未知量'哪行是 #3'
- 续读已捕获快照剩余范围或提取其中含 /p/ href 的行内标题链接——解决'#3 的唯一 ID'
- 沿 relations 从标题链接走到行容器再到操作按钮，建立同名按钮↔行的 1:1 绑定——解决'按钮归属'
- 独立交叉验证后才认定目标（实地访问候选 ID 核对标题；作者主页文章计数与 2×保留期+1×删除期 吻合）
- 若执行器只按名匹配：不点击，输出绑定链+目标 ID，移交用户或改用可寻址入口

## Stop conditions
- 绑定唯一且工具支持按 ref/id 寻址：执行，随后重观察确认该行消失且保留行（5 阅读）仍在
- 绑定完成但执行器只按名匹配且动作不可逆：停止动作，交付绑定链与已核实 ID 供用户手动执行或选择替代路径
- 用户点名的区分属性在任何捕获观察中都找不到：询问用户或做针对性补充观察，禁止按列表位置顺序猜目标

## Verification
- 同名按钮计数=行数，且每条 标题链接→行容器→按钮 绑定链的节点互不共享（一一对应，而非只验证目标一条）
- 目标身份经独立来源确认：访问候选 URL 核对正文/标题，作者页文章计数交叉吻合
- 如实际执行删除：重读列表确认行数减一且保留行未被误删

## Counterexamples
- 各行控件可访问名本身唯一（aria-label 含标题/ID）：直接按名操作，无需结构绑定
- 快照无 relations、按钮与行容器无父子结构（扁平 DOM）：结构绑定不可用，应逐行观察或另想选择器策略
- 捕获与执行之间列表会变（按实时阅读数实时排序、元素 id 过期）：旧绑定不可信，执行前必须重观察并重绑
- 只读探索或非破坏性任务：宽枚举成本可接受，不必先穷尽已捕获结构再扩展
