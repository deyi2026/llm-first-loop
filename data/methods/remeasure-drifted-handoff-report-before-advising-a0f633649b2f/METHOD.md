## Trigger
接到前一会话/他人写的交接或收尾报告，并被要求给后续决策建议（是否推送、如何处置剩余条目等）；报告内嵌自己的写作时点锚（列出的提交与时间），且其中至少一条决策相关的可变状态主张（工作区 clean、未推送/ahead N、基线→现值计数、K 个先例）在报告时点之后可能已变化；或报告自述曾依赖记忆/旧路径行事

## Discriminator
报告自嵌时间锚与当前时点之间的空隙 + 每条可变主张都存在本地廉价权威重测源：git status/untracked（z 口径）、remote-tracking reflog 中带时间戳的 push 事件、git ls-tree 在基线提交上的计数、目标目录实际文件数。空隙存在即把『报告=快照≠现值』设为默认假设，而不是把报告当权威、也不是把不符当谎言

## Short path
- 从报告抽取决策相关主张，并用报告内嵌的提交时间定位其写作时点（未知量：报告描述的是哪个时刻的世界）
- 一次复合重测：porcelain/untracked（z 口径）、最近 log、当前计数（未知量：哪些主张已漂移）
- 推送类主张查 remote-tracking reflog 的事件时间戳；事件时间晚于报告写作时间 → 分类为『过期』而非『错误』（未知量：报告是错的还是旧的）
- 基线计数在 referenced 大提交的父提交上用 ls-tree 重测；只保留自洽增量（基线+增量=现值）
- 历史无法复核的主张（如全新增文件上的『N 处替换』）改验最终内容（敏感 token 是否 0 命中），并显式标注『不可复核但不矛盾』
- 建议只建立在重测值与时间线推断上；每处不符给出 stale/wrong/unverifiable 分类后再给 P0/P1/P2 建议

## Stop conditions
- 所有决策相关主张已被重测，或已显式分类为本地不可核对
- 后续建议全部锚定实测值；过期项已按时间线解释而非指控报告说谎

## Verification
- 增量自洽：基线+各提交增量=当前计数（如 1038+518=1556、645+19+1=665）
- reflog push 事件时间戳与报告列出的提交时间能拼出单一无矛盾时间线（09:12 提交、09:24 推送 → 报告写于其间）
- 不可复核主张至少给出不矛盾性检查（如 541 个新增文件中敏感用户名 0 命中）

## Counterexamples
- 报告主张全是不可变历史事实（决策理由、提交信息、已收档裁定内容）——直接采信记录，重测现值无信息量
- 主张指向本地不可测的外部事实（评审结论、群 chat_id、他人是否见过报告）——标注不可核对即可，不为其消耗工具调用
- 报告由本会话数秒前生成且无并行写者痕迹（无 GUI/浏览器合并线、无其他会话活动信号）——漂移概率低，抽检一条高影响主张即可，不做全量审计
- 紧急止损场景且建议本身可逆、用户会自行复核——审计延迟成本高于错误建议成本时降级为抽查
