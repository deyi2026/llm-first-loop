## Trigger
机械判分器因阴性对照破防（内容无关条件把实例由 fail 翻 pass）而按观察到的失败样本收紧词法判据（加排除项/必备词），收紧后重跑的门槛全部通过，正准备宣布判分器合格并放行后续阶段。

## Discriminator
收紧前已知的两个事实足以预判词法修补可被注入绕过：(1) 阴性对照按冻结定义是『等长、同结构、内容无关』——凡度量表层结构/词形的判据，任何同构卡都能满足；(2) 翻动的 check 分布高度集中（本例 c3 为主、c1 次之、c4 零），指明主要翻动通道是表层计数型 check。由此可构造仅含新字面判据、不含目标语义的最小扰动作为决定性检验。

## Short path
- 读冻结规格/交接文档，取得阴性对照失败分布与对照卡定义；首要未知量不是『怎么改』，而是『每条 check 度量的是表层词形还是内容语义』。
- 读判分器源码，把每条 check 标注为表层型/语义型；预期表层型是注入弱点。
- 按处方实施收紧（离线重判存量文本，不重跑模型调用），得到数值门槛结果。
- 构造最小注入探针：向 filler 与 no_card 文本各追加一句只满足新字面判据、无目标行为语义的扰动（如仅声明『成本低、不执行动作』类字样），重判两臂；这是特异性判定的决定性一步。
- 探针翻动≥1 → 如实报告『数值过、探针败』：维持停阶段，不再迭代词表，转向已文档化的替代判分单位；探针 0 翻动 → 才可宣布仪器初步合格，并披露收紧所依据的样本来源（校准集内拟合风险）。

## Stop conditions
- 注入探针在 filler 与 no_card 两臂均 0 翻动，且非饱和 check 至少 2 条在工作。
- 判分单位已切换为语义证据（决策点行为证据 + 人工盲标复核），词法注入探针不再适用。
- 冻结文档/用户明确该门槛只认证表层格式合规，不承担行为归因。

## Verification
- 用至少 2 种不同措辞的注入句重跑探针，排除单字符串巧合。
- 确认注入只追加一行、未改动其余内容，diff 可审计。
- 复核各 check 饱和度：若多数 check 已饱和（几乎全 pass），门槛通过只剩 1-2 条 check 在支撑，不得读作整体特异性。
- 报告中同时给出收紧所依据的失败样本范围，明示校准集内拟合风险与离线重判的适用边界。

## Counterexamples
- 判分器本身是语义判定（人工盲标/LLM judge 判动作主体）时，词法注入探针不是正确检验，应改用标注一致性（kappa）与盲标包。
- 阴性对照失败源于纯实现 bug（如正则漏配带格式前缀的条目）且修正是对称的、有负例单测覆盖时，修复+单测即可，注入探针属过度工程。
- 存量文本被预注册冻结、禁止任何改动时，无法事后注入；必须在冻结期预注册探针臂。
- 门槛按设计只认证表层格式合规时，filler 翻动是预期现象，不应据此阻断流程。
