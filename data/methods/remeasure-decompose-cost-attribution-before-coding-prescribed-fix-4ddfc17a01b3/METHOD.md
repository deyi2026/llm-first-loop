## Trigger
执行前一轮产出的修复/优化建议清单，且至少一项的阈值、预算或裁剪对象派生自上一轮的量化归因，而该归因在证据库中只有聚合总数、没有按来源分解的测量回执。

## Discriminator
聚合总数是否为复合量且未分解：材料+模板+锚定范围这类复合量只报一个总数时归因不可信；计划参数抄了这个数就存在『修错组件』的结构性风险。『缺分量测量回执』这一事实在动手前即可观察，不需要事后答案。

## Short path
- 逐项审清单：标出参数依赖量化归因的项，与已被本 run 回执证实/证伪的项（后者直接结案，不重做）
- 对每个未验证归因，在源头做一次直接测量，把聚合数按 scope/锚点/来源分成分量
- 分量分布与上轮归因不符 → 先重设修复对象（针对真正的支配分量），再写代码；相符 → 按原方案实现最小改动
- 用同一测量口径复测改动后数值，把前/后数字与门槛判据一起写进提案
- 无测量回执且无法低成本测量的前提项 → 显式 deferred/rejected 并说明，不照叙事实现

## Stop conditions
- 每个动了代码的项都有改动前/后实测数字，且达到既定判据（如耗时低于硬上限）
- 所有未验证前提均已标注为已证实/已证伪/延后，无一项按上轮叙事照抄实现

## Verification
- 同一仪表复测：改动后数值与预测方向一致并跨过门槛值
- 提案/提交中的量化断言能指回真实测量回执；引用的登记类 ID 在登记库中真实存在，不制造看似可核验的引用

## Counterexamples
- 前提是机械契约事实且已有回执（如报错指名缺字段）——直接修，重新测量是浪费
- 上轮归因自带内容身份（sha/version）的测量回执且产物未变——只需核对身份，不必重测
- 测量本身就是被门禁的高成本/高危动作——改用低成本代理指标或先推迟该项
- 纯定性改动（命名、文档结构）不依赖归因参数——不适用
