## Trigger
通过 agent 浏览器通道操作一个自托管/大型 Web 面板，需要在会被截断的语义快照中定位并切换/操作某个由任务给定的唯一字面标识符（会话 ID、job ID）标识的列表条目

## Discriminator
当前回执/证据已同时显示两件事：(1) 目标条目的显示名里逐字包含该唯一 token（如会话条目名含 ea89d59c，页面内指令文本也点名该 ID）；(2) 同一区域存在可输入的原生搜索/过滤框（『查看会话』展开后的侧栏）。两者齐备时，再枚举快照、换措辞搜证据、读源码反推结构都是绕路；若 token 不出现在任何显示名中或根本没有搜索框，本判别不成立

## Short path
- pages 枚举并 rebind 到目标面板页；按 kind 投影（button/input）做一次有界快照，确认会话列表的展开按钮与侧栏搜索框存在
- 展开会话列表后，把任务给定的唯一 token 逐字输入侧栏搜索框——未知量『目标条目在哪』由原生过滤一步缩小
- 若浮出的是父会话（目标为嵌套子会话），展开该父节点树并点击子条目完成切换
- 有界快照核对切换已生效（URL/session 指示或消息内容匹配目标会话），立即停止探索
- 在面板输入框执行待办动作（如带来源标注的收口指令），并以权威台账回执核到终态

## Stop conditions
- 原生搜索+树展开已浮出目标条目并点击，且切换后快照的状态指示（URL/会话 ID/内容）与目标一致
- 搜索过滤零命中且确认 token 不出现在任何条目显示名中→终止搜索框路线，转树结构导航或直接以 session 参数构造 URL/API

## Verification
- 切换后的有界快照显示目标会话的内容/标识，而非原会话
- 对目标会话执行的动作取得权威台账（task/goal 记录）终态回执

## Counterexamples
- 面板没有原生搜索/过滤输入框，只有静态长列表→只能按 kind 投影分页浏览或读前端源码，本方法不适用
- 唯一 token 只存在于内部 ID 字段、UI 显示名不含它→搜索框过滤不到，需按树结构导航或直接 API/URL 携 session 参数
- 快照完整不截断→直接读快照定位即可，无需动用搜索框
- 目标只有模糊语义描述（『关于促销的那篇』）而无唯一 token→原生搜索同样退化为猜词，应浏览列表或向用户要标识符
