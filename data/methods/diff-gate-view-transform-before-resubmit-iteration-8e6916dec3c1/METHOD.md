## Trigger
评分型审查/发布闸门首轮未过阈值，且其契约明示比对目标是变换后视图（如『页面可见正文』）而非原始 artifact；或重交分数单调上升但停滞在阈值下方。

## Discriminator
内容已由独立来源核验为正确，而分数变化只与格式/形态调整相关（改内容不动分、改格式才动分）——缺口在 gate 的视图变换而非内容本身；且 gate 契约文本已写明比对对象，该判断在首轮失败后即可成立，无需多轮试探。

## Short path
- 首轮未过时先读 gate 契约：比对的是原始稿件还是变换后的可见视图？
- 若为变换视图，直接取得该视图文本（预览/已发布页 DOM 文本或 gate 回显的比对摘录），与稿件做一次机械 diff——未知量是变换规则，不是内容质量。
- 把 diff 归纳为有限的规范化规则清单（如去粗体标记、固定宽度折行、表格保留分隔符、图片→alt），在本侧对稿件复现该变换并确认 diff 归零。
- 按规则调整稿件形态后一次性重交；内容实质（论点、来源、数字）不因 gate 分数回退。
- gate PASS 后再独立验收最终线上页面，确认发布内容与过审稿一致。

## Stop conditions
- gate 通过且稿件实质内容与独立核验版本一致（只改了形态）。
- diff 已被有限规则完全解释且本侧复现归零，重交仍不过——判定为内容级缺口，转内容修补而非继续形态试探。
- gate 的重交次数或成本有真实限制（如对外可见发布）——停止试探，改在草稿/私密环境预实测渲染规则后再正式送审。

## Verification
- 用归纳出的规则在本侧变换稿件后，与 gate 视图文本 diff 为零（变换被完全解释）。
- 最终发布页 DOM 回读与过审稿件逐段对齐，确认形态调整未吞掉实质内容（如被『删除』的粗体段落在正文仍有等价表达）。
- 回溯确认：分数从首轮到通过的提升全部可归因于已枚举的变换规则，无未解释残差。

## Counterexamples
- gate 比对原始 artifact 与原始参考（无变换视图）——分数缺口即真实内容缺失，应修内容而非寻找变换。
- gate 输出逐项失败原因或差异回显——直接消费反馈即可，无需试探性重交。
- 单次提交不可重试、或每次尝试有对外可见的真实成本——不能用重交探测，必须先用已知平台渲染规则或草稿环境预规范化。
- 内容本身尚未经独立核验（来源、数字未验）——首轮低分的第一怀疑应是内容缺口，视图变换排查应排在其后。
