## Trigger
用户把另一位 agent 产出的分析/审查报告交给你，要求独立复核并给出自己的审查结论；报告混合硬数字、内部文档先例引用、带 ID 的外部引用、以及绑定某 HEAD 时点的门禁/测试状态断言。

## Discriminator
报告自身已为每条断言写明 provenance（数字对应 git/wc/grep、先例引用点名了文档与章节、外部引用带资源 ID、状态绑定某时点），且开局 git status 已显示未提交变更与报告自述的并发改文件迹象。这些开局事实足以按证据类型路由到各自最廉价的决定性检查，而『转述先例结论』类断言只有逐字读原文才能暴露方向反转；反爬插页/通用搜索结果对存在性问题零信息。

## Short path
- 把报告拆成五类断言：可复测数字/标识、内部文档先例引用、带 ID 的外部引用、时点性状态、本环境不可测项
- 数字类：用同一测量命令批量复跑并 diff；不一致时先核对测量口径（路径范围/过滤器/时间窗/棘轮基线）再定性为错
- 引用类：打开被引文档的被引章节逐字比对方向，而不是采信报告的一句话转述
- 外部类：按资源 ID 直取规范权威端点（论文 abs 页、包索引 simple 页）；反爬插页记为『未知』而非 404
- 状态类：以审计时点重跑定向门禁重定基线；若观察到 staged 在途修复，只验证不动手，建议等收口后复测
- 不可测项明确标注【未核验】，输出确认/更正/未核验三分结论表

## Stop conditions
- 每条承重断言已归入『已证实 / 带证据更正 / 明确未核验』三态之一
- 已拿到决定性更正（如引用方向反转）且剩余断言为低承重或不可测时，停止扩大重查面

## Verification
- 每条更正都附自家命令输出或被引文档原文位置
- 数字类更正在宣布前已确认双方测量口径一致（含基线/棘轮类过滤机制差异）
- 外部存在性结论只基于权威端点直接回执，不基于搜索结果或插页

## Counterexamples
- 报告只含主观判断/评分、无可复测断言时，数字复测与引用核对均不适用
- 工作区静止无并发写者时，『快照 vs 现在』与『只验证不动手』分支退化，可直接复测
- 被引文档不可读或不存在时，引用核对只能标『无法核验』，不得据转述采信或否定
- 权威端点被墙且无替代机器索引时，外部存在性保持未知，不得用插页或搜索空结果顶替
