## Trigger
一次代码编辑已验证通过，下一步要定位引用/测试该模块的文件，且该模块的完整 import 路径已在定位或编辑该文件时暴露

## Discriminator
模块的精确 import 路径是已知且唯一的：凡静态引用它的测试或消费者，其文件内容必含该字符串；泛化文件名搜索无法表达依赖关系，只会枚举噪声并被截断

## Short path
- 停一下：先取出被改模块的完整 import 路径（来自当初定位该文件的搜索命中或读取结果），作为唯一搜索键
- 以该路径字符串做内容搜索，得到直接 import 该模块的文件清单，而不是按文件名前缀枚举
- 从命中中识别主测试树文件（排除生成/镜像副本目录），运行该测试文件
- 通过即收口；如需扩大回归再按该测试所在目录扩展

## Stop conditions
- 内容搜索命中的主树测试已运行且退出码为 0
- 内容搜索零命中（说明动态导入或无静态依赖）时，才切换到目录/文件名级发现

## Verification
- 每条命中的匹配行确实是 import/from 该模块的语句，而非注释或同名子串
- 所选测试文件运行退出码为 0
- 如命中多份镜像副本，确认只运行了主树版本

## Counterexamples
- 目标是行为/集成级测试（如 CLI、端到端流程），不绑定单一模块 import 路径时，此法零命中，应按目录结构或测试命名约定发现
- 模块经动态导入或上层包 re-export 被使用，消费者文件中不出现该路径字符串，内容搜索会漏报，需辅以调用点分析
- 仓库存在多份生成/镜像副本时内容搜索会全部命中，若不先判断主树会误跑非权威副本并产生虚假信心
