## Trigger
配对干预实验返回 Δ=0 或噪声级差异，且下一步候选包括加重复轮、改进干预物（如改补丁）或改判分器时的排序决策

## Discriminator
两个零成本即可读取的事实：(a) 配对构造代码只按家族/标签匹配干预物与测试单元，从不检查触发条件是否出现在题面；(b) 已落盘的两臂输出失败位点逐条相同，且失败模式是自由文本撞 schema 未定义允许值的隐藏枚举评分项。二者同时成立时，Δ=0 度量的是配对与判分器，不是干预本身

## Short path
- 未知量：干预在所配测试材料里会被触发吗？读配对构造代码＋干预物 trigger＋题面：仅标签/家族配对 → 触发重叠必须手工核验；零重叠即判配对无效
- 未知量：Δ=0 是判分器看不见还是真没差？用已落盘两臂原始输出逐条比对失败位点：完全相同且属自由文本对隐藏枚举/schema 未定义允许值 → 判分不可满足，先修判分并用旧 artifact 重判验收
- 未知量：噪声底多大？仅在前两步仍有歧义时才做少量同臂重测，把旧的单次 Δ 归入抖动并给出波动范围
- 结论映射行动：配对无效→重建触发匹配表或换题换卡；判分失明→补 allowed values 或改语义裁判；两者通过仍 Δ=0→才接受真 null
- 闸门：配对有效性未确立前，不投入任何改进干预物的工作——改了也测不到（重复测空集）

## Stop conditions
- 零成本读取已证触发零重叠（配对无效）：停止解释 Δ、停止加跑、停止改干预物，转重建配对
- 失败位点审计证明判分器对干预差异不可见且评分字段不可满足：先修判分器并用已落盘 artifact 重判通过，再安排任何新跑

## Verification
- 逐对抽查：干预物的每个 trigger 关键条件都能在被配到的题面/任务描述中找到实例
- 判分器修复后对同一批已落盘原始输出重判：格式类失败归零、真实失败保留
- 报告任何干预 Δ 前：同臂重测噪声底已知，Δ 超过噪声底且配对区间下界>0

## Counterexamples
- Δ 显著非零且复现稳定：干预显然已被触发，跳过触发重叠审计，直接做机制归因
- 配对构造本身含内容/触发匹配而非仅标签：步骤一由构造保证，直接进判分器审计
- 判分是语义裁判而非机械枚举匹配：两臂失败位点相同更支持真无效应，不应推出判分失明
- 没有已落盘的逐条原始输出、只有总分：失败位点审计无法免费进行，小规模补跑属合理
