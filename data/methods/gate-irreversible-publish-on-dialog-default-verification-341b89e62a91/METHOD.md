## Trigger
浏览器自动化流程中，用户以简短指令确认执行一个不可逆的对外发布/提交动作，而该动作前的确认弹层首次暴露若干平台默认勾选的选项，其当前值在点击最终按钮前即可从 DOM 读出。

## Discriminator
弹层选项枚举输出中是否存在『对外约束/声明/收益』类选项，且其勾选值来自平台默认而非用户显式指令；配合一次新鲜的页面状态读取（URL、内容块数、图数、字数、按钮清单）确认未基于过期快照操作。两者在点击最终按钮前均已可观察，足以把『直接点确认』缩成『先核验再决定是否提问』。

## Short path
- 收到简短确认后先做一次新鲜状态读取（URL、正文块/图/字数、按钮清单），确认页面未过期且内容完整，不基于旧快照操作
- 触发最终动作入口（如预览并发布）后轮询弹层渲染完成，读取弹层全文与按钮清单，确认进入最终确认层
- 枚举弹层内全部 radio/checkbox 实际勾选态，按 已被用户指令覆盖 / 可逆呈现默认 / 约束性承诺 三分类
- 仅对无授权依据的约束性承诺与关键呈现选择（如封面模式）一次性打包提问，其余不再追问
- 获批后点击弹层内最终确认按钮，并验证 URL 或页面状态发生预期跳转才算发布完成

## Stop conditions
- 所有约束性选项均有用户显式授权依据（历史指令或本次指令明示）时，跳过提问直接执行最终点击
- 新鲜状态读取发现内容缺失、页面已离开目标页或最终按钮不可用时，停止并报告，不继续点击

## Verification
- 汇报给用户的选项状态表与 DOM 实际 checked/disabled 状态逐项一致
- 最终点击后观察到 URL 跳转或明确的发布成功状态，而非仅按钮点击回执

## Counterexamples
- 弹层选项在先前对话已被用户逐项确认，或指令本身已包含选项设置（如『单图封面、不声明首发，发布』）→ 直接执行，二次提问即摩擦
- 目标动作可逆（保存草稿、预览、撤销型提交）→ 无需此门控，直接执行
- 弹层仅含纯排版类选项且默认即用户一贯偏好 → 只汇报不提问
