## Trigger
用户指示开跑一个预注册 A/B（配对）实验，且满足任一：至少一臂含昂贵随机执行器需批量调用、吞吐压力可能迫使降级样本；执行者更换（人→agent）已改变主端点量纲；同时管线含确定性本地组件（README/docstring 明示只读检查命令）或端点为逐题阈值机械判分、题面已冻结可读。

## Discriminator
开跑前已在手的两条可观察事实：(1) README/脚本 docstring 已声明某臂变换是确定性、结构限定、且提供零成本只读检查命令——对全部冻结样本跑一遍即知该臂实际改变什么，若逐卡 diff 塌缩为同一句样板，配对比较无论结果如何都不含信息；(2) 判分器为纯机械 all_checks_pass 逐题打分——少数几次无干预基线调用即可测出天花板，多数题无干预即满分则非劣门恒真。两条事实都不消耗昂贵臂预算，却分别决定'干预有没有内容'与'端点能不能区分'。

## Short path
- 先读预注册端点与计量单位：执行者更换若摧毁主端点量纲（人时→agent 无此量纲），登记偏离/另立窄命题预注册后再谈跑（未知量：换执行者后命题还成立吗）
- 零成本探针：用文档明示的只读检查命令对全部冻结样本枚举确定性臂输出，落盘缺陷类别分布与逐卡 diff（未知量：昂贵跑要检验的干预到底改变什么；22/23 同一样板行 → 干预无内容）
- 廉价探针：抽 3-5 个单元跑无干预/有原卡对照（未知量：端点有无区分力；3/4 无卡满分 → 非劣门不可证伪）
- 两探针全过才放行昂贵臂预算；任一失败即停，交付不合格判定+再准入要求；如仍需跑只作描述性小样并明示不出统计裁决
- 吞吐被迫降级时切点先于任何解题结果并登记为偏离（本集已做对），降级后若已注定无裁决力则不补跑

## Stop conditions
- 确定性枚举显示绝大多数单元的干预塌缩为同一编辑，或无干预基线显示端点天花板 → 不放行完整跑、不出 D 类统计裁决
- 两探针通过（干预有实质变异、端点有 headroom）→ 按预注册放行、跑满样本后停止

## Verification
- 探针产物可复现落盘：逐卡 check 输出与 diff（如 22/23 同一样板行）、有卡/无卡对照表可由原始调用记录重放
- 最终报告的每个不合格判定都追溯到探针或原始 usage 记录；天花板/退化条件下明确声明未发布统计裁决

## Counterexamples
- 两臂均为真随机黑盒、无本地可枚举组件且无廉价基线可测时，首批小样本即探针，不得以'未先免费验证'为由拒跑
- 端点为连续分数且已知有 headroom（非 pass/fail 天花板结构）时，无需单独判别力探针，直接按预注册跑
- 确定性组件的一致性本身就是研究假设（'变异器是否退化'即命题）时，枚举它是主要结果而非预检失败
- 用户成本不敏感且明确要求全量复现跑（复现/监管目的）时，省预算不得否决指令
