## Trigger
要把一个外部工具/插件与自家同类实现逐维度对比、给出『有什么值得借鉴』的分析建议时；尤其外部 README 或介绍文章含量化能力断言，或上一轮结论基于二手材料且数字有争议，或外部工具疑似与本机平台不兼容（README 声明平台专属）。

## Discriminator
任务开始时已可见：README/文章的量化断言属宣传面且二手来源互相矛盾（19 vs 15/16 个工具；『静止几乎不花 token』）；README 同时明示 Windows 专属→本地实测不可能。这两条当时就把候选空间从『继续读宣传材料/搭环境实测/逐目录翻仓库』缩成『克隆源码核断言+声明证据边界』。

## Short path
- 读外部 README/SKILL.md 只用于列断言清单（含量化项），标记二手来源间的矛盾数字，不作为结论依据
- 用 README 平台声明/一次平台字符串检索（如 macOS|darwin 命中 0）裁决本地可运行性；不可运行即封顶为源码级证据，砍掉全部实测分支
- 克隆外部仓库，只读各断言对应的源码裁决点：工具注册处计数、盯屏 pipeline 的兜底常量与注释，逐条裁决并纠错
- 自家侧按已有机制锚定卡直读 live 实现（perceive/operate）与设计书（含已延后合同与既有裁决），不进 .releases 宽搜
- 输出：开头取证边界表（外部仅源码级/本机锁屏/推算值标注）→ 逐维度判定+按风险分批优先级 → 不借鉴清单（自家更强或更诚实处）→ 许可证限制 → 外部实战可作已延后决策的需求证据（在原裁决内激活，不重开）

## Stop conditions
- 每个有争议的量化断言都已被源码裁决点逐字核实，或显式标注为不可核
- 可运行性已由平台声明/检索一次性裁决，报告中不再出现与该裁决冲突强度级别的行为断言
- 每个借鉴建议都映射到自家具体合同/文件与风险级别；自家更优机制已列入不借鉴；所有推算值集中标注

## Verification
- 纠正后的数字与源码计数/常量一一对应（注册处恰好 N 处、兜底帧常量与注释原文）
- 『不可运行』有 README 明示或平台检索回执支撑，全文无源码级以上强度的外部运行时断言
- token/节点数等推算值显式标注非实测，未验证项集中在边界章节而非混入结论

## Counterexamples
- 外部工具闭源或源码不可得：源码裁决面不存在，退化为 README+黑盒实测，应改走最小实测+状态断言路径
- 外部工具可在本机运行：实测证据强于源码阅读，应先跑最小实测而非只读源码
- 用户只问『这工具是什么/怎么装』：README 足够，克隆源码是浪费
- 断言不含量化数字且不影响取舍（如 UI 文案风格）：无需源码级裁决
- 仓库的 README 本身就是官方合同文档（API 文档型项目）：可直接作为权威面
