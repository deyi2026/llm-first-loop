## Trigger
需要判断一篇对外内容当前是否已在平台公开发表，且手上同时有写侧信号（编辑器态、预览/临时链接）与可能的发表侧信号（后台发表列表、永久 URL、内容 API）时；尤其是此前曾报告『未发表/还差一步』后的复查，或发表动作可能由本会话之外（人工点击/其他会话）完成。

## Discriminator
编辑器态与预览页是写侧工件，发表后平台不会自动重置它们，因此对发表状态零证据；真正能一跳缩小空间的判别事实是：永久正式 URL 是否返回正式条目/publish_time，或后台『近期发表』列表是否出现匹配条目。

## Short path
- 明确未知量是『内容是否已在平台侧公开可见』，并把编辑器态/预览页从证据集中剔除（它们最多说明草稿仍存在）
- 首选消费侧/匿名路径：请求永久正式 URL 或内容 info API，看是否存在正式条目与 publish_time
- 若匿名请求返回反爬空壳（空 body + 混淆 JS），换已登录浏览器/CDP 读同一 URL，不得把空壳当『未发表』
- 拿得到后台时读『近期发表』列表，核对条目与发表时间，与永久 URL 交叉
- 两类独立发表侧工件均为空才判『未发表』；任一存在即判已发表，转入正文回读比对后停止

## Stop conditions
- 永久 URL 或内容 API 返回正式条目（含 publish_time/正式 slug）→ 已发表成立，停止状态判别，进入回读比对
- 后台『近期发表』列表出现内容匹配的新条目 → 同上，停止
- 只有当永久 URL 无条目且发表列表也无条目（两条独立路径都为空）才报告『未发表』

## Verification
- 永久 URL 条目正文与本地稿件回读比对：注意平台可能剥离 emoji/标记，按归一化字符数与逐字全等双口径报告（如剥离计数 + 归一化全等）
- publish_time 与后台列表时间一致；两条互不依赖路径（匿名内容 API + 后台/公网只读）结论一致才收口

## Counterexamples
- 未知量是『草稿还在不在/能否再编辑』时，编辑器态才是权威信号，本方法不适用
- 幂等动作（保存草稿、生成预览）无需发表态判别
- 平台强风控且无登录态可用、两类发表侧工件都取不到时，只能如实标注『状态未核验』，不能据写侧信号反推未发表
- 刚提交、平台异步入库延迟期间永久 URL 短暂 404 不代表最终未发表，应等待或查后台提交回执
