## Trigger
浏览器任务要求向富文本编辑器输入正文、点击无名称的 icon-only 按钮或上传文件/图片，目标元素可能不在无障碍树中，或对某浏览器路径是否可行存在开放疑问。

## Discriminator
进入宽探测前即可核对的机械事实：①对目标占位符的定位回执是 target_not_found/match_count=0（确定性失败，非超时或模糊匹配）；②快照显示目标输入区无 kind+name（占位符走 CSS 伪元素不进无障碍树），全页仅少数有 name 的常规输入框；③所需工具栏按钮是无 accessible name 的 icon-only <button>；④备用脚本执行工具 schema 明示 URL 白名单+每次调用独立子进程不保留会话，接不到已登录会话；⑤工具清单无文件上传能力。②③④⑤中覆盖'必需动作'的部分成立，即证明该路径在当前工具面不存在。

## Short path
- 先列全所需动作全集（聚焦正文、输入正文、点插入图片、上传文件），把开放式探测变成有限清单核对
- 一次按 kind/role 过滤的快照列出全部可寻址输入与命名按钮，对照清单逐项标注可寻址/不可寻址，不逐页翻全量对象
- 对每个不可寻址的必需动作，查当前工具注册表/schema 有无可达同一会话的替代通道（脚本 exec、上传 API），以合同原文（白名单、会话隔离、能力声明）为准，不以历史会话检索为准
- 必需动作全部不可达 → 立即产出人工交接包：已完成部分确认、待粘贴成品、逐处精确操作说明，停止探测
- 若评估期间目标工件被改（行号/尺寸漂移），交接前重读并哈希核对，以分支/权威版本为准

## Stop conditions
- 任一必需动作被证实在当前工具面可寻址且有可用通道 → 走正常操作路径，不降级人工
- 三项门控（输入可寻址性、按钮命名、替代通道）核对完毕且结论为不可行 → 立即转人工交接，不再补充探测
- 交接包已逐项核对（产物存在、引用与实际文件一一对应、已完成部分与回执一致）→ 终止

## Verification
- 每条不可行结论挂机械回执：target_not_found+match_count=0、快照对象 attributes 无 name、schema 白名单/会话隔离原文；不接受纯推断
- 能力判断只引用当前工具合同；历史会话检索的空命中只能说明无记录，不能反向证明能力存在与否
- 交付前重读被评估工件做哈希/尺寸核对，确认探测期间未被并发改动或换版

## Counterexamples
- 目标输入在无障碍树中有 kind+name（如普通有名称的 textarea/input）→ 直接 set_text，不套用本门控
- 存在无白名单/会话隔离限制、能接入同一已登录会话的脚本或上传工具 → 走该通道，不判不可行
- 操作可寻址但被业务规则拦截（未登录、权限、审核）→ 这是流程/权限问题，解决流程而非降级人工
- 任务只需填写命名输入框的普通表单 → 直接操作，无需整面可行性评估
