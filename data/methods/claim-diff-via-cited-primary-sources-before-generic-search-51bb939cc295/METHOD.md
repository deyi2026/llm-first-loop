## Trigger
用户给出新闻稿/评测/发布公告并要求解读、评估或核查其主张；正文显式列出可抓取的一手来源链接（项目官网、论文、规范文档），且主张以可对照的数字与排名为主。

## Discriminator
抓取正文后即已具备两个当时可见的事实：①文中显式引用的一手来源 URL 清单，与核心数字主张 1:1 对应（官网和论文能直接核对全部头条数字）；②正文或一手来源已出现自我限定语（如'公开评测部分，不是完整的私有榜单成绩'）。这说明核验所需权威证据已在 provenance 边上；剩余未知量（竞品动态、第三方榜单权威性）要么不是用户核心问题，要么通用搜索无法权威解决（会退化为词典词条或同源 PR 回声）。

## Short path
- 抓取正文：提取全部可核对主张与文中显式引用的一手来源清单；若回执标记 source_partial，先用 provenance 句柄补全剩余区间，再外查
- 逐个抓取被引一手来源：先做数字对照，再专门摘录原文未复制的限定语/脚注/默认参数——打折结论主要来自这些限定语
- 把主张分桶：与一手来源一致 / 需打折 / 一手来源无法裁定
- 仅当某剩余未知量同时满足'用户问题依赖它'且'能命名具体权威信源'时，才做专名开头的窄搜索；否则直接在答案中标注'未核实'
- 输出核验报告并停止，不为补充语境追加搜索

## Stop conditions
- 全部数字/排名主张已与被引一手来源逐一对照，限定语已摘录
- 无法由一手来源裁定的主张已在答案中显式标注未核实，且不存在可命名的权威信源可窄查
- 用户问题的结论不再因任何剩余未知量而改变

## Verification
- 每条'打折'结论都能指向一手来源的原文短语（子集范围、评测范围声明、参数默认值）
- 确认没有把二手转载或同源 PR 回声当作独立佐证引用
- 答案中'已核/未核'边界清晰，未核项不会伪装成结论

## Counterexamples
- 用户要的是行业语境、第三方口碑或竞品对比而非主张核验：搜索是主线，vendor 一手来源反而是利益相关方
- 主张涉及第三方动态（如竞品发布）：被引一手来源不可能覆盖，需以具体产品/事件名为查询的窄搜索，本方法不适用
- 被引链接失效或付费墙：provenance 边断裂，转发现式搜索
- 文章不含任何来源引用：无 edge 可沿，只能搜索发现
