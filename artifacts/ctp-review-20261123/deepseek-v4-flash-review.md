## P0（致命 / 规范不可判定或按文档无法实施）

### P0-1 公差带 [TBD-V3] 与门槛 V3 互为前提（循环依赖）
- 等级：P0
- 位置：SPEC §0.2 第 22 行 + §4 P-2 第 92–94 行 + §11.2 V3 第 251 行
 - 原文：`[TBD-V*]：数值空缺，依赖第 11.2 节门槛 V* 的实测结果填充；` / `| V3 | 公差带 | 认证样本经影像测量仪 / 激光跟踪仪实测公差落入规范带 |`
- 问题：P-2 的公差带数值标 [TBD-V3] 并声明由 V3 实测填充，而 V3 的通过判据是"实测公差落入规范带"——判据需要尚未存在、且正待它自己产出的规范带，V3 在带定义前不可执行。
- 修法：V3 判据改为"实测值 ≤ 独立外部给定上限"（先定带再验证），或在 §11.2 明确 V3 只输出分布、由工作组据分布定带，不承担"落带"判定。

### P0-2 门槛 V4 可被"永不输出"平凡满足，且与 C-4 阈值互相依赖
- 等级：P0
- 位置：SPEC §5 C-4 第 125–126 行 + §11.2 V4 第 252 行 + PROP §G7 第 73–75 行
- 原文：`a) 输出观测的必要条件：可见角点数 ≥ [TBD-V4] 且数据位可见比例 ≥ [TBD-V4]；` / `| V4 | 降级行为 | 低于最小可读条件的样本：误读率 = 0（只允许漏检，不允许错读） |`
- 问题：误读率 = 0 不设召回率下限，任何"永不输出"实现均通过，验证方法预设了待验证结论；且界定"低于最小可读条件的样本"需先用尚无的 [TBD-V4]，循环。
- 修法：V4 增列召回率下限、样本量与重复次数；阈值由 V4 网格扫描产生并写入回执，C-4 只引用回执编号，不反向依赖。

### P0-3 级间位姿差阈值与 V8 判据互为输入（循环依赖）
- 等级：P0
- 位置：SPEC §9 F-3 第 211 行 + §11.2 V8 第 256 行 + §14 第 315 行 + PROP §G3 第 48 行
- 原文：`相邻两级给出的位姿差 > 阈值 [TBD-G]（联动 V2 实测）时，必须回退上一级并报警` / `- k 初值 = 2；终值由 V8 注入故障集校准——取"1000 故障样本中带错硬接 = 0"的最小 k`
- 问题：判定是否"带错硬接"必须先有级间阈值，而 G3 又规定该阈值由 V8 结果校准，判据与阈值互为输入；且 SPEC §14 记"联动 V2"，G3 记"由 V8 校准"，依赖声明本身不一致。
- 修法：阈值先以 k·RSS（k=2）独立冻结并裁决，V8 只用于验证，不参与定值；同步 §14 依赖栏为"V8 验证，非 V8 定值"。

### P0-4 单码容量与"按 C-1 解析的 ID"输出契约冲突，规范未声明容量约束
- 等级：P0
- 位置：SPEC §5 C-1 第 110–113 行 + C-5 第 134 行 + PROP §G1 第 30、32 行
- 原文：`| id | 按 C-1 结构解析的靶标 ID |` / `- 码内物理承载：板内索引（10 bit 足够覆盖 587 码字），前缀与本地高段由注册表 + 板级几何登记（M-2）联合解析；`
- 问题：C-5 要求读码器直接输出按"前缀段 + 本地段"解析的 ID，而 G1 已承认单码只能承载板内索引、全局 ID 须经注册表聚合；规范正文既未写单码容量上限，也未给离线不可反解的例外，照 C-1 直读不可实施。
- 修法：C-1 增"单码承载容量上限 + 强制分层映射"，C-5 增"本地索引 / 板级聚合来源 / 离线不可解析"字段与限制声明。

## P1（重要缺陷）

### P1-3 门槛占位符一对多：同一编号指多个不同物理量
- 等级：P1
- 位置：SPEC §4 P-1a 第 88 行、P-2 第 92–94 行、P-3b 第 98 行、§7 M-2a 第 163 行、§9 F-2 第 207 行 vs §11.2 V2 第 250 行 / V3 第 251 行
- 原文：`a) 靶标表面必须为哑光；可见光（400–700 nm）下黑白区域漫反射对比度必须 ≥ [TBD-V3]；` / `| MID → NEAR | 阵列 / 高密度大板可见；角点亚像素残差 ≤ [TBD-V2] |`
- 问题：V3 同时承载对比度（无量纲比）、边长/平面度/贴合公差（mm）、热膨胀系数（1/K）、阵列夹角（deg）；V2 同时承载位姿精度（mm/deg,3σ）与亚像素残差（像素）。一号多义，判据无法一一对应，回填必然错配。
- 修法：按物理量拆分占位符并各自绑定门槛（如 [TBD-P1]/[TBD-P2]/[TBD-P3]、[TBD-F2] 残差），§14 跟踪表逐项列行。

### P1-4 C-2"必须指定强制码族"与"最终选择 [TBD-G]"同句冲突，合规实现不可判定
- 等级：P1
- 位置：SPEC §5 C-2a 第 116 行 + §1.2a 第 43 行 + §11.1a 第 239 行
- 原文：`a) 本规范必须指定至少一个强制码族；候选示例（资料性）：…或等效族；最终选择 [TBD-G]；` / `a) 读码器检测算法的内部实现——任何满足 C-5 输出契约并完成第 11 章合规声明的实现均为合规实现；`
- 问题：约束力词"必须"用于一个留作 [TBD-G] 的选择项；裁决前不存在可判定的码族基线，§1.2a 的"合规实现"定义与 §11.1a 的"支持码族"声明项均落空，互操作测试无法启动。
- 修法：加过渡条款"裁决前以 tag36h11 为暂行强制族"，或把 C-2a 改写为对工作组的限期交付要求并移出规范义务。

### P1-5 门槛 V1 无通过/不通过语义，且 100 ms 系经验估算值写入门槛表
- 等级：P1
- 位置：SPEC §11.2 V1 第 249 行 + §13.1 Q1 第 288 行 + §0 第 6 行；DESIGN §10.1 Q1 第 278 行、§11.1 P2 行 第 331 行
- 原文：`| V1 | 自检时延 | 全流程 P95 < 100 ms；超时降级为逐靶串行并报告，不判失效 |` / `估算，未实测…不触发 fail-closed`
- 问题：既写"P95 < 100 ms"又写"不判失效"，门槛不可判定；100 ms 自认估算，与 SPEC 第 6 行"禁止以经验值填充"冲突；而 SPEC §13.1 又称其为"非规范指标"，DESIGN P2 验收却要求"V1–V8 全部实测通过"。
- 修法：V1 移出门槛表改列为可用性指标，或补二元判据（P95 ≤ 100 ms 通过 / >100 ms 不通过）并注明 100 ms 为待实测目标值。

### P1-6 覆盖因子与合成判据缺失：V2 的 3σ 与 V6 的 RSS 无法对照
- 等级：P1
- 位置：SPEC §11.2 V2 第 250 行、V6 第 254 行 + §5 C-5b 第 142 行 + §11.1c 第 241 行
- 原文：`| V2 | 定位精度 | 合作通道在 0.2–2 m、入射角 ±60°、规定光照内：平移 ≤ 2 mm (3σ)、旋转 ≤ 0.5° (3σ) |` / `| V6 | 跨厂商一致性 | 两个合规读码器对同一认证样本位姿差 ≤ 声明不确定度的 RSS |`
- 问题：V2 固定 3σ 口径，C-5/V6 的不确定度声明未规定覆盖因子 k 与 1σ 值，把 3σ 目标与未定 k 的 RSS 阈值相比不可判；V6 亦无样本量、重复次数、通过比例与独立性假设。
- 修法：C-5 强制声明 k 与 1σ 值；V6 改写为 |Δ| ≤ k·sqrt(u1²+u2²)，并规定测量次数 N、通过判据（如 ≥95%）与独立性前提。

### P1-7 G6 公差带构造与"认证样本内侧 ≥1/3 带宽"数值上不能同时成立
- 等级：P1
- 位置：PROP §G6 第 66–68 行（关联 SPEC §4 P-4 第 102 行）
- 原文：`- 制造裕度预留 ≥ 20% 带宽（覆盖批次间漂移）；` / `- 认证样本公差必须落在规范带内侧 ≥ 1/3 带宽处（保证基准件不贴边）`
- 问题：带定义为合并分布 P2.5/P97.5 再外扩 ~20% 带宽，落在 P97.5 的样本距带边仅约 0.1/1.2 ≈ 8% 带宽，达不到"≥1/3 带宽内侧"；两条决策规则互斥，G6 无法生成有效带。
- 修法：带改为 P0.5/P99.5 或均值 ±3σ 加裕度，或把内侧要求降为 ≥10% 带宽，并给出带宽-分位-裕度的反算公式与数值示例。

### P1-8 V8 要求的"全部停止 + 报警"与 C-4b/C-2b 规定的"不输出"行为冲突
- 等级：P1
- 位置：SPEC §11.2 V8 第 256 行 vs §5 C-4b 第 126 行、C-2b 第 117 行；§9 F-4 第 213–216 行
- 原文：`| V8 | fail-closed | 注入 1000 个故障样本（错 ID / 贴歪 / 遮挡 / 伪造），"带错硬接" = 0，全部走停止 + 报警 |` / `b) 低于阈值时读码器必须不输出——宁可漏检，不可错读（对应门槛 V4）；`
- 问题：对遮挡/超纠错码字，C-4b 与 C-2b 的合规行为只是"不输出"（相当于静默漏检），V8 却要求所有注入故障样本一律"停止 + 报警"。同一输入两套强制行为，实现方无法同时满足。
- 修法：V8 按故障类型分派期望行为（漏检类 = 不输出且计数上报；伪造/层级矛盾类 = STOP + 报警），并使 F-4 各出口与之一一对应。

### P1-9 "禁止移除任何 TBD 标记"与"回填时替换标记"的填充流程互斥
- 等级：P1
- 位置：SPEC §0.2 第 25 行 + PROP §附 第 79 行（关联 SPEC §15 第 322–325 行）
- 原文：`正式发布（v1.0）前禁止移除任何 TBD 标记；每次填充必须附对应实测回执或工作组决议编号（记入第 15 章变更历史）。` / `回填规范时替换对应 `[TBD-G]` 并记入第 15 章变更历史；`
- 问题："禁止移除任何 TBD 标记"若按字面执行，则每次填充都与该禁令冲突（替换即移除），而 PROP 的回填流程明确要求"替换"；不写清填充/移除的区别，规范永久停留在不可填状态。
- 修法：改为"填充时保留 TBD 编号并追加值与回执编号；仅在 v1.0 定稿时统一清除标记"，PROP §附 1 同步为同一动作词汇。

### P1-10 G7 以"共面 4 点"为最小可读角点数，忽略平面 PnP 位姿二义性
- 等级：P1
- 位置：PROP §G7 第 74 行（关联 SPEC §5 C-4b 第 126 行、§7 M-2b 第 164 行）
- 原文：`- 角点数阈值：提案 = 4（几何必要性：共面 4 点是 6DoF PnP 解的最低要求，属结构事实而非经验值，可直接裁决）；`
- 问题：共面靶标仅 4 个可见角点时 PnP 存在两个位姿解（planar pose ambiguity），可能输出"看起来达标"的错误位姿；这与 C-4b"宁可漏检、不可错读"及几何互证的防伪假设相悖，提案把可解性直接当作可读性。
- 修法：4 点作为下限但附"共面单靶 4 点必须做二义解消解或要求 ≥6 点"，并新增对应实测项（低角点数姿态歧义率）。

## P2（改进建议）

### P2-1 C-4a 同一 [TBD-V4] 同时代表"角点计数"与"可见比例"两种量纲
- 等级：P2
- 位置：SPEC §5 C-4a 第 125 行（PROP §G7 第 74–75 行已拆为两项）
- 原文：`a) 输出观测的必要条件：可见角点数 ≥ [TBD-V4] 且数据位可见比例 ≥ [TBD-V4]；`
- 问题：一个占位符承载"整数个数"与"0–1 比例"两种量纲，回填与审计时易错配；提案已按两项分别裁决，正文未同步。
- 修法：拆为 [TBD-V4a]（角点数，个）与 [TBD-V4b]（数据位可见比例，%）并在 §14 各列一行。

### P2-2 §3.2 中阶段"1–10 mm"与 V2 的"≤2 mm (3σ)"口径不一致
- 等级：P2
- 位置：SPEC §3.2 第 81 行 vs §11.2 V2 第 250 行
- 原文：`| 中：编码图案 | AprilTag / ArUco 族 | 1–10 mm | 阵列 / 高密度大板可见 | 角点亚像素残差、重投影误差 |`
- 问题：同一通道 3.2 给 1–10 mm 上限 10 mm，V2 要求 ≤2 mm(3σ)；虽 3.2 标"资料性/禁止引用"，两表并列必被对照引用，形成"能不能做到"的误判。
- 修法：3.2 精度列改为"（V2 口径：平移 ≤2 mm@3σ；收敛前量级见 §10 Q2）"，或删除具体区间只留量级说明。

### P2-3 F-4a "有限次"重试无上限，不可判定
- 等级：P2
- 位置：SPEC §9 F-4a 第 214 行
- 原文：`a) FAR 失败：按实现策略重试（换通道 / 扩大搜索）有限次后 → STOP；`
- 问题："有限次"与"按实现策略"均无界，无法判定实现是否合规，V8 也无法据此构造期望行为（重试几轮算失败）。
- 修法：规定 1 ≤ N ≤ 3 或要求实现方在 §11.1 合规声明中公开 N 与单次超时预算，并纳入 V8 期望行为表。

### P2-4 T-3"至少一级防伪或独立安全通道"与 T-4d"必须 a + b"强度不一致
- 等级：P2
- 位置：SPEC §8 T-3 第 186 行、T-4d 第 192 行
- 原文：`涉及安全的决策必须叠加 T-4 至少一级防伪或独立安全通道（Q11 裁决）` / `d) 开放环境部署必须至少实现 a + b，并留存风险评估记录。`
- 问题：同一对象（安全决策的防伪下限）在 T-3 允许"仅一级"或"独立安全通道单独满足"，T-4d 对开放环境要求 a + b 两级；实现方不知以哪条自证合规。
- 修法：明示 T-4d 为 T-3 的加严子条款并声明"开放环境不适用独立安全通道单独满足"，或统一为 a + b。

### P2-5 V5 判据中"毫米级通道"未定义，不可实测
- 等级：P2
- 位置：SPEC §11.2 V5 第 253 行（关联 §7 M-5b 第 172 行）
- 原文：`| V5 | 投影标定 | 前提自检不满足时必须判"粗对齐"并打降级标记；混入毫米级通道即不通过 |`
- 问题："毫米级通道"未定义为哪一级/哪个阈值；C-5 输出契约也无降级标记字段，无法观测"是否混入"，判据不可实测。
- 修法：定义为"该观测被 F-2 用于 NEAR 交接或计入 V2 精度统计"，并在 C-5 增 degradation_flag 字段以支持观测。

### P2-6 Q10 状态标记在设计与规范间不一致（已闭合 vs 待确认）
- 等级：P2
- 位置：DESIGN §10.4 Q10 第 311 行 vs SPEC §13.1 Q10 第 297 行
- 原文：`已闭合方向：规范条目（S2，Phase 0 起草）。` / `| Q10 | 温度形变 | P-3 | T0 提案待确认 |`
