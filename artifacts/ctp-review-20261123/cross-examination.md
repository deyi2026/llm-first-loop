## Q1 SPEC 111「可选公共注册」能否保证 113 的前缀唯一？是否与 G1 无关？

- **结论**：不能；是独立缺陷，与是否采纳 G1 无关。**等级：存疑 3 → P1（新增 P1-11）**。
- **依据**：113 `c) 跨机构互通必须且只需前缀唯一（Q9 裁决）。` 而 111 行只给「机构自治分配 + 可选公共注册」，57 行却把前缀定义为「跨机构唯一」。唯一性是分配权威的属性，与码内是否承载前缀（G1）正交；「可选」注册无碰撞检测机制。
- **修法**：C-1a 改强制公共注册，或写明自治分配 + 冲突检测 / 保留号段；否则 113 的「必须」降为「应」。

## Q2 PROP 48「最小 k」是否可识别？零错约束集是否向下封闭？

- **结论**：向下封闭；故最小 k 被推到 0.5 粒度下限 → 阈值≈0 → 回退率近 100%，规则失去判别力。**等级：新增 P1-12（提案层；照用即 P0）**。
- **依据**：48 `取"1000 故障样本中带错硬接 = 0"的最小 k，四舍五入到 0.5 粒度后取保守侧；` + 46 行阈值 = k×RSS。k↑→阈宽→漏拦↑ ⇒ N(k) 单调不减，零错集为 [0,k*]。
- **修法**：取满足零错的**最大** k（边界），并显式加回退率上限（如 ≤5%）作第二约束；PROP 75「上确界」同型，须配漏检率上限（并入 P0-2）。

## Q3 PROP 66 定带样本与 SPEC 251 判据是否样本内自证？

- **结论**：是，判据恒真——带由认证样本自身 P2.5/P97.5 生成，样本必落自身上下级分位内；68 行再加「内侧 ≥1/3」。**等级：P0-1 范围扩大（P0 维持）**。
- **依据**：66 `上/下界取认证样本 + 批次抽检合并分布的 P2.5 / P97.5（对应 ≈ 2σ）；`；251 行 V3 用同一认证样本判「实测公差落入规范带」。
- **修法（最小）**：V3 改用独立留出批次抽检落带（认证样本仅定带 + 作 V6 基准），判据改为带外率 ≤ 声明值。

## Q4 用 1.96σ 重算「样本距带边占比」，8.3% 是否与 σ 无关？

- **结论**：与 σ、1.96/2、分位取值全部无关；P1-7 维持 P1，但算式与修法需更正。
- **算式**：h=1.96σ，分位带 2h，总带 2h+0.2·2h=2.4h，带边 1.2h；P97.5 样本在 h，距边 0.2h ⇒ 0.2h/2.4h = 1/12 = 8.3%（h 约去；取 2σ 同得 0.4/4.8 = 8.3%）。
- **更正**：原式「0.1/1.2」应为「0.2/2.4」；一般式 m/(2+2m) 不随分位变，故原修法「改 P0.5/P99.5」无效——要满足 ≥1/3 需裕度 ≥200% 带宽。
