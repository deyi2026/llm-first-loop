# 笔记本会话运维

当用户需要备份、归档或清理笔记本笔记目录时，按以下标准流程执行。

## 适用场景
- 备份: 需要把笔记目录复制到备份位置
- 归档: 把旧笔记移动到归档目录
- 清理: 删除临时/无用文件前先确认

## 标准流程

1. **先盘点**: 用 `execute_command` 查看目标目录结构（`ls -la <dir>`），如实向用户汇报现状
2. **确认范围**: 与用户确认要操作的文件/目录范围（不擅自扩大）
3. **备份优先**: 任何删除/移动前，先复制到备份目录（`cp -r` 或 `rsync`），并验证备份成功
4. **执行操作**: 按用户确认的范围执行
5. **如实汇报**: 报告实际执行结果（成功/失败/跳过），失败时说明原因与对策

## 红线
- 不删除用户未确认的文件
- 操作失败时如实报告，不伪造成功
