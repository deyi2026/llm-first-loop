【场景】为技术科普稿画信息图（docs/promotion/figures/_dNN.py + _draw.py），一张图里放两组或多组百分比条形。

【已发生的失败】2026-11-03 晚班 d57 画 fig250（压缩预算 → 规则保留率）：上半部分「规则保留率」用的是 0–60% 标尺（因为该组数值都在 5.9%–100% 且想放大差异），下半部分「规则丢失率」用的是 0–100% 标尺。两组条形长度因此不可比，且下半部分按 100% 标尺画到 100.0% 时条形顶到了分图标题，压住标题文字。首次渲染即废，重画后修好。

【运作规则】① 同一张图里所有百分比条形必须用同一条 0–100% 标尺（长度可比是这类图的第一要件）；若某组数值区间太窄想放大效果，就改成区间标注或单独成图，不要换标尺；② 画完必须 read_image 实看：重点看条形是否压到标题/图例、右侧标注是否被裁切、同图两组条形长度是否可比；③ 渲染脚本里加断言：内容下缘 < 画布高、底部留白 ≥8px（本班脚本已有）。

【当前性验证】复现：跑 `cd docs/promotion/figures && python3 _d57.py`，应打印 4 张图的 (1000, 宽) 与 bbox 且不报断言；当前 fig250 的条形宽度两段同为 `sx, sw = 250, 430`（同一标尺），grep -n "sx, sw" docs/promotion/figures/_d57.py 可确认两段标尺一致；若后续新稿沿用同一画法，先 grep 该行确认。

【适用边界】只管条形标尺与版面净空；论文数值本身不得自行补值（见 EXPERIENCE-20261101-推广配图-论文未给出的量化值一律不得自行填）。
