title: 会话瘦身四步（备份+占位化+flock安全写+配对检查）与分批治本
scenario: 会话历史膨胀（超 100 万字符）触发频繁压缩、缓存命中率下降时；批量任务（SWE 等）跨批次的会话维护。
root_cause: 长会话（SWE 批量任务）工具消息累积致历史膨胀→每轮压缩破坏前缀→缓存命中率下降。
solution: "会话瘦身四步：① 备份会话文件（cp 到 /tmp 带时间戳）；② tool 消息占位化——保留最近 N=50 条完整，更早的 tool 结果压缩为占位（保留 role/tool_name/status），消息数与结构不变；③ flock 安全写回（防并发写坏）+ 配对检查（tool_call 与 tool_result 一一对应，0 孤儿回执才算成功）；④ 注入引导消息（如\"分批 ≤20 实例 + 批间 /clear\"）治本。验证：引擎可加载 + 0 孤儿回执 + 字符数下降。备份保留可恢复特定条目。**治本**：批量任务分批（≤20 实例/批），批间 /clear 或开新会话，避免单会话无限膨胀。"
evidence: "2026-08-18 会话 2a3385da 膨胀至 220 万字符触发每轮压缩（缓存命中率从 99.6% 跌至 90% 以下），外部执行瘦身：2176 条 tool 消息占位化（保留最近 50 条完整），总字符 220万→75万（-66%），消息数 5807 结构不变，flock 安全写 + /tmp 备份（9.2MB）+ 配对检查（0 孤儿 tool 回执）。效果：历史 75万<预算 100万，不再每轮压缩，前缀稳定，命中率回升 90%+。引导消息注入\"分批 ≤20 实例 + 批间 /clear\"。"
