scenario: 任何需要经验/教训卡防再犯的多步工具任务（尤其含 execute_command + python 的长流程），开局检索只用任务域词时，执行环境类既有坑卡不会被命中。
root_cause: 经验检索关键词只覆盖任务域（做什么），未覆盖执行环境（怎么做）；已知执行习惯坑的卡因此不在工作集内，防再犯机制失效
solution: 开局检索固定两组关键词：任务域词 + 执行环境词（heredoc/解释器/管道/沙箱/命令模式）；命中执行习惯类卡后在心里预演一次触发场景再动手。

现象：d39 早班开局按任务域词（「头条 发布 链路 CDP 审核」）检索经验库，命中的全是发布域卡；随后执行中 3 次重踩「heredoc 直喂解释器 / 复杂管道接 python -c」并被 FR-SAFE-01 硬阻断——而该坑的既有教训卡确实存在（d38 早班开局检索命中过并在 13:2x 重踩 1 次）。本班 3 次阻断的根因不是卡缺失，而是检索关键词面没有覆盖执行环境词，导致已知坑的卡未被拉进工作集。

修复：每次硬阻断后立即改「先 cat > 落盘脚本文件、再单独 python3 file.py」两步式恢复，无数据损失；但重复阻断本身消耗了轮次。

预防：任务开局的经验检索至少两组关键词——任务域词（做什么）+ 执行环境词（怎么做：heredoc/解释器/管道/sandbox/命令模式）。对已登记过「执行习惯类」坑的安装（本安装有 FR-SAFE-01），执行环境词组是必选项。
