title: push 需用户当次同意；依赖用户浏览器/账号的代码与验收考虑剥离独立项目
scenario: 跨会话交接后继续执行实验项目任务：交接文档含用户历史批准（真机 web 通道验收），新会话据此直接操作用户的 CDP 浏览器（开标签页）并准备依赖用户 deepseek 账号发真实请求。
root_cause: 将上一会话交接文档中记录的历史批准当作当前会话的持续授权，未意识到用户在当前时刻的边界（浏览器/账号是用户私域，实验依赖它们时应先问）。
solution: 收到 push 禁令与剥离评估指令后：所有 git push 动作以用户当次明确同意为前提；涉及用户私域（浏览器、账号、外部服务）的操作在执行前以当前对话确认授权；对影响测试/验收的代码做只读影响面评估后向用户提交剥离方案选项，不擅自启动剥离。
