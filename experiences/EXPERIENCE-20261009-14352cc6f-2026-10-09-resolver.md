发布门禁（插件/任何版本发布前逐项核验）：
1. `git merge-base --is-ancestor 14352cc6f <发布分支>` 必须为真；不为真则先合入 fix/restart-cli-recovery-stable-20261009。
2. 同文件冲突（resolver.py / service_control.py / restart_mirror.sh / task_budget_admin_once_setup.py / test_evo_9d116efa_restart_hardening.py 两线都改过）以 14352cc6f 侧语义为准：查询与 --check-toml 分离、端口 1..65535 前置校验、not_started 回执释放准入、单次新受管 action 回滚绑定 generation 接管终态屏障。
3. 验收只认受管 action + live manifest + 健康接口 + 准入屏障；脚本 rc=0/无回执/陈旧回执不能证明停机，不自动制造新物理操作。
4. 部署候选从含 14352cc6f 的线切出，不用插件分支未资格化状态。
