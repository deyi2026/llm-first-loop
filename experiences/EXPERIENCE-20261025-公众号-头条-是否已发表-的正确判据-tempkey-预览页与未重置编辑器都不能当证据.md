title: 公众号/头条「是否已发表」的正确判据（tempkey 预览页与未重置编辑器都不能当证据）
scenario: 微信公众号图文发表后做公网回读判定时，误把 tempkey 预览页（页面自述「此为临时预览链接，将在短期内失效」）与「编辑器标签页仍开着、封面槽仍空、发表按钮仍置灰」当作「尚未发表」的证据，据此向用户报告「还差一次人工点击」；实际文章已于 30 分钟前发表，且公网永久短链可匿名读。同类风险也存在于头条：作品管理页的「审核中」是快照态，会自行转为「已发布」。
root_cause: ""
solution: "判定「已发表」必须用下列任一独立证据，不能用编辑器态或预览页：(1) 后台「近期发表 / 全部发表记录」列表出现该条；(2) 存在永久 /s/ 短链（公众号）或 item URL（头条）；(3) 页面 meta 出现「原创 + 发布时间 + 地区」等平台生成字段。查证最快路径：公众号直接 web_fetch https://mp.weixin.qq.com/s/<短链>（匿名可读）；头条抓 https://m.toutiao.com/i<itemId>/info/v2/（匿名返回完整正文 JSON + publish_time），比在作品管理页翻找链接快。附带要点：发表后编辑器不会自动重置，封面槽/按钮状态与发表态无关；跨平台逐字比对必须先按 code point 归一化（头条会剥离 🟩🟨🟦📌💥 等非 BMP emoji，✅⛔ 存活，公众号不剥离），否则会把渲染差异误判为内容缺失。"
evidence: "本轮实测：公众号永久短链 https://mp.weixin.qq.com/s/v3_u5a3BbnxjjZPIsHy6aA 匿名可读，meta「原创 LFL 起末 / 2026年10月25日 15:38 广东」；头条 https://m.toutiao.com/i7700481913084969482/info/v2/ 匿名返回完整正文与 publish_time=1792909021(14:17:01 CST)。误判发生于 16:09–16:15（仅看 tempkey 页 + 编辑器态），纠正于 16:53–17:05。emoji 偏差：头条公网非空白 11781 vs 本地 11825，差 44；剥离 44 个 emoji 后 11778=11778 逐字全等。"
