title: 一次性脚本依赖第三方包时不要加 python -I：隔离模式会丢 site-packages
scenario: "LFL 推广第 95 期用一次性脚本直连 CDP 做发布页取证（需要 websockets 包）：写成 `python3 -I /tmp/d95_editor_check.py` 执行，结果 ModuleNotFoundError: No module named 'websockets'——`-I` 隔离模式会丢掉 site-packages，第三方依赖不可见；同一批脚本里只用标准库的（读文件、数值抽取）用 -I 正常，混用时容易误判成「包没装」。"
root_cause: ""
solution: "一次性脚本若依赖第三方包（websockets/requests 等），不要加 -I；需要隔离时改用 `python3 -E -s` 或显式设置 PYTHONPATH；纯标准库脚本保留 -I 无妨。判据：脚本 import 了非标准库模块就不要加 -I。当前性验证：跑 `python3 -c \"import websockets\"`（加 -I 会失败、不加 -I 成功）；复现：`python3 -I <脚本>.py` 若报 ModuleNotFoundError 即命中此坑。"
evidence: "执行 `python3 -I /tmp/d95_editor_check.py` 回执 ModuleNotFoundError: No module named 'websockets'；去掉 -I 后同一脚本正常输出 JSON 取证结果"
